# AI state icon set

- `clear` — A balanced four-point signal star with two quiet companion stars. It reads as an available AI presence without implying activity. Static by design.
- `overcast` — The signal contracts into a nucleus while one satellite makes a slow six-second orbit. The orbit suggests thought circling a problem; the core breathes every 2.4 seconds.
- `storm` — The constellation becomes an angular lightning route between two nodes. A restrained 0.9-second trace and alternating 1.15-second node pulses make execution feel active without flashing.
- `clearing` — Three loose paths converge on a resolved star. Staggered 2.7-second dashes imply remaining work arriving in sequence, while the final star gently settles into full size.

All geometry is stroke-only in a `24 24` viewBox. Every path and circle has `pathLength="1"`, so it remains compatible with the widget's draw-in animation and halo/ink double rendering.
