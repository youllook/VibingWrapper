# 環形太空站（ring-station）· 0 分析做法與預期效果

目標圖：`../infinite-series/x02.png`（2026-11-27 用戶從無限系列 16 張挑中，Tripo 點數不設限）。

## 幾何怎麼成立（決定一切的那一步）
- 棲地是一個**巨大圓筒的內壁**（Bishop ring 式）：半徑 R≈2 km、寬 W≈6 km，**轉軸沿世界 +X**（畫面右手方向、往霧裡）。
- 列車沿**圓周**跑。從車窗斜看「前方偏右上」：
  - 左邊＝前進方向：地面沿圓周往上翹 → 爬過頭頂 → 就是頂上那片「倒掛的城市」（同一個圓筒的對面）。
  - 右邊＝沿軸線：地面是平的，一路延伸進霧裡。
  - 人造太陽在圓筒中心軸上（離地 R）。
- 目標圖裡「軌道往左上彎」「左側城市爬牆」「頂上倒掛」「右側平坦城市＋霧」用這一個圓筒全部對得上。

## 無限怎麼成立
- 鏡頭＋車窗框固定，**整個棲地繞 X 軸轉**（角速度 ω＝v/R）。圓筒沿圓周天然無縫，轉一整天都不會有接縫或精度問題（角度取 mod 2π）。
- 近景桁架以 8 m 一節沿圓周 instanced 一整圈（≈1,570 節），每節一盞維修燈，掠過速度最快。

## 分層（對應「前景重複、背景微變」）
| 層 | 內容 | 速度感 |
|---|---|---|
| 鏡頭層（固定） | 車窗框、座椅邊、玻璃髒污與反光 | 不動 |
| 近景 | 高架軌道、護欄桁架、維修燈、維修工（偶發） | 最快、可加動態模糊 |
| 中近景 | 軌道沿線的建築、溫室、圓頂會館、河道 | 中速 |
| 中景／遠景 | 右側沿軸平坦城市、左側爬升的城市、頂上倒掛城市 | 慢 |
| 天空 | 人造太陽、圓筒結構拱肋、玉色霧 | 幾乎不動 |

## 素材策略（用戶：Tripo 別客氣）
- **建築、維修工、配電箱、樹 → Tripo 生成**（Codex 先出 3/4 俯視、去背的輸入圖）。建築 7 款以 instancing 鋪滿圓筒內壁，遠的用同款縮小＋霧蓋細節。
- **要拼接／精準尺寸的 → 程式**：軌道、護欄桁架（要無縫串接）、車窗框、圓筒拱肋。
- 雲霧光一律程式（規則）：沿視線累積的霧＋太陽散射。

## 預期效果與風險
- 預期：一眼看出「在一個會轉的世界裡」，倒掛城市緩慢從頭頂滑過，近景桁架快速掠過，維修工偶爾出現。
- 風險 1：城市數量（圓筒內壁 75 km²）→ 密度分區：鏡頭附近密、遠處稀，遠處靠霧和剪影。
- 風險 2：Tripo 建築的面數 → 重拓撲到 1–2 萬面，遠處另做低面版本。
- 風險 3：內顯效能 → 30 fps、半解析度，GPU 目標 12 ms（README 規格）。

## 狀態對應（之後步驟 5 細做）
待命＝慢速巡航；思考＝太陽脈動、城市窗燈陸續亮；執行＝加速、桁架燈拉成光條；收尾＝減速、霧變金；等你＝列車靠站停下、維修工出現招手；不在＝夜間模式（人造太陽調暗、全城點燈）。
