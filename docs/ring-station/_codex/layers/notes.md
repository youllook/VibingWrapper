# `target.png` 四層分割

在原圖座標上以 Python 手工描繪窗框曲線、軌道與桁架輪廓、城市天際線，再用 OpenCV 建立遮罩，透過 Pillow 輸出 RGBA PNG。四張圖都採用原圖的 1920 × 1080 畫布與 RGB 像素。

| 檔案 | 保留範圍 | 不透明像素 |
| --- | --- | ---: |
| `L0_frame.png` | 左側車窗框、窗台與座椅一角 | 213,641 |
| `L1_near.png` | 高架軌道、門架、護欄桁架、燈具、維修工和配電箱 | 691,137 |
| `L2_city.png` | 地面建築、樹、河道、圓頂、溫室，以及沿左側牆面往上延伸的城市 | 453,031 |
| `L3_sky.png` | 上方倒掛城市、圓筒拱肋、人造太陽、霧與天空 | 715,791 |

重疊處依 L0、L1、L2、L3 的順序取最前面的可見物件。桁架孔洞保留後方實際看得見的城市像素，遮住的區域保持透明。桁架的動態模糊處沿可辨識的輪廓分配像素。城市與霧氣相接處沿可辨識的建築與樹冠描邊，融入遠處霧氣的區域歸 L3。

逐像素檢查確認每個座標恰好在一層不透明，其餘三層的 alpha 為 0。由 L3 到 L0 疊合後，2,073,600 個像素與 `target.png` 完全一致。
