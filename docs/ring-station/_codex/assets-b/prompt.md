# 任務：環形太空站場景的 5 件物件，Tripo 輸入圖
## 共同規格（給 Tripo 圖生 3D 用的輸入圖）
- 先看 target.png 抓整體風格（象牙白建築、玉綠／海玻璃色玻璃、淡金色日光、日系動畫背景的柔和寫實），但**每張只畫一個物件**。
- 物件完整、不被裁切、置中，佔畫面約 70%；3/4 俯視角（約 30° 俯角、45° 側向）。
- 背景純淺灰（#d8d8d8）平光，無地面、無陰影投射、無其他物件、無文字、無刻度。
- 光線均勻柔和（不要強烈陰影或高光，方便 Tripo 推材質）。
- 1:1 正方形，1024×1024 以上。用圖像生成工具直接生成。
- 存成指定檔名放在目前資料夾；另寫 notes.md 記每張實際 prompt；完成後建立空檔 .done。只動目前資料夾。

## 清單
1. townhouses.png — 一小街區的低層連棟屋：2–3 層、象牙白牆、淡色斜屋頂與平屋頂混合、中間小庭院有樹。
2. tree.png — 一棵圓潤的闊葉樹：樹冠飽滿成團、淡綠到翠綠、樹幹短；整體輪廓簡潔（會大量複製當行道樹）。
3. worker.png — 太空站維修工：白色太空衣、白色頭盔（從背後看看不到臉）、安全吊帶與腰間工具包、一條安全繩掛在腰後；**背影 3/4 後視**，右手往前伸、像正伸進配電箱；雙腳站直分開。全身入鏡。
4. service_panel.png — 打開門的維修配電箱：牆掛式金屬箱、門板往側邊打開、裡面有接線排與管線、頂上一盞小黃燈（目標圖維修工面前那個箱子）。單獨一件。
5. truss_lamp.png — 軌道護欄上的維修燈：一個長方形嵌入式燈具，金屬外框、暖白燈罩（目標圖護欄上一盞盞的那種）。
