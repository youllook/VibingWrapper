# 環形太空站 · 1 拆景 ＋ 2 素材

## 分層標準答案
Codex 照 `target.png` 拆成四張 RGBA（`_codex/layers/L0_frame … L3_sky.png`），佔比：鏡頭層 10%、近景 34%、城市 22%、遠景天空 35%。
擺景驗收（步驟 3）就拿灰模的分層遮罩跟它逐層比，工具在 `themes/ring-station/check.js`（頁內算，不用存圖）：

```
index.html?freeze=1&ids=1 → await (await import('./check.js')).score()      // 逐層 IoU＋像素一致率
                          → (await import('./check.js')).compare()            // 上：我們／中：目標／下：差異
                          → (await import('./check.js')).optimize({...})      // 鏡頭與窗框參數座標下降
```

## 元素 × 做法

| 層 | 元素 | 做法 | 來源 |
|---|---|---|---|
| 鏡頭層 | 車窗框、透視窗台、座椅一角 | 螢幕空間 SDF 遮罩（之後換成有厚度的 3D 窗框） | 程式 |
| 近景 | 高架橋面、兩組軌道與枕木 | 沿圓周的帶狀曲面＋instanced 枕木（一整圈） | 程式 |
| 近景 | 護欄桁架＋維修燈 | 8 m 一節 instanced 一整圈（≈1,550 節） | 程式（燈具不必生成） |
| 近景 | 門形架 | 30 m 一座 instanced | 程式 |
| 近景 | 維修工、配電箱 | 偶發事件，掛在某一節桁架上 | **Tripo** `worker`、`service_panel` |
| 城市 | 圓頂會館、玻璃溫室、圓柱住宅塔、尖塔大樓、階梯住宅、連棟屋 | instancing 鋪滿三條陸地帶，前密後疏 | **Tripo** 6 款 |
| 城市 | 行道樹、樹叢 | instancing | **Tripo** `tree` |
| 城市 | 河道 | 陸地帶上的水面帶 | 程式 |
| 遠景 | 倒掛城市 | 同一批建築（圓筒另一條陸地帶），霧蓋細節 | 同上 |
| 遠景 | 玻璃窗帶＋縱肋、環向拱肋 | 三條窗帶（三陸三窗）＋每 650 m 一圈拱肋 | 程式 |
| 天空 | 人造太陽、霧 | 太陽擺在目標圖位置（氛圍優先，不在軸上）；霧程式 | 程式 |

## 幾何修正紀錄
- 純圓筒時「左上那片」是牆面城市，但目標圖那裡是有肋的玻璃拱 → 改成 O'Neill 式**三陸三窗**，窗帶剛好落在目標圖的拱肋位置。附帶好處：列車每繞一圈會經過三段玻璃橋，下面是星空（之後當偶發事件）。
- 太陽：放在軸上會在畫面最右邊；目標圖在左上 → 世界固定擺位、不隨棲地轉。
