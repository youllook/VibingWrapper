## 近景動態模糊（`post.js`）
鏡頭固定、棲地等速繞軸轉 → 每個像素的運動向量可以精確算：深度還原世界座標 → 繞軸轉「角速度 × 快門 1/45 秒」→ 再投影 → 沿向量取 12 個樣本（起點逐像素錯開，避免小亮點拖成等距白條）。夜裡桁架燈壓暗成暖黃（爆白的燈被模糊拖成白條很突兀，2026-11-28 用戶回饋）。視距 2.5 m 內（車窗框、座椅）不模糊；太陽（不寫深度）不模糊。`?blur=0` 關、`?shutter=` 改快門。

**踩到的管線問題**（已修）：three.js 的材質是「色調映射 → sRGB → 霧」，霧疊在最後。畫進浮點 render target 時 three.js 會跳過前兩步，霧就變成在線性空間混、再被 ACES 壓 → 整片發灰、太陽光暈消失。
修法：把 `tonemapping_fragment`（內嵌同一條 ACES Filmic 公式）與 `colorspace_fragment`（一律 sRGBTransferOETF）都改成在 shader 裡強制做，renderer 本身關掉這兩步 → 直接畫到螢幕或畫進 render target 結果一樣（實測兩者平均亮度相同）。窗帶 shader 的霧也改成在編碼之後才混。
