# 霓虹隧道（neon-tunnel）· 0 分析做法與預期效果

目標圖：`target.jpg`（＝`../infinite-series/s07.png` 轉 JPG，無限系列「先做」那排；2026-11-28 用戶點名開工）。

## 畫面讀出來的東西
- **夜車駕駛座視角**：左下角是方向盤的上緣，下方是一長條暗色的儀表台。兩者都在陰影裡，看不到任何儀表數字。左邊是 A 柱。
- **擋風玻璃**是最近的一層：滿滿的雨珠，幾道斜著往下流的水痕，雨刷停在掃到一半的位置，掃過的地方比較乾淨、帶著水霧。
- **隧道**：圓拱斷面，一圈圈拱肋往前排。左牆上緣有一排橘色燈條，近的大、遠的小。右牆和天花板很暗（右上角留給 HUD）。
- **路面**是濕的：兩線道、白色虛線、兩側護欄上有橘色反光片。燈光在路面拉成一條條縱向的倒影。
- **遠處出口**偏左，透出白光，外面是藍黑色夜空和城市剪影，窗戶亮著冷色的光。整張圖只有這裡是冷色。
- 配色：琥珀色配深炭灰，只有出口一點冷藍。
- 畫面裡**沒有人物**。主角就是「我」，也就是鏡頭本身。

## 無限怎麼成立
- 鏡頭和車內固定不動，**隧道往鏡頭移動**。拱肋、燈、虛線、反光片都照固定間距重複，用同一個行駛距離 `offset` 捲動，接縫天然無限。
- 隧道用程式生成：圓拱斷面沿 Z 拉長，切成幾段循環使用。加上很慢的左右彎道擺動（曲率隨時間飄），讓消失點不要死盯在同一點。
- 出口一直在遠方，像永遠開不到的終點。只有「收尾」時真的開出去（見狀態對應）。

## 分層
| 層 | 內容 | 速度感 |
|---|---|---|
| 近景 | 擋風玻璃上的雨珠、水痕、雨刷；方向盤、儀表台、A 柱 | 雨珠會滑，車內不動 |
| 中景 | 拱肋、牆燈、護欄反光片、濕路面倒影 | 最快，燈一盞盞往後掠過 |
| 遠景 | 往消失點收攏的燈串、隧道的暖色霧 | 慢 |
| 天空 | 出口的白光、城市夜景（一張圖） | 幾乎不動 |

## 做法
1. **擋風玻璃雨**：全螢幕 shader 疊在最上層，經典的「玻璃上的雨」：
   - 雨珠分兩種：靜止的小珠，和會往下滑、拖出水痕的大珠。
   - 每顆雨珠照它的法線去折射後面的畫面（讀上一層的 render target），所以雨珠裡看得到倒過來的橘燈。
   - 雨刷是一條旋轉的遮罩：掃過的地方把雨珠清掉，再慢慢長回來。
   - 估計每幀約 1–2 ms。
2. **濕路面**：不做螢幕空間反射，因為太貴。改用假倒影：
   - 每盞燈在路面下方放一條鏡像的拉長光帶，用加法混色。
   - 路面粗糙度貼圖打斷光帶，讀起來像水漬。
   - 光帶跟著燈一起捲動，看起來就像燈在路上拖出倒影。
3. **燈**：用 instanced 的發光燈條，不掛真的光源。牆面的亮度用 shader 照「離最近那盞燈多遠」來算，所以近燈掠過時，整面牆會跟著一明一暗地閃過去。這個明暗節奏就是速度感的來源。
4. **車內**：儀表台、方向盤、A 柱都在陰影裡，只看得到輪廓和邊緣反光，所以程式建模（幾個簡單的形體）就夠，不用 Tripo。燈掠過時，邊緣反光也跟著閃。
5. **出口**：一張城市夜景圖貼在出口的圓拱裡，加一圈光暈。白天的時候換成白天的城市。

## 素材策略
- **隧道、燈、路面、護欄、車內 → 全部程式生成**。混凝土的質感用素材庫的 ambientCG 貼圖，或用程式做的噪點。
- **出口外的城市 → Codex 生圖**，日夜各一張，寬幅、同畫風。另外也可以直接從目標圖裁出口那塊來當第一版。
- 沒有生物、沒有角色，避開已知的瓶頸。

## 狀態對應（步驟 5 細做）
| 狀態 | 畫面 |
|---|---|
| 待命 | 定速巡航，雨刷間歇擺一下 |
| 思考 | 車放慢，方向燈的橘光一明一暗打在儀表台和 A 柱上（像在等著切車道） |
| 執行 | 加速，燈掠過得很快，雨變大，雨刷連續快掃，燈拉出光軌 |
| 收尾 | 出口迎面放大，衝出隧道：一瞬間開闊，看到城市夜景和雨後的天空，再進下一條隧道 |
| 等你 | 停在隧道裡的緊急停車彎，雙黃燈閃，雨刷停住，雨珠慢慢在玻璃上積起來 |
| 不在 | 熄火停著，隧道燈調暗，只剩幾盞亮著，雨珠緩緩往下滑 |

隧道裡沒有日夜之分，日夜只影響出口外的城市（白天是灰藍的雨天）。

## 預期效果與風險
- 預期：一眼就是「雨夜開在一條隧道裡，橘燈一盞盞從頭頂掠過」，有放空、催眠的感覺。執行的時候明顯變快。
- 風險 1：**擋風玻璃雨的質感**，這是整張圖的靈魂。程式雨珠容易顯得太「程式」，要調到像手繪。必要時用 Codex 生一張雨珠的法線圖或遮罩來混用。
- 風險 2：**燈掠過的節奏**。太規律會像螢幕保護程式。要靠彎道、燈偶爾壞一盞、閃一下這類小變化打破。
- 風險 3：**衝出隧道的那一下**，從封閉切到開闊，出口外要有夠深的空間。第一版先用 2.5D 拆層（夢境之門的做法）處理出口外的城市。

## 已定（2026-11-28）
