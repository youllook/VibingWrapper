## 一、整體做法：擠出紙片的 2.5D 場景

三種做法比較：

| 做法 | 內容 | 優點 | 缺點 |
|---|---|---|---|
| A 純 2D 分層 | Codex 圖去背，一層層平面疊起來做視差 | 最快、最像目標圖 | 沒有厚度和真陰影，一動就看出是貼圖 |
| B 全 3D 建模 | 燈塔、岩石都建真模型 | 光影最真 | 失去紙感，又回到「模型」路線 |
| **C 擠出紙片（推薦）** | 每張去背圖 → 從 alpha 描出輪廓 → `ExtrudeGeometry` 擠出 2–4 mm 厚度；正面貼 Codex 圖，外圈白色刀模邊用程式擴張 alpha 產生，側面是奶油色紙芯 | 有真厚度、真接觸陰影、紙片間有縫；鏡頭微晃就看得出是紙 | 要做「圖 → 輪廓 → 擠出」的共用工具（一次性） |

**鏡頭固定**，只做極小的呼吸晃動（約 0.3°），讓紙的厚度與層間陰影露出來。這是紙感的關鍵，不必轉鏡頭。

**停格**：所有會動的東西都用量化時間 `floor(t*12)/12` 驅動；鏡頭呼吸與景深保持順暢。

## 二、逐元素做法與預期

| 元素 | 做法 | 預期效果 | 把握 |
|---|---|---|---|
| 天空底紙 | 一張大平面，藍色水彩紙紋理＋纖維 | 跟目標圖幾乎一樣 | 高 |
| 雲 | 3–4 層擠出紙雲，緩慢停格平移；陰天換灰紙、往中間聚攏 | 有層次的紙雲，比目標圖更立體 | 高（但見「待決定 1」） |
| 遠山、遠岬 | 2 層擠出剪影，往後越淡 | 同目標圖 | 高 |
| 海 | **一條條橫向波浪紙條**由遠到近排列（約 12–16 條），每條上緣是白色浪花刀模邊；每條上下起伏、左右錯動，停格節奏。近處浪條更高、更彎 | 最能表現「紙浪」，會比目標圖更有手作感；遠海會比目標圖少一點筆觸 | 中高 |
| 拍岸浪花 | 岩石前方的白色紙浪片，定時「啪」一下翻起再落下（換卡 3 張） | 很有停格感 | 高 |
| 岩岸、岬角 | 前、中、後 3–4 層擠出紙片，正面貼 Codex 岩石紋理 | 同目標圖 | 高 |
| 燈塔、小屋、圍籬、樹 | 立起來的卡片（可帶一點摺角，像立體書站起來）；燈塔燈室晚上發光 | 同目標圖；夜晚多出亮點 | 高 |
| 燈塔光束 | 夜晚、暴雨時：半透明紙片光束繞著燈室轉（停格） | 目標圖沒有的亮點 | 中 |
| 帆船 | 遠方水平線上 3–5 艘紙帆船，沿軌道停格滑行、輕搖 | 同目標圖，會動 | 高 |
| 海鷗 | 吊在細線上的卡片，像鐘擺一樣晃；翅膀兩張卡交替 | 細線是紙模型的招牌，很討喜 | 高 |
| 企鵝（卡片角色） | 一個角色多張卡：坐著、甩竿、收線、釣到魚、揮手；換卡做動作、翻卡轉身 | 角色個性的來源 | 中（多張卡畫風要一致） |
| 浮標與漣漪 | 紅白浮標上下點；漣漪是一圈圈擴大的紙環 | 細節加分 | 高 |
| 雨（暴雨時） | InstancedMesh 紙雨滴，部分吊線；12 fps 落下 | 同《紙信》的味道 | 高 |
| 紙彩虹（收尾） | 一片片彩色紙條依序彈起成拱 | 收尾的記憶點 | 高 |
| 景深 | 後製 pass：前景岩石、近浪糊，中景燈塔與企鵝清楚 | 像拍真的模型 | 中（效能） |
| 紙張質感 | 全畫面纖維＋印刷顆粒疊加，霧面 | 統一紙感 | 高 |

**整體預期**：靜態畫面能做到目標圖的八成五上下；多出來的是會動的紙浪、吊線海鷗和停格節奏，動起來會比靜態目標圖更有手作感。

## 三、風險與對策

1. **素材畫風不一致**：分開請 Codex 產的物件色調、筆觸會飄。
   → 優先從目標圖直接扣；被擋住或太碎的送回 Codex，**附原圖要求補完整**（步驟 2 新規則）。
2. **白邊重複**：Codex 圖本身已經畫了白邊，程式再加一圈會變兩圈。
   → 扣圖時要求「不要白邊」，白邊一律由程式產生，寬度才會統一。
3. **右上角 HUD 被擋**：目標圖右上有燈塔頂和海鷗。
   → 構圖微調：燈塔下移約 8%，海鷗不進右上角 20%。
4. **效能**（Intel 內顯，目標 12 ms，流程放寬上限 36 ms）：陰影與景深最貴。
   → 陰影只在 12 fps 換格時重算，平常沿用；半解析度；景深用便宜的兩層模糊。
5. **企鵝多張卡**：動作卡多，最容易破功。
   → 先定一張基準卡，其他卡都附基準卡給 Codex，一次產一組。

## 四、用戶決定（2026-10-30）

1. **海鷗、帆船獨立拆**：各自是一組素材，不跟天空、建物混在一起。
2. **有日夜**：白天如目標圖；夜晚加紙月亮、星星、燈塔光束、窗戶亮燈。
3. **海浪分層、要交錯**：浪條和岩石、礁石前後穿插（浪在礁石前、後都有），交錯感比單純由遠到近排更好。
4. **前景植物、石頭細拆**：前景的草、小花、石塊各自一片，不要整塊。
5. **礁石不動、獨立拆**：海中礁石是靜態，但獨立成片，好讓浪條穿插。
6. **企鵝釣魚動畫由賈維斯發揮**。

沿用建議、用戶未另外指示：雲用紙片物件（這個主題不套「雲霧一律程式密度場」）；5 個 session＝水平線上的紙帆船。

- 中近景：近海浪條、拍岸浪花、浮標
- 中景：岬角岩壁、燈塔、小屋、圍籬、樹、海鷗
- 遠景：遠海、帆船、遠山遠岬、雲、天空

**素材家族（步驟 2，子代理按家族分工；2026-10-30 依用戶決定調整）**：
1. **紙片工具 lib**（主線先做）：圖 → 輪廓 → 擠出、白邊、紙芯、紙紋、12 fps 時鐘、景深、日夜色調
2. **海**：分層浪條（程式產生形狀＋紙紋，要能插在礁石前後）、拍岸浪花三張卡、漣漪、浮標

## 七、企鵝釣魚動畫（賈維斯提案，關鍵幀說明時再細化）

一張卡＝一個姿勢，換卡不補間，偶爾整張卡「翻面」轉身。
- **待命**：坐著拿竿，每隔幾秒點一下頭（2 張卡交替）；偶發：打呵欠、伸手進魚桶拿小魚吃、浮標一沉→看一眼→沒事又放鬆。
- **思考中**：抬頭看天上聚攏的雲（換一張「仰頭」卡）。
- **執行中**：浮標猛沉 → 站起來（站姿卡）→ 拉竿身體後仰（3 張卡循環、竿子彎曲程度跟著換）→ 被拖得往前滑一小步 → 高潮：一條比自己大的紙魚破浪飛出、停在半空（停住約 1.5 秒）→ 抱著魚跌坐。
- **收尾**：把魚放進桶、拍拍肚子。
- **等你**：翻卡轉身面向鏡頭，舉起「？」小牌子揮動；久等升級：牌子換成「…」、開始打瞌睡。
- **夜晚**：戴上小頭燈，其餘一樣。
