# 任務：分層補完＋出血（讓鏡頭可以微晃）

`in/` 裡是一張紙片模型風格海邊燈塔桌布（`target.png`，1672×941）切出來的 7 張 RGBA 分層，彼此互斥、像素對齊：
- `far.png` 遠景：天空、雲、遠山遠岬、遠海
- `boats.png` 帆船、`gulls.png` 海鷗（含吊線）——獨立物件
- `mid.png` 中景：岬角岩壁、燈塔、小屋、圍籬、樹、草坡
- `reefs.png` 海中礁石
- `near.png` 中近景：近海、浪花、浮標與漣漪
- `fg.png` 前景：左下右下石頭、植物、企鵝坐的岩台、企鵝、魚桶

這些層會在 3D 裡前後擺放、鏡頭微微晃動。現在每層只有「看得到」的像素，被前面擋住的地方是空的，一晃就露出黑洞（見 `in/露洞示意.png`）。

## 要做的事

產出到 `out/`，同樣 7 個檔名，每張都是 **1872×1053**（四邊各出血：左右 100px、上下 56px），原本 1672×941 的內容放在 **(100, 56)** 位置。

1. **原本看得到的像素一個都不能改**：在 (100,56) 那個範圍裡，原圖 alpha>0 的像素必須與輸入完全相同（最後用程式把原層貼回最上面保證這點）。
2. **補完被擋住的部分**，就像前面的層不存在一樣，畫風、紙紋、光線、色調與原圖一致：
   - `far.png`：整張 1872×1053 **完全不透明**。燈塔、岬角、帆船、海鷗後面補成天空／雲／遠山；遠海往下一直延伸到底（近海、岩石擋住的地方都補成遠海）。
   - `near.png`：從原本上緣（海平線附近那條切線）**往上多補 20px** 遠海，往下到底、左右到邊**完全不透明**；企鵝岩台、前景石頭、礁石後面都補成海浪（延續周圍的浪與浪花）。
   - `mid.png`：岬角岩壁往下延伸到海面以下約 60px（被近海、前景石頭、企鵝岩台擋住的部分補成岩壁），往右、往上出血處延續樹與草坡；燈塔、小屋要完整。
   - `reefs.png`：每顆礁石底部往下補約 15px（埋進水裡的部分）。
   - `fg.png`：石頭、植物往畫面外（左、右、下）出血延伸；企鵝、魚桶不動。
   - `boats.png`、`gulls.png`：只換到大畫布（物件已完整，海鷗吊線往上延伸到畫布頂）。
3. 補的方法你決定（內建圖像生成／編輯、程式化填補、或混用）；生成的圖若對不準，就只取需要補的區域，再把原像素貼回最上層。補的邊界不要有接縫、不要模糊一塊。
