# 紙片場景（paper-popup-stopmotion）

2026-10-30 收錄。靈感來自 Threads 上 jaschiang 的《紙信》（用 Claude Code、Codex、Three.js 做的紙片立體書短片）。
**只拿風格，不照做**：不用郵差女孩、紅屋、拱橋、小溪這組構圖和角色。

和素材庫裡既有的 `paper-craft` 不一樣：那張是素雅和紙、低彩度、靜態；這張是**飽和繪本色＋白色刀模邊＋有厚度的紙板＋停格動畫**。

## 風格要素（可以帶走的）
- **白色刀模邊**：每個物件外圈一道白紙邊，像貼紙、刀模，邊緣微微不規則。
- **紙板厚度**：平面輪廓擠出成有厚度的薄片，側面露出淺色紙芯；不做圓滑的 3D。
- **角色＝整張卡**：用換卡片做動作、翻卡片轉身，不做骨架。
- **不要書（2026-10-30 用戶定）**：畫面只有紙片場景本身、佔滿全畫面，不出現書、書頁、翻開。物件仍可用摺疊關節彈起、倒下、從地面「站起來」。
- **特效也是紙**：雨、閃電、彩虹、雲全是剪紙片（大量雨滴用 InstancedMesh）。
- **停格節奏**：特效和角色用每秒 12 格抽格；鏡頭和景深可以順，物件抖一下才有手作感。
- **景深**：GLSL 淺景深，前景、遠景糊，中景清楚，像在拍真的模型。
- **用色**：飽和繪本色（草綠、天藍、磚紅、奶油黃）；陰天時整體壓成灰藍；描邊用深褐，不用黑。
- **質感**：紙張纖維加一點印刷顆粒；接觸陰影軟，紙片之間有空隙陰影。

## 套到桌布狀態（構想，還沒定）
- 不在 → 場景物件一片片倒平
- 待命 → 物件彈起站好，輕微停格晃動
- 思考 → 紙雲聚攏、紙雨開始落
- 執行 → 卡片角色換卡做事
- 收尾 → 紙彩虹彈起
- 等你 → 某個物件「啪」一聲彈起來招手

## 技術對應
Three.js：SVG 或 Codex 圖 → 加白邊 → ExtrudeGeometry 擠出厚度；摺頁用 pivot group 當轉軸；
特效用時間量化 `floor(t*12)/12` 做出每秒 12 格；景深做成後製 pass。素材先請 Codex 產設定圖，統一畫風。
