# 紙片燈塔 — 02 紙片工具（`themes/paper-lighthouse/lib/paper.js`，2026-10-30）

素材家族 1：主線先做的共用工具，後面海、礁石、角色、天空各家族都用它。

## 提供什麼

| 功能 | API | 做法 |
|---|---|---|
| 紙片厚度 | `createPaperLayer(img, { d, thick, side, blur })` | 不建幾何：shader 在透明處往「遠離鏡頭軸」方向找背面，找到就畫紙芯側面（越深越暗）。鏡頭一晃，側面跟著變寬變窄，像真的紙板 |
| 層間陰影 | `createShadow(img, { d, gap, strength, blur, dir })` | 剪影模糊、偏移，放在紙片後面一點 |
| 景深 | `blur`（px） | 每層只有一個深度，模糊直接烘在貼圖上，執行時零成本 |
| 停格 | `stepTime(t, 12)`、`boil(seed, t)` | 時間量化到每秒 12 格；手作抖動每格換一個值 |
| 紙紋、顆粒 | `createPost` 的 `uFiber`、`uGrain` | 後製：拉長雜訊當紙纖維（固定），顆粒每 1/12 秒換一次 |
| 日夜 | `uNight`（後製）、`uTint`（每層） | 夜晚壓暗、偏藍、降飽和；燈光（燈塔、窗戶、月亮）步驟 5 再加 |
| 鏡頭換算 | `updateLayers(layers, camera)` | 每格把鏡頭位置換算到各層，厚度才會跟著晃 |

色彩全程用 sRGB 原值直通（不做色彩空間轉換），`mode=flat&set=layers` 拼回去仍是 100%（原始扣圖 2026-10-30 已移出 repo，見 02-海浪分層.md）。

## 預設值與量測

擺景頁預設：厚度 `0.004`（畫面邊緣約 3px 紙芯）、陰影 0.6、紙紋 0.06、顆粒 0.025、渲染解析度 1、鏡頭呼吸 ±0.06／±0.03。

| 設定（鏡頭不動） | 相似度 | ΔE |
|---|---|---|
| 補完分層、純貼圖 | 98.6% | 0.53 |
| 只加厚度 | 98.1% | 0.66 |
| 只加陰影 | 98.4% | 0.81 |
| 只加景深（前景 1.5px、遠景 0.6px） | 97.6% | 1.07 |
| **預設（厚度＋陰影＋紙紋顆粒，不加景深）** | **97.1%** | 1.67 |

- **景深預設不加在靜態層**：目標圖本身已經畫好前景糊、中景清楚，再加會雙重模糊、掉最多分。`blur` 留給之後新加的會動物件，讓它們跟所在層一樣糊。
- 效能（Intel 內顯、1920×1080、`LOWPOWER=1 PERF=1`）：解析度 1 約 **14 ms／格**、0.75 約 12 ms。在流程放寬的 36 ms 內，接近 12 ms 目標；先用解析度 1 保畫質。

## 發現

- 鏡頭偏移加大到 `cam=0.25,0.12`（約正常呼吸的 4 倍）時，**企鵝後方露出藍色**：中景岬角只往下補，沒補被企鵝岩台擋住的部分。正常呼吸幅度下幾乎看不到；之後送回 Codex 補 `mid.png` 企鵝後方那塊。
- 白邊：沿用 Codex 畫好的白邊，程式不加（見 03 第一次的結論）。
