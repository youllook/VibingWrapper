# 紙片燈塔 — 02 海鷗帆船（2026-10-30）

素材家族 6（海鷗）＋ 7（帆船）。模組 `themes/paper-lighthouse/lib/flyers.js`，開發頁 `flyers-dev.html`（index.html 上午版複製，整張 gulls／boats 換成模組）。

## 做法

1. **海鷗拆卡**：`gulls.png` 連通區塊 → 3 隻，藍色吊線像素拿掉（`b − r > 40`），留最大塊 → `assets/gulls/gull{0,1,2}_a.png`。
   吊點 = 吊線那一欄卡片最上緣往下 2px，記在 `gulls.json`（`hook`，1872 出血畫布座標）。
2. **翅膀上揚卡** `gull*_b.png`：派 Codex，它沒有生圖、而是寫位移場把翅膀往上推（[tools/gull_wings_codex.py](tools/gull_wings_codex.py)），身體像素原樣保留。
   gull1、gull2 可用；gull0 的前翼被推出畫布上緣、撕裂 → 改成**兩翼各自繞肩膀轉**（前翼 +30°、後翼 −7°，肩膀附近留原圖墊底補縫，[tools/gull0_wings.py](tools/gull0_wings.py)），
   畫布往上多 25px（`gulls.json` 的 `by`）。Codex 在 gull0 之後額度用完（11:42 恢復），沒能重畫。
3. **海鷗動態**：每隻一個 group，軸在吊線頂端（畫面上緣外，畫布 y = −10）；卡、影子、吊線都在 group 裡一起擺。
   - 鐘擺：擺幅 1.6／2.2／1.2°、週期 3.3／2.7／4.1 秒，停格 12 fps；t=0 在正中。
   - 拍翅：每 6 秒一輪，一陣 1.0–1.6 秒（`boil` 決定每輪長度）每 3 格換一次卡，其餘滑翔（原卡）；三隻錯開。
   - 吊線：程式畫的細長平面（1.3 目標圖 px、`#eef5fb`、不透明度 0.8，比原圖的藍線淡，接近目標圖的白線），放在卡片後 0.05，背上那端被鳥蓋住。
   - 深度：27／28／25（原本同一層 26），各自視差。最右那隻（HUD 附近）擺幅最小，不會比原位更往右上。
4. **帆船**：原 4 艘裁成 `boat0–3.png`；第 5 艘 Codex 畫（米白主帆＋淡藍前帆、深藍船身，自帶白刀模邊），縮到 60px 高、烘 0.8px 模糊＋14% 遠景霧 → `boat4.png`，放在 (850, 底 482)。
   - 深度 50／54／55／57／53（遠海 60 與岬角 30 之間），右邊被岬角擋住是對的。
   - 滑行：3–5 目標圖 px/秒、方向各異，繞出血畫布外一圈（出去另一邊進來）；t=0 在原位。
   - 輕搖：以船底中央為軸 1.4–2.2°、週期 2.8–4.2 秒，加 0.5px 起伏。
   - `setBoats(n)`：0–5 艘，第 k 艘 = 第 k 個 session。多的從**最近的一側**滑入、少的往最近一側滑出，3.2 秒 smoothstep；滑到一半反向會從目前位置接著走。
5. **renderOrder**：模組自己依深度插進場景既有紙片之間（找比自己遠的最大 renderOrder +0.1），場景子物件數變了會重排，不管 index.html 先建後建。
6. **紙片厚度**：卡在 group 裡，`updateLayers` 用的區域座標會錯 → `update(t)` 自己用世界座標算 `uCam`；日夜色調用 `update(t, tint)` 傳。
   所以**不要**把 `flyers.papers` 丟進 `updateLayers`。
7. **遠景補洞**（[tools/farfix.py](tools/farfix.py)）：原 `far.png` 在海鷗、吊線、帆船底下的補圖其實有鬼影（帆形、海鷗形的白邊與異色塊、海鷗烘進去的影子），滑開／換卡會露出來 → 重補：
   - 帆船水平線以下：同列水平平移鄰近乾淨區塊，色差用外圈差值 inpaint 進來（水平線對得上）；水平線以上：inpaint 低頻＋鄰近紙紋高頻（只在水平線以上找邊界，海的藍不滲上去）。
   - 海鷗本體＋影子：能平移就平移，不行就 inpaint＋紙紋；吊線：細 inpaint。
   - 原檔備份在 `E:\tmp\paper-scene\flyers\far_orig.png`。

## 整合到 index.html

```js
import { createFlyers } from './lib/flyers.js';
// LAYER_DEFS 拿掉 gulls、boats 兩行（或在 items() 過濾掉）
// build() 結尾（其他層都建完之後）：
flyers = await createFlyers(scene, { loadImg, camera, boats: 5, shadow: SHADOW, thick: 0.004 * THICK });
// render()：updateLayers 之後
flyers?.update(ANIM ? t : 0);           // 夜晚：flyers.update(t, tint)
// session 數變了：flyers.setBoats(n)
```

## 已知問題

- 翅膀上揚卡不是 Codex 重畫的，是變形／旋轉：gull0 肩膀接縫在 1x 下 1–2px 看得到一點；之後 Codex 額度恢復可以重畫三張。
- 中間那隻海鷗在雲上，遠景補的雲裡有一小段被平移來的雲邊，平常被鳥蓋住，拍翅換卡時露一點。
- 第 5 艘是 Codex 新畫的，比原 4 艘清楚、飽和（已烘糊＋霧），並排細看仍略新。
- 帆船一直往同方向滑，久了會跟彼此或岬角重疊（不同深度，會正確遮擋）；滑出畫面再從另一邊進來，進出那一刻被出血擋住看不到。
- 帆的狀態變化（00-分析家族 7）還沒做。
