# 任務：生成 3 張桌布構圖概念圖（美式健力健身房）

用你內建的圖像生成工具，生成 3 張 16:9 橫幅（約 1672×941）概念圖，存成本資料夾的 gym1.png、gym2.png、gym3.png。全部完成後建立空檔 `.done`。

## 共同設定（三張都要）
- 場景：老派美式地下健力（powerlifting）健身房。紅磚牆、鐵皮／木樑天花板、高處的長條窗，傍晚夕陽從窗斜射進來，光束裡飄著鎂粉與灰塵（明顯的體積光）。
- 鎢絲燈泡的暖黃光、牆上一個紅色霓虹招牌寫「NO PAIN NO GAIN」。慢轉的老吊扇。
- 地上是黑色橡膠地墊＋木質舉重台，槓片堆、深蹲架、貼滿膠帶的長凳、一面略有裂痕的大鏡子。
- 後牆：一張健力比賽海報（只要看得出是比賽海報，文字可簡短如 "POWERLIFTING MEET"），旁邊一塊白板寫著幾行訓練紀錄與「正」字計數。
- 比賽台角落有三盞裁判燈（三個圓燈並排）。
- 主角：一位壯碩的健力選手（男性，穿舉重背心或無袖上衣、護腕護膝、腰帶），正在拼命舉重，臉部用力、手上有鎂粉。不要露出可辨識的真實人物或品牌 logo。
- 質感：寫實偏電影感，舊、髒、有使用痕跡，不要太新太亮；適合當桌面桌布，畫面左上與右上留一些較暗、較單純的區域讓桌面圖示可讀。

## 三張的差異（構圖）
1. gym1：側面 3/4 中景。選手在深蹲架下做重深蹲（槓上片很多、槓微彎），夕陽光束從後方高窗打成逆光輪廓，霓虹與白板在背景。
2. gym2：鏡子視角。從選手背後看向大鏡子，鏡中映出他硬舉拉起的正面用力表情，鏡框邊緣看得到裁判燈與比賽海報。
3. gym3：低角度廣角。選手躺在長凳上臥推，鏡頭從地面槓片堆旁往上拍，強調槓鈴與槓片的重量感，天花板吊扇與體積光在上方。
