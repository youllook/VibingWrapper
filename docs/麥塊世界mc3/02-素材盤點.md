## 派工：按素材家族分，不按景分

同一種素材（浮島、紫頌）跨好幾層，按景分會四個人各寫一份浮島。改成按家族分，每人只碰自己的檔，平行不打架：

| 子代理 | 檔案 | 交付項目（items 名稱） |
|---|---|---|
| A 苦力怕 | `assets/creeper.js` | `hero`（主角，回頭姿勢）、`walker`（隊伍用，正常姿勢）、`row`（6 隻排一列看比例） |
| B 地形 | `assets/terrain.js` | `foreCliff`（近景平台）、`bridge`（窄橋＋缺口）、`islandSmall`（橋尾小圓島）、`islandBig`（中景大島）、`islandMid`（中景下層中型島） |
| C 植物與柱 | `assets/flora.js` | `chorusS` / `chorusM` / `chorusL`（三種高度）、`pillarS` / `pillarL`（黑曜石柱）、`grove`（一小片林看密度） |
| D 遠景 | `assets/far.js` | `farIslands`（遠島群一整片）、`voidBackdrop`（背景漸層球／面） |

## 共同規格（所有子代理都要守）

- **單位**：1 = 1 方塊。苦力怕照原版比例：頭 8×8×8 像素、身 8×12×4、腳 4×6×4 ×4，1 像素 = 1/16 方塊，總高 1.625。
- **座標**：y 向上；苦力怕臉朝 +Z。原點：角色＝腳底中心；浮島＝頂面中心（頂面 y=0，底往負）；植物、柱子＝底部中心。
- **只用 `lib/voxel.js` 生方塊**：靜態用 `Voxels.set()` + `merged()`（自動剔除相鄰面），會動的部件用 `instanced()` 或各自一個 merged mesh 掛在 Group 的樞紐上。遠處可用 `merged({ scale: 2 })` 粗方塊省面。
- **顏色只用 `lib/palette.js`**（可在同色系內微調明暗做斑駁，例如末地石每格隨機 ±6% 亮度）。這階段是**固有色＋平光**，不做貼圖、霧、發光、陰影——那是階段 4、5。
- **材質槽**：每個 mesh `merged({ slot })` 標上 `endstone` / `obsidian` / `chorusStem` / `chorusFlower` / `creeper` / `creeperFace` / `void` 之一，階段 4 依槽換材質。會發光的（紫頌花、柱頂光點）**獨立成一個 mesh** 標 `chorusFlower` 或 `obsidianGlow`。
- **浮島介面**（B 產出，C 會用）：浮島 Group 的 `userData.surface` = 頂面可放東西的格子陣列 `[[x, y, z], …]`（局部座標，y 是該格上表面高度）。C 的 `grove` 先自己做一塊平地測試，不要 import terrain.js。
- **亂數用 `rng(seed)`**，同參數同結果（要能重現）。
- **匯出形式**：`export const items = { 名稱: { build: () => Object3D, note: '一句話' } }`；另匯出產生器函式（例 `export function makeIsland(opts)`、`export function makeCreeper(opts)`）供階段 3 組場景用，參數寫 JSDoc 一行。
- **預算**（三角形，`countTris`）：苦力怕每隻 ≤ 3k（主角 ≤ 6k）；foreCliff ≤ 30k；bridge ≤ 15k；islandBig ≤ 60k（不含植物）；每株紫頌 ≤ 1.5k；遠景全部 ≤ 60k；build 時間每項 ≤ 200 ms。
- **只改自己的檔**。不要動 `lib/`、`assets.html`、別人的 assets 檔；需要共用改動就寫在回報裡。

## 驗收方法（子代理自己做）

```bash
npx electron "docs/麥塊世界mc3/tools/shot.js" "creeper-end/assets.html?m=<模組>&grid=1" E:/tmp/mc3/<模組>.png 1280 720
```

- 加 `&i=<項目>` 看單一項；`&yaw=…&pitch=…` 換角度（度）。左上角會印尺寸、三角形數、build 毫秒。
- 用 Read 看截圖，對照 mc3.png 的形狀、比例、輪廓；至少拍兩個角度。
- 交付：截圖存 `docs/麥塊世界mc3/02-素材/<模組>-*.png`，並在 `docs/麥塊世界mc3/02-素材/<模組>.md` 寫：做了什麼、產生器參數、三角形數、和目標圖還差什麼。
