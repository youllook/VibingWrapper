## Codex 扣圖（2026-10-29，分層的標準答案）

用戶請 Codex 依前景／中近景／中景／遠景把目標圖扣成四張 RGBA（[01-拆景/](01-拆景/) `codex-*.png`）；跨層的東西歸最前面那層。
和上表的差別：上方中央那座島歸**中景**（上表當遠景）、橋尾小圓島歸**中景**、右下角深處的島歸**遠景**。以 Codex 扣圖為準。

核對工具 `tools/layercheck.py`：四張疊成答案分層圖，先**去雜訊**（遮罩開／閉運算去碎點補洞）、**去背**（遠景層剔除沒紋理的天空，只比物件），再和灰模 `?layers=1` 截圖逐層算 IoU，輸出差異圖。

```bash
python -I docs/麥塊世界mc3/tools/layercheck.py <灰模分層.png> docs/麥塊世界mc3/01-拆景 <差異圖.png> [遠景去背遮罩.png]
```

## 光與色（階段 4、5 才做，先記下來）

- 主光：低角度金色側光，從左上方來（主角左臉、橋與台地上緣亮）。
- 環境：紫色虛空的冷紫補光；島底有違反物理的柔光（prompt 有寫，可做）。
- 霧：越遠越紫、越亮（上緣偏粉紫 #a9839e、下方深紫 #604e7a）。
- 光點：紫頌花與柱頂的粉紫自發光（會 bloom）。

## 會動的（階段 5）

紫霧密度、島底光、漂浮粒子、隊列腳步、主角回頭角度。鏡頭與島不動。
AI 五態對照（概念稿）：待命＝全隊站定；思考＝主角轉頭、隊列由近到遠亮綠輪廓；執行＝原地踏步、光點沿橋流；收尾＝依序停步；等你＝主角回望閃白。
