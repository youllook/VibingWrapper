# 沙蟲 — 03 場景擺放（2026-10-30）

Godot：`godot/sandworm2/main.gd`　素材：[02-素材盤點.md](02-素材盤點.md)　標準答案：[01-拆景/](01-拆景/) 四層扣圖

## 怎麼擺

全部照目標圖的像素反推（`main.gd` 的 `ground_at(px)`：像素射線打到沙面；`at_px(px, dist)`：像素射線上某個距離的點）。

| 項目 | 依據 | 值 |
|---|---|---|
| 鏡頭 | 遠景圖地平線在第 545 列 → 仰角讓水平視線落在那一列 | 高 25 m（站在岩階上俯看平原）、垂直 FOV 50°、仰 4.2° |
| 遠景 | `sky/backdrop.tscn` 掛在鏡頭下 | 15 km 外填滿視錐 |
| 沙蟲 | 嘴中心對準像素 (1000, 318)、離鏡頭 252 m | 縮放 2、口緣 0.8、彎度 0.1，轉向讓嘴正對鏡頭；火山口與塵在它腳下 |
| 塵 | 目標圖塵團從 x 330 一路到 1340 | 主塵團往左偏 45 m（半徑 100、高 120），左邊再一團低的（半徑 90、高 80） |
| 岩柱 | 12 根，依「底部像素＋頂端列」換算高度 | 表 `SPIRES` |
| 塵捲風 | 3 道，依底部像素＋頂端列 | 表 `DEVILS` |
| 石拱、岩階、右下岩塊、底邊碎石 | 掃參數對近景 IoU | 表 `TUNE`，可在命令列覆寫（`arch_z=-40` …） |

## 核對

```bash
FRAMES=30 godot/sandworm2/tools/shot.sh out.png layers=1
python -I docs/沙蟲/tools/layercheck.py out.png docs/沙蟲/01-拆景 diff.png
docs/沙蟲/tools/sweep.sh "arch_z=-40 arch_h=70" "arch_z=-46 …"   # 一次比多組
```

塵與塵捲風在 `gray=1`／`layers=1` 下保留柔邊、只換成單色（`look_flat`），不會變成整片方塊。

## 目前 IoU（2026-10-30）

| 層 | IoU | 差在哪 |
|---|---|---|
| 近景 | 0.78 | 石拱內緣輪廓與目標圖的手繪岩形不完全一樣；右下岩塊偏小 |
| 中近景 | 0.57 | 塵團下緣與沙丘的交界、塵捲風位置 |
| 中景 | 0.63 | 目標圖沙蟲是一整個大圓頂（頭＋往右後彎的粗身體＋塵），Tripo 沙蟲身體細、直立 |
| 遠景 | 0.46 | 中景塵團邊緣半透明，被判成遠景／中景的都有 |

中景的差距主要來自沙蟲模型本身的體型（身體比目標圖細很多），擺位調不出來，要嘛接受、要嘛像石拱一樣重生沙蟲。

## 修正紀錄

- 遠景看板原本把深度釘在 `w * 0.999999`：Godot 4 是反向 Z，那是**近**平面，正常模式整張遠景蓋住所有東西。改成不釘深度，靠 15 km 的距離排在最後。
- 沙塵改重力＋顆粒感（用戶 2026-10-30：「看起來比較像煙」），由沙與塵家族重做中。
