# B 沙蟲 `worm/` — 交件（2026-10-30）

## 檔案

| 檔 | 內容 |
|---|---|
| `godot/sandworm2/worm/worm.tscn` | 成品。只有一個 root（`worm.gd`），執行時才把模型、牙圈、喉洞、口緣刺長出來（`@tool`，編輯器裡也看得到） |
| `worm/worm.gd` | root 腳本：instance `models/src/sandworm_rigged.glb`、擺骨（bend／lip／sink／yaw）、`maw()` |
| `worm/maw.gd` | 程式產生的嘴：粉紅肉環、5 圈牙（MultiMesh）、梯田狀漏斗、吸光黑喉、口緣內側小刺；並修掉 Tripo 口緣伸進嘴裡的肉片 |
| `worm/preview.tscn`／`preview.gd` | 預覽：沙色地板＋自帶暖色側光，鏡頭正對嘴 |

原始 GLB **沒有改**、沒有另存：三角形數本來就在預算內，所以不進 Blender 減面；顏色貼圖照 GLB 原樣。

## 尺寸（公尺，`bend = 0`、`lip = 0`）

- 原點：沙面線（y = 0）上、身體中心。`sink = 0` 時脊椎露出沙面約 **119 m**（脊椎底端在 y ≈ −2），口緣頂端到 y ≈ 140。
- 身體直徑約 24 m；口緣靜止時左右展開約 50 m 寬，`lip = 0.8` 時約 70 m 寬。
- 嘴：粉紅肉環外徑約 **19 m**（半徑 9.4），黑喉洞半徑約 **4 m**（與目標圖一樣約占肉環直徑 43%）。
- 嘴心（靜止）在 worm 座標約 (0.2, 107.5, −6.0)。靜止時嘴朝 +Z 但往上仰約 47°；**`bend ≈ 0.1` 時嘴剛好水平朝 +Z**。

要放大縮小直接縮放 worm 節點（統一縮放，牙圈、喉洞跟著走）。

## 可調參數（root 的 export）

| 參數 | 意思 | 範圍（export） | 實用值 |
|---|---|---|---|
| `bend` | 上段脊椎（spine_04 → head）每根骨繞本地 X 的彎度（弧度）；＋把頭往 +Z（鏡頭）壓 | −0.3 … 0.5 | 0 = 抬頭朝天；**0.1 = 嘴正對 +Z**；0.15–0.2 = 低頭俯衝 |
| `lip` | 四片口緣張開角（弧度）；＋張開、−合攏 | −0.6 … 1.3 | **−0.6 = 合攏成花苞**；0 = 半開；**0.8 = 十字大張（目標圖）**；1.0 = 最大，再大會翻過頭 |
| `sink` | 整隻往沙裡沉的公尺數 | 0 … 160 | 0 = 全露；約 145 起整隻沒入 |
| `yaw` | 繞 +Y 的弧度（0 = 嘴朝 +Z） | −π … π | 鏡頭在 +Z 方向就用 0 |

- `lip` 的鉸鏈不是骨頭本地 X，而是每片口緣根部的「嘴緣切線」（lip_front 的本地 X 是直的，繞它轉會往旁邊甩）。＋一律是尖端往外、往後翻。
- `lip < −0.3` 時口緣內刺自動隱藏（合攏時刺會從口緣背面穿出來）。
- `maw()` 回傳 `Maw` 節點：它的 global transform 就是嘴的座標系（原點 = 嘴心，+Z = 嘴朝外）。主線要「讓嘴正對鏡頭」或擺沙瀑、塵的發射點都用它。

## 嘴怎麼做的（maw.gd）

- 嘴座標系：由四根口緣骨的靜止位置算（左右定 X、上下定傾角），掛在 `head` 骨的 BoneAttachment3D 下，跟著 bend／sink／yaw 走。
- 5 圈牙：半徑 7.2 → 4.5 m、深 0.5 → 6.5 m，每圈 24 → 16 顆，一圈比一圈小、往深處收；每顆是彎錐（往嘴外傾、尖端往喉嚨勾），基部粉褐 → 尖端象牙白。
- 漏斗：梯田狀，每圈牙坐在一道牙齦肉稜上；顏色由粉紅 → 暗紅 → 黑。最裡面一個 unshaded 純黑錐＝喉洞，任何打光都是黑的。深 16 m（再深會從後腦穿出去）。
- 肉環：嘴緣一圈凹凸、有細肋的粉紅肉環。
- 口緣內刺：從四片口緣網格挑「面向嘴外、朝向嘴軸」的頂點，每片最多 70 根小彎刺，各自掛在自己的口緣骨上。
- 修模：Tripo 的口緣網格有一大片肉伸進嘴裡，口緣一張開就整片翻過來蓋住喉洞；執行時把靜止姿勢下落在嘴筒（半徑 9 m）內的口緣三角形刪掉（只動記憶體裡的 mesh，GLB 不改）。原本的 `worm_throat` 網格也藏起來（被程式漏斗取代）。

## 三角形數

全部合計 **約 67.7k**（預算 80k）：身體 30k、四片口緣 ≈ 13k（修掉一些）、牙 100 顆 × 60、口緣刺 ≈ 280 × 30、漏斗＋肉環＋牙齦 ≈ 7.5k。

## 已知問題

- 修掉口緣內片後，口緣根部靠嘴的地方有幾處破邊（正面看在肉環左下、右下），遠景看不出來；要更乾淨得在 Blender 裡重拓那一圈。
- Tripo 身體比例偏細長：目標圖的頭（含口緣）約畫寬 33%、身體跟頭差不多粗，這隻身體只有口緣張開寬度的 1/3。主線可以靠縮放／鏡頭距離湊，粗細比例沒動。
- 上口緣（lip_back）張很大時會翻到頭頂後面，正面看十字的上臂比較短。
- 牙與肉環是程式材質（頂點色），沒有貼圖細節；中景距離夠用，近拍會顯得乾淨。
- `bend` 繞的是每根脊椎骨的本地 X（Tripo 骨的 roll 不完全一致），大角度時頭會帶一點側偏。
