# 沙蟲 — 04 貼圖、材質、環境光（2026-10-30）

Godot：`godot/sandworm2/main.gd` 的 `_light()` 與表 `LIGHT`（每個數值都能在命令列覆寫，例如 `amb_e=0.3`）

## 環境光

| 項目 | 做法 | 為什麼 |
|---|---|---|
| 主光（太陽） | 平行光，從右前方低角度（`SUN_TO`，對準遠景圖裡的太陽），暖橘，陰影開但透明度 0.45 | 逆光：朝鏡頭的面多半在自己的影子裡；空氣裡全是塵，長影子要淡 |
| 補光 | 平行光，從鏡頭這側的上方往下打，弱、暖 | 天空與亮沙的反光，讓岩階頂面、沙丘正面讀得出來 |
| 拱口反光 | 點光掛在拱口後方 | 拱外亮沙照亮石拱內緣 |
| 環境色 | 低強度暖橘 | 暗部不要死黑，也不要灰 |
| 霧 | 深度霧，60 m 起、1600 m 滿、最多 0.85，暖橘 | 目標圖遠處岩柱與地平線被塵霧吃掉；沙丘自帶的地平線霧關掉，只留一層 |
| 色調 | Filmic、曝光 0.85、輕微 bloom | |

## 材質

| 物件 | 做法 |
|---|---|
| 石拱、岩階、右下岩塊 | `rocks/rock_detail.gdshader`：保留 Tripo 顏色＋法線貼圖，先降飽和、壓暗（Tripo 是平光底下生成的，太亮），再在世界座標疊**水平層理（斷斷續續）、裂縫、凹洞、細沙粒**與細節法線；朝拱口、又轉向側面的邊緣自發暖光（目標圖拱口內緣那圈亮邊） |
| 岩柱 | 原材質壓暗到 0.55，偏剪影 |
| 沙蟲身體 | `worm/skin.gdshader`：Tripo 貼圖原本偏紅褐，降飽和後拉向目標圖的米白；剪影邊緣逆光發亮；加一點自發光（太陽在牠背後，但目標圖裡牠是亮的——氛圍優先於光學） |
| 沙蟲嘴 | 不動（牙、肉環、黑喉是程式材質） |
| 沙丘 | 沙色降飽和：亮面偏桃、背光面偏紅褐，起伏加深 1.6 倍 |
| 塵 | 顏色改成金橘（tint／shade／glow），不吃場景光 |

## 修正紀錄

- 複製 Tripo 材質再改顏色時，Compatibility 渲染器報 `Parameter "material" is null`：改成直接改記憶體裡的材質（它們沒有別人在用）。
- 塵捲風與塵團不投影（它們是透光的塵，不是實體）。

## 和目標圖還差的（留給第 5、6 步）

- 塵團仍比目標圖白、薄，缺體積明暗；太陽前方的光束（god rays）還沒做。
- 沙蟲身體細（模型限制，見 03）。
- 沙丘近處沙紋太規律，略像條紋。
