## 共用規格（大家都遵守）

- **單位公尺**，+Y 朝上，沙地平面 y = 0。鏡頭大致在原點附近、高約 8 m、往 −Z 看（步驟 3 才定準）。
- **每個家族只動自己的資料夾**（`rocks/`、`worm/`、`sand/`、`sky/`）和自己的文件 `docs/沙蟲/02-素材/<家族>.md`＋截圖。不要改 `main.gd`、`lib/`、`tools/`、`project.godot`。
- 每個家族交一個 `<家族>/preview.tscn`：把自己的成品擺出來、放一台鏡頭，root 腳本 `_ready` 裡呼叫
  `Look.plain_env(self, Look.mode())` 和 `Look.apply(self, Look.mode())`，這樣 `gray=1` 也能看灰模。
  正常模式（沒帶參數）要有自己的光，看得出材質。
- 截圖：`SCENE=res://<家族>/preview.tscn FRAMES=60 ./tools/shot.sh <out.png> [gray=1]`（1672×941）。
  新增 GLB／貼圖後先跑 `./tools/import.sh`。shot.sh／import.sh 自帶排隊鎖（Godot 平行跑會出黑圖），別直接呼叫 Godot 執行檔。
- 交件截圖放 `docs/沙蟲/02-素材/<家族>-*.png`，文件寫：成品檔、尺寸（公尺）、原點位置、可調參數、三角形數、已知問題。
- 效能預算（全場合計）：內顯每格 12 ms 內，所以模型盡量減面：石拱 ≤ 60k 三角形、每根岩柱 ≤ 15k、沙蟲 ≤ 80k。
- Blender：`E:\Tools\blender-5.2.2-windows-x64\blender.exe -b -P x.py`；腳本先寫成檔案再跑。
- 原始模型（Tripo，只有顏色貼圖可信）：`godot/sandworm2/models/src/`：`stone_arch.glb`、`rock_spires.glb`（6 根拼在一起）、`sandworm_rigged.glb`（14 骨：spine_00–08、head、lip_front/back/left/right；**口緣骨繞本地 X：＋張開、−合攏**；靜止時嘴朝本地 +Z）。
- 素材庫 `E:\DesktopPet\docs\素材庫\`（ambientCG 地面、micro_grime 做舊紋理等）可直接拿。

## 尺度（從目標圖量，給大家對比例）

- 石拱：高約 60 m，拱口寬約 45 m，鏡頭就站在拱口內側；拱口占畫面約 75%。
- 沙蟲：頭（含四片口緣）寬約畫寬 33%，露出沙面的身體約 120 m；口緣張開時十字形，嘴內是**深黑喉洞＋外圈粉紅肉環＋好幾圈往內彎的白牙**。
- 岩柱：近的高 35–70 m，遠處很多小的。
- 太陽：右側、貼地平線，地平線約在畫高 55%。

## 四個家族

### A 岩石 `rocks/`
- `arch.tscn`：石拱。原點＝兩腳之間地面中心，拱口朝 ±Z。減面到預算內、保留顏色貼圖（可另烤法線）。
- `spire.tscn` 或 `spires.gd`：把 `rock_spires.glb` 拆成 6 根獨立、底部對齊 y=0 的岩柱（每根原點在底面中心），讓主線可以複製、縮放、旋轉散布。
- `ledge.tscn`：前景岩階（目標圖左下層層堆疊的岩板、底邊碎石、右下岩塊）。可用石拱模型切下來的碎塊或程式堆疊的岩板；要看得出一階一階的水平層理。
- 材質：暖褐砂岩，層理水平；內緣吃暖色反光是階段 4 的事，現在顏色貼圖＋標準材質就好。

### B 沙蟲 `worm/`
- `worm.tscn`：root 腳本 export `bend`（上段脊椎彎度）、`lip`（口緣張開角度，弧度）、`sink`（往沙裡沉的公尺數）、`yaw`。原點在沙面線上的身體中心，`sink = 0` 時露出約 120 m。
- **牙圈＋喉洞**（重點）：在嘴裡程式產生 3–5 圈往內彎的錐形牙（MultiMesh），一圈比一圈小、往喉嚨深處收；最裡面是吸光的黑色漏斗（喉洞），外圈接粉紅肉環。牙與喉要跟著 head 骨走。
- 口緣內側也有一排小刺牙（目標圖的四片口緣內面布滿細刺），能做就做。
- 交件截圖：正面張口（lip 大）、合攏、側面；正面張口要能讀出「黑洞＋牙圈」。

### C 沙與塵 `sand/`
- `dunes.tscn`：沙丘地面（約 8 km × 8 km 以原點為中心，近處細、遠處粗），程式高度場：前中景低矮起伏的沙丘、稜線受側光；沙紋細節用 shader。export：火山口（沙蟲破土處）的中心與半徑、隆起量。
- `dust.tscn`：沙蟲基部的塵牆／翻騰塵團、沙瀑（從口緣與身側往下流的沙幕）、塵捲風（`devil` 可單獨擺）。粒子或 shader 都行，export 強度 0–1。**Compatibility 下 CPUParticles3D 的頂點色會出現接近黑色的粒子 → 塵的顏色不要吃粒子 RGB，只用 alpha**（自訂 shader）。
- 顏色：暖橘沙 #d89a5a 一帶，塵受逆光偏亮橘；不可以有暗塊。

### D 天空遠景 `sky/`
- `backdrop.tscn`：遠景看板。請 Codex 把目標圖改成**只剩遠景**的乾淨背景（天空、雲、太陽、遠山、地平線霧；把石拱、岩柱、沙蟲、塵、近中景沙丘全部去掉並自然補畫），1672×941 以上、構圖與目標圖完全對齊。看板要能貼在鏡頭視錐的遠端剛好填滿畫面（export `fov`、`distance`，掛在鏡頭底下即可）。
- shader：雲慢慢往一個方向飄（UV 位移或流動貼圖）、太陽光暈微微呼吸；export 速度與強度。
- Codex 用法：`codex exec --skip-git-repo-check -s workspace-write -C <dir> "Read prompt.md and do exactly what it says." < /dev/null`，prompt 寫在 prompt.md，參考圖放同資料夾並在 prompt 裡點名；約 4–5 分鐘，外層指令結束不等於 Codex 做完，要等產出檔。
