# 麥塊世界 — 02 場景擺放（灰模）

入口：`themes/creeper-window/index.html`（此階段只有純色＋一盞平光）；擺放程式 `scene.js`。
對照圖：`02-對照.jpg`（第一版）、**`02-前景對照.jpg`（現行：前景對齊 mc1）**。

## 前景對齊作法（2026-10-29 用戶：前景、桌子、建築、角度對齊原圖，滿足鏡頭即可）

1. Codex 從 mc1 抽前景：`codex-fg/fg.png`（窗外塗洋紅；Codex 自承有小偏移，只當參考）、
   `codex-fg/fg_lines.png`（前景結構線，疊回 mc1 驗過是準的 → **以這張為對位基準**）、`structure_points.json`。
2. 用結構線上的點反解鏡頭：左窗四角、中柱右下角、右窗台線在畫面右緣的高度、苦力怕頭頂與腳底，
   隨機搜尋（鏡頭位置／偏轉／俯仰／視角＋窗高、苦力怕大小與深度）→ 誤差 RMS 約 2.5 %。
   結果：鏡頭往左偏 22.6°（窗牆右側離鏡頭較近，跟 mc1 窗框線往左收的消失點一致），原本往右轉是錯的。
3. 燈籠、桌面、凳子沒有世界尺寸可依，直接把結構線上的畫面點反投影到選定深度／高度的平面上擺放。
4. 為了貼合畫面而「作弊」的幾何（只保證從鏡頭看對）：窗牆只有 0.45 格厚（mc1 窗框很細）、中柱 0.42 格寬、
   苦力怕 1.82 倍、桌子高 1.84、左窗高 4 格、右窗一路開到 y = 12（右上是天空）。

## 擺放參數（`scene.js` 的 `LAYOUT`，單位＝方塊，+x＝畫面右）

- 鏡頭 (3.04, 2.36, −0.72) 看向 (−0.8, 2.32, 8.51)，垂直視角 60.1°（`index.html` 的 `CAM`）。
- 窗牆 z = 3（厚 0.45）；左窗 x −2…1、y 1…5；中柱 x 1…1.42；右窗 x 1…40、y 1…12；最左小窗 x −5…−4、y 2…5（十字橫木 y 3.4）。
- 苦力怕 (−0.85, 1, 4.6)；門廊在左窗後三格深，其餘沿牆一格寬石台；牆與門廊之間補石窗台。
- 燈籠 (0.9, 1.84, 0.36)；桌面中心 (0.7, 1.77, −0.28)、2.6 × 1.65；凳子 (1.25, 0.94, 1.6)。
- 湖：大橢圓（中心 15, 30）＋門廊前湖灣；近岸 18 格內不種樹；對岸四間小屋；遠山 4 倍方塊；方塊雲 y = 52。
- 世界以 `root.scale.x = -1` 鏡像（三維 +z 朝前時 +x 在左），對外座標用 `mirror()`。
