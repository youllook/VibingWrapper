# 麥塊世界（creeper-window）— 01 素材盤點

目標圖：`docs/codex-brainstorm/minecraft/mc1.png`「雨夜窗外的訪客」（2026-10-29 用戶選定）。
輸出規格：`themes/README.md`（theme.json、state.json 輪詢、wpPause、30 fps、半解析度、`window.theme`）。

**流程（2026-10-29 用戶定）**：① 素材盤點＋製作 → ② 場景擺放＋驗證 → ③ 細節、貼圖 → ④ 燈光、特效、氛圍。
只參考輸出規格與素材庫，不套既有主題的程式模板。

## 素材庫查過的東西

| 素材庫項目 | 能不能用 | 結論 |
|---|---|---|
| `美術風格/voxel-worlds_2` | 只當參考 | 色票：藍炭 #111B25、石板青 #29434B、琥珀燈 #F4B868、淡青 #A4D7DF；「方塊靠幾何定邊、不描線」 |
| `shadertoy_minecraft` | ✗（CC BY-NC-SA） | 只看 raymarch 寫法，不拿貼圖與程式 |
| `chiro_rain`（MIT） | 第 ④ 階段參考 | 雨絲 instancing、閃電閃光 |
| `退役主題/voxel-station` | ✗ | 已退役的 2D 烘焙路線，不沿用 |

→ 方塊貼圖、苦力怕、道具**全部程式自製**（16 px 原創像素貼圖，固定亂數種子，可重現）。不用 Mojang 原版貼圖。
