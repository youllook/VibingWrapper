# 麥塊世界・雨夜木屋 — 美術評審（Fable）

評審日期：2026-10-29
對照：`目標-mc1.png`（Codex 概念圖）vs `現況-夜晚.png`（主要）、`現況-白天.png`、`現況-黃昏.png`（次要）
前提：苦力怕改成一群是需求變更，不扣分；構圖與鏡頭已對齊，不重談。

---

## 一、總評

骨架已經對上了：桌面、燈籠、窗框、石砌窗台、雨痕玻璃，和目標圖的前景幾乎一比一，室內那層暖色也有味道。但現況與目標最大的差距不在「元素少」，而在**明暗關係整個反過來**——目標圖裡苦力怕是整張畫面最暗、最沉的角色，窗外的「亮」來自月光、對岸燈火、湖面反射，現況卻讓苦力怕變成最亮最飽和的一群螢光綠方塊，窗外該亮的湖與村莊幾乎不存在，於是「在溫暖的屋內往外看一個有深度的雨夜世界」變成「一面藍牆前面貼了幾塊綠」。最該先做的兩件事：**（1）把苦力怕的亮度壓下去、改成被燈籠和月光打的角色，（2）把窗外的縱深層次拉出來（湖面＋對岸燈火＋霧＋遠山至少三層）**。這兩件事做完，其他調整才看得出效果。

---

## 二、已經做得好的

- 前景構圖對位準確：桌面、燈籠位置、窗框分割比例、石砌窗台都與目標圖吻合。
- 燈籠的暖光溢到牆面與窗台的那一層，色溫對、衰減自然，是現況最接近目標圖的區域。
- 玻璃上的雨滴有體積感、有折射亮點，貼在窗上的感覺是對的（比目標圖的雨痕還細緻）。
- 右上角安靜：只有天空與雨，沒有高對比物件，HUD 放上去不會打架。
- 日夜切換三個版本的色溫方向正確（白天冷灰、黃昏粉橘、夜晚藍），底子可以疊。
- 近景那隻正面苦力怕的臉部表情與方塊比例可讀，角色辨識度足夠。

## 三、建議（依「改完畫面提升最多」排序）

### 1. 苦力怕群：從「發光體」改成「被光打的物件」　｜效能代價：低
- **目標圖**：苦力怕的綠是壓暗的灰綠（平均約 RGB 24/35/22），只有靠燈籠那側的邊緣和頂面被暖光舔亮，背後有月光冷色勾邊，整體比天空還暗。
- **現況**：近景苦力怕平均 RGB 38/92/24，純飽和綠、全身均勻亮，看起來像自發光材質或沒做受光；中遠景更糟，是一團沒有明暗的綠色平板。
- **怎麼改**：
  - 基礎色先降：貼圖本身的綠 saturation 掉 30–40%、亮度掉一半，夜晚時底色應接近「墨綠」。
  - 讓光源決定亮暗：靠窗（面向燈籠）那一側加暖橘的 point light 或直接在 shader 用方向性暖色加成；背側用月光的冷藍 rim。苦力怕被燈光「畫」出形體，而不是整隻亮。
  - 近景六隻要有一隻是主角（最靠近燈籠、最亮、臉最清楚），其餘遞減；現在兩隻並排一樣亮，視線沒有落點。
- 效能：改顏色與加一盞點光幾乎零成本，36 ms 預算內可吃。

### 2. 窗外縱深：至少做出「湖面 → 對岸燈火 → 霧 → 遠山」三到四層　｜效能代價：中
- **目標圖**：中景是整片湖水佔畫面下半，湖面反射月光與暖燈；對岸是石砌岸、雲杉、兩三棟有燈的小屋；再後面是霧帶與遠山，層層變藍變淡。
- **現況**：窗外只有一條 20 px 高的白灰色水平亮帶（看起來像積水而不是湖），其後直接接一排深藍方塊剪影，再接天空；中間沒有任何「有燈的東西」。
- **怎麼改**：
  - 湖面要佔窗戶下半部的三分之一以上。現在窗台外那片石地可以縮短，讓湖水更早開始。
  - 對岸放 4–6 個暖色小燈點（火把／窗戶 emissive 方塊），以 sprite 或 emissive 面片即可，不用真的建村莊；它們在湖面上要有拉長的垂直反射。這是目標圖「有人住」的氣氛來源。
  - 剪影分兩層：近岸深藍帶雲杉輪廓、遠山更淡更藍（fog 混合），兩層之間用霧的淡藍拉開。
  - 遠景元素可用 billboard 或低面數方塊，深度感靠顏色（霧色混入比例隨距離提高），不靠幾何細節。
- 效能：燈點＋反射 sprite 低；加兩層剪影與霧 mix 中等（可做成一張預烘的遠景面片，幾乎零成本）。

### 3. 雨：減量、分層、減白　｜效能代價：無到低（通常還省）
- **目標圖**：雨主要表現為玻璃上的雨痕與水滴，空中雨絲細、稀疏、偏灰，遠處幾乎看不見。
- **現況**：整個窗外被均勻的白色雨絲蓋住，近遠密度一樣、顏色一樣亮，把本來就稀薄的遠景層次全部洗平，也是「整張看起來像藍牆」的主因之一。
- **怎麼改**：
  - 雨絲數量先砍一半；顏色從純白改成半透明淡藍灰（alpha 0.25–0.4），只有在月光附近與燈籠光附近才稍亮。
  - 分近遠兩層：近層（玻璃外一兩公尺）粗一點、短一點、可見；遠層幾乎不畫，改用霧與湖面漣漪暗示下雨。
  - 讓玻璃上的雨滴繼續當主角——它已經做得好。
- 效能：粒子減半反而省。

### 4. 天空與月亮：做出「月光是場景主光」　｜效能代價：低
- **目標圖**：月亮有明顯的大光暈，雲從背後被打亮形成亮邊，天空是從月亮往外的徑向漸層，整個畫面的冷光都來自它。
- **現況**：月亮是一個很小的棋盤格方塊，光暈半徑小；雲是純深藍平板；天空一片均勻藍（RGB 25/37/74），沒有漸層與重點。
- **怎麼改**：
  - 月亮尺寸放大 1.5–2 倍，光暈半徑放大 3 倍以上，中心亮、邊緣用加法混合（additive）淡出。
  - 天空背景做徑向漸層：月亮周圍偏青白，遠離月亮往下壓成深藍墨色，地平線附近再微微亮回（霧）。
  - 雲塊的頂面或靠月那一側給一道亮邊（頂面用較亮的藍灰），背光側保持深色。
  - 方塊雲排列現在太整齊成一排，建議三群高低錯開，最高的一群在右上角要壓得更暗更淡（HUD 區）。
- 效能：漸層天空改 shader 零成本，光暈用一張 sprite 零成本。

### 5. 湖面反射：讓它反射「東西」　｜效能代價：中
- **目標圖**：湖面有月光的大片碎金、對岸每一盞燈都拉出暖色長條反射，水面還有雨點激起的小點，是畫面裡最「活」的一層。
- **現況**：那條水平亮帶是純白、無波動，不反射任何東西，看起來像停車場的積水。
- **怎麼改**：
  - 反射色跟著光源走：月光區反射冷青白，燈火區反射暖橘，不要純白。
  - 用簡單的 scrolling normal map 或兩層正弦波擾動反射，不需要 planar reflection——用「反射 sprite 隨波動拉長／抖動」的方式便宜得多。
  - 雨點在湖面上用稀疏的小圓漣漪（sprite sheet）點綴。
- 效能：假反射＋擾動低至中；真實 planar reflection 高，不建議在內顯上做。

### 6. 中遠景苦力怕群：拉開層次與可讀性　｜效能代價：無
- **目標圖**：（無此元素，以群像構圖原則評）
- **現況**：左窗中景那一團苦力怕全部等亮、等色、無邊線，彼此融成一塊綠平板，看不出有幾隻；右窗的兩隻正好被窗框切半。
- **怎麼改**：
  - 遠一層就暗一階、藍一階（霧色混入），近層與遠層之間至少差 20–30% 亮度。
  - 讓部分苦力怕只露頭或側身，高低錯落；用 1 個站在窗邊、2–3 個在中距離、其餘更遠的三角形分佈，避免成排。
  - 被窗框切半的那幾隻要嘛完全進窗、要嘛只露眼睛（偷看感更強）。
  - 眼睛與嘴可以在夜晚微微亮一點點（不是發光，是因為靠近燈籠），讓遠處的「臉」還能認出來。
- 效能：純擺位與顏色，零成本。

### 7. 整體調色：把「綠 vs 藍」的二色衝突收成「暖 vs 冷」　｜效能代價：無
- **目標圖**：整張圖只有兩個色系——室內暖橘與室外冷藍，苦力怕的綠是被兩者「染」過的中性色，不跳出來。
- **現況**：三個互不相讓的主色（橘、藍、螢光綠），綠色沒有被環境光影響，像貼紙。
- **怎麼改**：
  - 全場景加一道統一的後製色調：陰影偏藍紫、高光偏暖，中間調稍微去飽和；可用簡單的 LUT 或 color grade shader。
  - 所有窗外物件（含苦力怕）都要吃到同一個霧色與同一個環境光色，不要有任何物件是「不受天空影響」的。
- 效能：一個全螢幕後製 pass 約 1–2 ms，接近預算邊緣，可先用材質層級的 tint 替代。

### 8. 燈籠與室內：核心不要爆白、牆面加點材質層次　｜效能代價：無
- **目標圖**：燈籠內部是暖橘黃但不過曝，看得出內側的方格；燈光在木牆上形成漸層，木紋有明暗的格子感；桌面有微弱的反光。
- **現況**：燈籠玻璃面幾乎純白，看起來像 LED；木牆是整片均勻深紅橘，沒有木紋格子；桌面整塊黑橘，與燈距離近卻幾乎沒受光。
- **怎麼改**：
  - 燈籠 emissive 從純白拉回暖黃（例如 #FFB65A），讓內側四格有不同亮度（靠近火源的格子最亮）。
  - 木牆貼圖加入兩階明度的格子（像素圖兩色就夠）；燈籠旁的牆面亮、遠離燈籠的牆面快速變暗，現在衰減太慢，整面牆一樣亮。
  - 桌面在靠燈籠的角落加一塊柔和的暖高光，讓桌子看起來有實體與距離。
- 效能：貼圖與數值，零成本。

### 9. 玻璃：加一點室內的微弱映像　｜效能代價：低
- **目標圖**：窗玻璃上隱約看得出燈籠的暖色反射與玻璃格的邊線，告訴觀眾「中間有一片玻璃」。
- **現況**：雨滴很好，但玻璃本身沒有任何反射；視線會以為窗戶是開著的。
- **怎麼改**：
  - 在玻璃上疊一張極淡（alpha 0.08–0.12）的燈籠暖色光斑，位置與燈籠呈鏡像偏移；靜態就夠。
  - 玻璃格子的邊線可以用更細一階的深色線條提示，不要太明顯。
- 效能：一張 sprite，零到低。

### 10. 窗台外的石地：縮小面積、壓暗、濕感　｜效能代價：無
- **目標圖**：窗外石砌平台很窄，濕濕的、反著一點燈光，馬上接湖。
- **現況**：石地佔了窗戶下方很大一塊，顏色偏亮藍灰，乾燥，把湖水擠到只剩一條。
- **怎麼改**：石地深度縮到現在的一半，整體壓暗，在靠燈籠側加一點暖色反光（濕地面），其餘吃冷色。
- 效能：零成本。

## 四、白天與黃昏版本

### 白天（`現況-白天.png`）
- 天空是一片均勻灰白，太陽是一個很小的黃色方塊，沒有雲層的明暗；建議雨天白天的天空用「上深下淺」的灰藍漸層，雲塊頂面亮、底面暗，太陽藏在雲後只留一圈柔光。
- 苦力怕群在白天的飽和綠更刺眼，與中景那團綠（像灌木叢）完全同色，彼此融在一起看不出是什麼；苦力怕要比背景綠暗一階或冷一階，背景草地／灌木可以偏黃綠拉開。
- 白天沒有任何陰影方向，所有方塊都平光；給一個很弱的方向光（從雲縫來，偏左上）讓方塊頂面比側面亮一階，就會立刻有立體感。
- 燈籠白天仍然全亮沒問題（木屋氣氛），但室內牆面可以比夜晚再亮一點，讓窗外的冷灰與室內暖色對比不要那麼極端。

### 黃昏（`現況-黃昏.png`）
- 粉紫色天空的調子好看，是三個版本裡色彩最有氣氛的；建議再往地平線加一條較亮的橘色帶，雲底吃到那層橘光。
- 苦力怕與湖面完全沒有跟著黃昏變色：苦力怕還是同一個綠，湖面亮帶還是冷白。黃昏時所有戶外物件都該被天空染成偏暖的灰，湖面反射應該是粉橘色。
- 遠景剪影在黃昏應該是最美的一層（逆光），現在的剪影與夜晚一樣的深藍；建議用深紫褐色，邊緣有一點天空色的透光。
- 室內暖光與黃昏天空色溫太接近，窗內外的分界變弱；可以把室內稍微壓暗、或讓燈籠光在黃昏時稍微偏紅，保持「屋裡／屋外」兩個色域。

## 五、建議施工順序（供參考）

1 → 3 → 2 → 4 → 5，前三項做完就能看出「有沒有走對方向」；6–10 是收尾打磨。所有建議中只有第 5 項（真反射）與第 7 項（全螢幕後製）會明顯碰到 36 ms 預算，其餘都是數值與貼圖層級的調整。
