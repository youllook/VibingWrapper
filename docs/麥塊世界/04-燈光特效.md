# 麥塊世界 — 04 燈光、特效、氛圍

截圖：`04-燈光特效.png`（待命）、`04-對照.jpg`（左 mc1、右現況）、`04-狀態.jpg`（六種狀態）。
程式：`themes/creeper-window/index.html`（燈光、狀態機、每格流程）、`fx.js`（天空、雨、水、玻璃、後製 shader）。

## 開始前清掉的
階段 3 把「室外乘 0.5 當月夜」寫進方塊底色（`scene.js` 的 `tintColor`），有了真的燈光會暗兩次 → 拿掉，只留雲杉葉本身偏暗。

## 每格流程（半解析度 HDR）
1. 湖的倒影：鏡像相機、水面裁切，不畫屋內與雨；每兩格更新一次。
2. 場景 → `sceneRT`（HalfFloat＋深度）。玻璃不在這裡畫。
3. 玻璃遮罩：屋內塗黑（擋住窗框後的玻璃）＋玻璃面寫入水珠法線與覆蓋量。
4. 霧：從窗外（z ≥ 窗牆）開始沿視線走 9 步，密度＝高度衰減 ×（隨風飄的雜訊）＋湖面低霧帶，朝月亮方向的散射較亮 → `mistRT`（含 mipmap）。
5. 合成：玻璃折射（水珠彎曲視線、水膜讓後方微糊、水珠邊緣反射燈籠暖光與天空冷光、苦力怕的綠映在濕玻璃上）、景深（對焦苦力怕、前景桌燈失焦且外溢）、泛光（mip 鏈亮部）、ACES、暗部偏藍、暗角、顆粒。

## 燈光
- 月光：冷藍平行光，從月亮方向來（在苦力怕身後 → 輪廓光、樹成剪影）；**只有窗邊的屋子、門廊、苦力怕投影**，陰影圖約 10 Hz 更新。
- 燈籠：暖色點光＋閃爍；屋內另一盞暖光補左牆（mc1 左側木牆是亮的）。
- 苦力怕臉上：一盞冷中性的聚光（只有燈籠暖光時綠色會變橄欖色）。
- 對岸兩盞暖燈；小屋亮窗、火把是 HDR 自發光，靠泛光發亮、在湖面拖出倒影。

## 特效
- 雨絲：9000 條線段，頂點 shader 落下、隨風斜，近處淡出（太近會像雪花）。
- 玻璃雨滴：兩層靜止水珠＋會停頓下滑的水滴與身後的小水珠痕。
- 湖面：雨滴漣漪（兩層格子各自循環）＋微風雜訊彎曲法線 → 倒影晃動；月光在漣漪上的碎光。
- 遠方閃電（只在執行中）：天空、霧、月光同時閃兩下。

## 狀態（苦力怕演出）
| 狀態 | 苦力怕 | 天氣 |
|---|---|---|
| 沒有對話 none | 從左側走開，窗外沒人 | 小雨 |
| 待命 clear | 走到窗前站著，綠色微微呼吸 | 小雨 |
| 思考 overcast | 頭歪向一邊、停、回正、歪另一邊 | 雨稍大、霧稍濃 |
| 執行 storm | 身體往玻璃前傾 | 大雨、霧濃、玻璃更濕、遠方閃電 |
| 收尾 clearing | 回正；燈籠亮一下再穩下來 | 雨變小 |
| 等你 waiting | 轉頭看你；每 1.6 秒鼓起、泛白一次（皮膚仍看得到），濕玻璃上映出綠光——永遠不會爆 | 中雨 |

## 效能（Intel UHD 630，1357×764）
約 32 ms／格（流程放寬上限 36 ms）。原本 56 ms：地形全部投影到陰影圖佔 17 ms → 只讓窗邊投影＋10 Hz 更新；景深 16→12 取樣、霧 12→9 步、倒影隔格更新。

- 湖：mc1 的湖面佔畫面下半大片、滿是倒影；我們的湖帶較窄，前面石台佔比大。
- 苦力怕比 mc1 暗一點、對比低一點。

## 第三輪：雲（2026-10-29 用戶：方塊要圓角、方塊之間不完全密合，懷疑有地表反射光）
對照 `04-雲對照.png`（上 mc1、下現況）。看 mc1 放大：雲是一條條「一格高、3–7 格長」的圓角方塊條，散在不同深度，塊與塊之間有縫；本體比天空暗，只有上緣被月光勾出一點亮邊，底面微亮（湖面、地表反上來的光）。
- 幾何：自製 `roundedBox`（4×4×4 段的盒子，邊與角推成圓弧，半徑 0.07 格），每塊比格子小 6 % → 縫。
- 排列：三層（y 28／38／52，方塊 5／7／9），每層 20–34 條雲條，長邊沿 x，偶爾上面再疊一條短的（階梯）；從 70 格外開始，在天空中段。
- 著色（`index.html` 雲材質的 onBeforeCompile）：本體深石板色；只有朝上的圓角邊在月亮附近亮起來；底面加一點偏藍的地表反射光。
- 修掉的坑：遠景景深把雲糊掉（遠側景深改成 1/4）；濕玻璃水膜的基本模糊降低；原本「月亮附近整片雲加亮」讓雲比天空亮 → 改成只加在邊上。
- 效能：約 35 ms／格（內顯）。

## 第四輪：月亮（2026-10-29 用戶：月亮也有像素貼圖）
對照 `04-月亮對照.png`（左 mc1、右現況）。mc1 的月亮是滿版方形：一圈亮白邊，裡面 2×2 像素一格、幾種淡藍成片（亮塊與暗塊），四周一圈柔和的藍色光暈。
- 貼圖（`assets.js` 的 `moon`）：16 px 滿版，1 px 白邊＋7×7 格、五階淡藍，用平滑起伏＋雜訊排出成片的「海」。色階拉開，才撐得過曝光、ACES、S 曲線。
- 亮度：原本月亮是 HDR ×2.6，曝光後整顆變白、格子看不到 → 改成 ×0.8，不靠自己發光。
- 光暈：在合成畫面上以月亮的螢幕位置加柔光（從月亮邊緣往外衰減，月面中心不加，所以格子保留、邊緣最亮），雲縫之間也看得到。天空本身另有緊的一圈。

## 第五輪：雲底反光（2026-10-29 用戶：雲下方補反光）
- 雲的底面（含下緣圓角）加冷藍的地表／湖面反光，越靠近月亮的雲越亮（下方的湖反著月光）。
- 從下往上看時底面就是雲的大部分，強度要很輕：第一版 (.020,.030,.052) 整片變白藍，定在 (.0065,.0095,.017)，月亮附近 ×2.5。
- 效果：正面暗、底面微亮，雲有了厚度。效能平均約 35 ms（偶爾 50 ms 尖峰，陰影更新那格）。

## 第六輪：月亮穿透雲（2026-10-29 用戶：月亮穿透了？）
對照 `04-月亮被雲遮.png`（同一處 0／20／40／70 秒）。
- 原因：月亮放在 100 遠，三層雲多半比它遠 → 月亮畫在雲前面。改放 380 遠（方向不變、放大 3.8 倍，畫面大小不變），在所有雲後面。
- 放遠後三層雲剛好都橫過月亮的視線，整顆被蓋住 → 每層在「月亮視線經過的那條 z 帶」只留 2 成雲條：雲偶爾飄過、遮住一部分，不會一直蓋著。鏡頭參數搬進 `LAYOUT.cam`（場景要用來算這條帶）。
- 螢幕光暈：用 5 個深度取樣算月亮露出多少，被遮時光暈降到 18 %、並允許溢到前面的雲上（月光從雲邊透出）；不再出現黑洞。
- 月亮附近整片泛白：大範圍泛光門檻提高（月亮本身不再觸發），天空中等光暈減到 1/3。

## 第七輪：日夜（2026-10-29 用戶：實作日夜）
對照 `04-日夜.jpg`（清晨 06:12／白天 10:30／黃昏 18:00／夜晚 22:00）。
- 時鐘：`CONFIG.clockHours`，null＝電腦時間；`?day=1`＝10.5、`?night=1`＝22（themes/README 規格），錄影器也設這個。
- 由時間算太陽高度 sunH（午夜 −1、正午 +1）→ 白天量 D、晨昏量 Tw。所有顏色是 `LOOK` 表的 [夜, 日, 晨昏] 三欄，晨昏欄用 Tw 疊上去；清晨另乘 `DAWN`（偏冷偏粉），黃昏偏暖橘。
- 月亮與太陽都走 mc1 月亮的方位：傍晚月亮從地平線升到原位、清晨落下；白天太陽同樣升到那個位置（略高）。構圖與右上 HUD 區不變。方向光、陰影、雲的銀邊、水面碎光都跟著當時在天上的那顆。
- 白天：下雨的陰天（灰藍天、淺灰方塊雲、灰霧）、像素太陽（暖黃 2×2 格、會泛光）、曝光降低；燈籠、屋內暖光、窗燈、對岸燈調暗；屋內多一盞冷色日光補光。
- 修掉的坑：玻璃遮罩那一步把月亮強制設回可見 → 改成還原原狀態（白天月亮不會出現）。
- 效能：約 35.7 ms／格。

## 第八輪：苦力怕群（2026-10-29 用戶：一群苦力怕跑出來看窗內；近景 4–8、中遠景 15 左右；走進方向依地形分左右）
對照 `04-苦力怕群.jpg`（跑出來 1.5／3／4.5 秒、等你閃白）。程式 `crowd.js`。
- 做法：20 隻另做成 instancing（腿／身／頭各一個 InstancedMesh，全部約 8 次繪製），每格在 CPU 算每隻的姿勢（位置、朝向、身體前傾、頭歪／轉、四腳擺動）；主角那隻維持原本的完整模型。每隻有自己的淡色差與待機相位，`aFlash` 做逐隻閃白。
- 近景 6 隻：主角＋左窗兩隻（門廊後、左緣探頭）＋右窗外三隻（擠在右窗右側，畫面 x ≈ 79–96 %）。右窗外的平台加寬成三格深。
- 中遠景 15 隻：在湖岸陸地上隨機取點 → 只留畫面上落在右窗空處（53–76 %）、沒被樹／小屋擋住（從鏡頭打射線）的 → 依畫面位置＋深度（log 距離）做最遠點挑選，分散開；越遠越大一點。
- 走進方向（依地形）：近景從門廊／平台的兩端進來（左 x −6、右 x 10.5），不踩水。中遠景各自試「左、右、後方」三條路，只取全程在陸地上、不穿過門廊的那條，先試牠在畫面那一側；都不行就從身後一步出來。這張地圖中遠景都站在湖左岸，右邊與後方是水，所以 14 隻從左邊跑進來、1 隻從身後。
- 狀態：有對話就依序跑出來（近的先、遠的後），對話結束跑回去；思考＝各自節奏歪頭；執行＝前傾（近的多）；等你＝全部轉頭看你，閃白由近往遠一波波傳出去。夜裡苦力怕群自帶一點綠光，不會全黑；右窗外另一盞聚光照近景那三隻。
- 效能：約 38 ms／格（內顯），略超 36 ms 上限。
