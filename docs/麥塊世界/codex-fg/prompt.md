# 任務：把 mc1.png 的「前景（室內）」單獨抽出來，給 3D 場景對位用

mc1.png 是從木屋室內望向窗外的概念圖。我要在 3D 裡重建室內，需要一張「只有前景」的對照圖。

## 前景＝屋內的東西（要保留）
- 左下的木桌與燈籠
- 左側木牆、左牆小窗的窗框
- 大窗的所有木框：左框、上框、中柱、窗台（屋內那側）、右下屋內的木牆／窗台
- 天花板／梁（若有）

## 背景＝窗外的一切（要拿掉）
苦力怕、門廊石台、湖、樹、山、天空、月亮、雨絲、玻璃上的雨滴反光——全部換成**純洋紅 #FF00FF 平塗**。

## 要求
1. 用圖像生成工具「編輯 mc1.png」：前景的位置、形狀、透視、比例**完全不動**，像素對齊原圖（同為 1672×941），只把背景改成純洋紅。不要重畫構圖、不要加東西。
2. 輸出 `fg.png`（前景＋洋紅背景）。
3. 另外輸出 `fg_lines.png`：同尺寸，黑底，把前景的主要結構邊線（桌面邊、桌腳、燈籠外框、牆柱、窗框內外緣、窗台線、天花板梁）畫成白色細線，背景不畫任何東西。這張可以用程式描邊（例如從 fg.png 取邊緣），重點是線要準。
4. 寫 `notes.md`：列出各前景元素在畫面上的位置（百分比座標：左框 x、中柱 x 範圍、窗台 y、桌面邊緣線兩端點、燈籠框範圍、天花板線），以及你估計的鏡頭：視平線大約在畫面幾 %、窗牆是正對還是斜對鏡頭（往哪邊轉幾度）、大概的垂直視角。
5. 完成後建立空檔 `.done`。
