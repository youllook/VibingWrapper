# 任務：「無限系列」桌布概念圖

## 背景
星圖（DesktopPet）是 Windows 動態桌布引擎。「無限系列」= 主角永遠往前（或原地永動），背景無限生成。
現有一支「滑板下坡」：style-ref.jpg 是它的實際畫面——第三人稱跟拍、主角在畫面左下三分之一、
道路／路線往畫面深處延伸、日系動畫背景美術的柔和寫實上色、乾淨大氣透視。
新圖要像同一系列：同樣的上色質感與「往前進」的透視引導，但每張的環境、時段、配色要明顯不同。

## 共同規則
- 先看 style-ref.jpg 抓畫風（只參考上色質感與構圖語言，不要複製內容）。
- 每張 16:9 橫幅，越接近 1920x1080 越好；用圖像生成工具直接生成，不要寫程式畫圖。
- 四層視差要讀得出來：近景（快掠過、可略帶動態模糊）、中景、遠景、天空。
- 畫面要有「正在移動、會一直延續下去」的感覺：路線／軌道／河道／氣流往消失點延伸。
- 主角不要太大（約畫面高 1/4–1/3），不要正臉特寫；人物用背影或側後方。
- 畫面右上角留一塊較乾淨的區域（放 HUD 的空間），不要放重要物件或高對比細節。
- 偶發事件那一欄：畫進圖裡，作為畫面中一個小亮點（不要搶過主角）。
- 不要文字、不要 logo、不要 UI、不要浮水印。

## 交件
- 依下方清單編號存檔：例如 s01.png、x02.png（檔名照清單給的），放在目前資料夾。
- 另寫 notes.md：每張一段——實際用的圖像 prompt（英文）、一句話自評「做成即時 3D 桌布的難點」。
- 全部完成後建立空檔 .done。
