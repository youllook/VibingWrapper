# 任務：「無限系列」第二輪桌布概念圖（2 個題材 × 各 2 個版本 = 4 張）

## 背景
星圖（DesktopPet）是 Windows 動態桌布引擎。「無限系列」= 主角永遠往前，背景無限生成，
畫面會跟著 AI 的工作狀態（待命／思考／執行／完成／等你）變化。
skate-ref.jpg 是系列現有作品「滑板下坡」的畫面，只當構圖語言參考（往前進的透視、主角小、右上留白）。

## 共同規則
- 每張 16:9 橫幅，越接近 1920x1080 越好；用圖像生成工具直接生成，不要寫程式畫圖。
- 要讀得出前景／中景／遠景／天空的分層（之後要拆層做視差）。
- 畫面要有「正在移動、會一直延續下去」的感覺。
- 主角小（約畫面高 1/6–1/4），不要搶畫面。
- 畫面右上角留一塊較乾淨的區域（放 HUD），不要放重要物件或高對比細節。
- 不要文字、不要 logo、不要 UI、不要浮水印、不要印章或題字。

## 題材一：紙飛機穿城（n01a.png、n01b.png）
- 畫風：看 paper-ref.png（我們的「紙片燈塔」主題）——飽和繪本色、每個物件外圈白色刀模邊、
  紙板有厚度露出紙芯、紙片之間有空隙陰影、淺景深像在拍真的紙模型、描邊深褐不用黑。
  只拿畫風，不要燈塔、企鵝、海岬這些內容。**不要出現書或書頁**。
- 主體：一架摺紙飛機（白紙或淺色紙），從側後方跟拍，往畫面深處飛。
- 場景：一座摺紙／剪紙城市——立體彈出的房子、屋頂、電線、晾衣繩、橋、塔，街道或運河往消失點延伸。
  近景有紙片招牌或紙樹快速掠過（可略帶動態模糊）。
- 天空：剪紙雲（一片片紙），遠方城市剪影層層疊。
- n01a：晴朗白天，奶油黃＋天藍＋磚紅。
- n01b：黃昏到入夜，窗戶亮起暖燈（紙後透光），天空紫橘漸層。
- 小亮點：一群紙鴿從屋頂飛起，或一扇窗啪地彈開。

## 題材二：水墨山水長卷（n02a.png、n02b.png）
- 畫風：中國傳統水墨山水長卷（宋元山水那種氣質）——宣紙底色、墨分五色的濃淡層次、留白當雲霧水面、
  可淡淡設色（淺絳：赭石、花青）。不要卡通、不要 3D 感、不要描邊動畫風。
- 構圖例外：這張是**橫向捲動**，不是往深處前進——像長卷一路往左展開，
  一艘小篷船（一個撐篙或垂釣的小人）在畫面中下偏左，順水往右漂（或畫卷往左捲）。
- 分層：近景岸石與老松（最濃墨）、中景村舍小橋與蘆葦、遠景淡墨群山、最遠是留白雲霧與天。
  每一層的山水要能左右無縫延續的感覺（不要在畫面兩側收尾）。
- n02a：清晨，霧多、墨淡、留白大，偶有幾點淺絳設色。
- n02b：雨後傍晚或雪景（擇一），墨更重，船上一盞小燈是唯一暖色。
- 小亮點：一行飛雁掠過遠山，或岸邊亭子裡一點燈。
