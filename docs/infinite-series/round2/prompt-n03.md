# 任務：「紙飛機穿城」概念圖重做（3 張）

## 背景
星圖（DesktopPet）是 Windows 動態桌布引擎。「無限系列」= 主角永遠往前，背景無限生成。
上一版 rejected.png 被退件：太像彩色繪本小鎮。用戶要的是 whitecity-ref.png 那種感覺——
**整座城市是白色建築量體模型（白模），看起來像用白紙做的**。

## 風格（最重要）
- 城市＝白紙模型：大樓、街道、橋、高架、電塔全部是白色或極淡的米白紙；
  看得出紙的質感（細微纖維、摺痕、紙板切口的厚度、邊角略不完美），但造型是乾淨的建築量體，不要可愛小屋。
- 光影是主角：柔和日光、清楚的投影與環境遮蔽，白色之間靠明暗分層次；遠景淡進霧裡（大氣透視）。
- 色彩極少：整體 90% 以上是白／淺灰。只允許一個點綴色（見各版）。
- 參考建築模型攝影、白模渲染、建築系紙模；不要卡通、不要飽和色、不要繪本描邊。
- 天空也淡：淺灰白、極淡藍，或乾脆紙色。

## 構圖
- 主體：一架白色摺紙飛機，從側後方跟拍，在大樓之間的街谷往畫面深處飛（高度約在大樓中段），
  主角約畫面高 1/8–1/5。
- 街道／街谷往消失點延伸，有「會一直延續」的感覺；近景大樓邊緣快速掠過，可略帶動態模糊。
- 要讀得出近景／中景／遠景／天空的分層。
- 畫面右上角留一塊乾淨區域（放 HUD）。
- 不要文字、不要 logo、不要 UI、不要浮水印。
