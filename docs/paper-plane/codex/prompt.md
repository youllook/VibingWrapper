# 任務：紙飛機穿城桌布 —— 依現成截圖「優化細節」（2 張）

## 背景
這是一張即時 3D 動態桌布（Three.js 程式生成的無限白模城市，一架藍色摺紙飛機在街谷間飛）。
shot1.png、shot2.png 是目前引擎的實際截圖；target.png 是當初定調的概念圖（參考氣氛與細節密度，不要照抄構圖）。

## 要做的
以 shot1.png、shot2.png 為底各畫一張「細節優化版」：
- **構圖、鏡頭角度、建築量體位置、紙飛機位置與大小都保持不變**（要能一格一格對回截圖）。
- 只在既有量體上加／改細節，讓它更像精緻的白紙建築模型攝影：
  立面分割、凹槽、窗洞的深度、紙板切口厚度、邊角倒角、摺痕、屋頂設備、橋與單軌的結構、街道上的小物件、
  光影（環境遮蔽、接觸陰影、反彈光）、遠景空氣透視。
- 整體 90% 以上是白／淺灰紙色；唯一點綴色是藍色紙飛機。不要卡通、不要描邊、不要文字或 logo。
- 細節要是「程式之後做得出來的」：重複性的幾何、規則的紋理、光影，優於一次性的手繪雕花。

## 交件（放在這個資料夾）
- shot1_detail.png、shot2_detail.png（1920×1080 或同比例）
- notes.md：用條列寫出你加了哪些細節，每項一行，依「對畫面幫助大小」排序（最有效的在前）。
- 完成後建立空檔 .done
