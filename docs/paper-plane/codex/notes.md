# 細節優化

- 加深原有直向窄窗與橫向凹槽，補上內側陰影與細亮切口，讓開孔有可辨識的深度。
- 在簷口、屋頂盒體底座與樓體交界補上接觸陰影和環境遮蔽，以柔和反彈光保留高亮白紙感。
- 用規則板縫切分大面積立面，在女兒牆和樓層收邊加上薄紙板疊層、切口厚度及微倒角。
- 明確化跨街橋的三角桁架與橋面邊緣，在單軌導梁上加入等距接縫並加深支撐接點。
- 把屋頂盒體細化成有淺框、等距百葉與底座的白色通風設備。
- 加入細微的霧面紙纖維與局部摺線明暗，讓白色立面和藍色飛機讀起來有紙材的質感。
- 沿既有街道加入小型方形排水格柵與地坪分縫，補足街谷的比例感。
- 讓遠處立面與橋梁的反差隨距離逐步減弱，保留街谷盡頭的淺色空氣透視。
