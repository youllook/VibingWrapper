# 紙摺城市的紙感手法

- **外露紙邊與翻摺屋簷** — 用薄殼擠出做出紙板截面，再沿屋頂輪廓疊上翻折的窄紙條，讓近景能看出薄紙層。
- **外露舌片與角落搭接** — 在屋簷與牆面的接點放置重複使用的三角或梯形舌片網格，稍微抬高尖端並加上接觸陰影。
- **山摺與谷摺** — 把局部屋頂和立面分成幾片夾角很小的平面，沿摺線保留法線轉折，讓側光自然分出摺脊和摺谷。
- **模切狹縫與壓痕** — 近景依立面原有的格線生成狹槽和窄切面，遠景用法線貼圖重現紙面的壓線。
- **橋梁與街道的紙片接法** — 用重複的三角折板組成橋側支撐，街道由大張紙片鋪成，在搭接處保留細小的高度差。
- **接縫陰影與亮邊** — 用略帶角度的柔光照出切邊，再以烘焙環境遮蔽或局部接觸陰影帶出紙片之間的縫隙。
- **紙纖維與淺皺** — 用可平鋪的纖維貼圖或程序噪聲輕微調整粗糙度與法線，並隨距離淡出細紋。
