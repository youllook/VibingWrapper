# 任務：紙飛機穿城桌布 —— 讓整座城市更有「紙摺的」感覺（3 張）

## 背景
這是一張即時 3D 動態桌布（Three.js 程式生成的無限白模城市，一架藍色摺紙飛機在街谷間飛）。
shot1.png（一般視角）、shot2.png（大俯視）、shot3.png（第一人稱，貼在飛機尾後）是目前引擎的實際截圖。
現在的城市比較像「白色建築模型／石膏量體」，用戶要的是**一看就知道是紙摺出來的城市**。

## 要做的
以三張截圖為底各畫一張「紙摺版」：
- **構圖、鏡頭、建築量體位置、紙飛機位置與大小保持不變**（要能對回截圖）。
- 把城市改成像用紙摺、紙切、紙黏出來的：例如摺線與山谷摺的明暗、紙板厚度與切口、略不完美的邊角與微翹、
  摺出來的屋頂與斜面、黏貼的接縫與舌片、紙的纖維與微皺、紙面之間的透光或陰影、街道與橋也是紙做的。
  可以自由發揮其他讓人一眼看出「紙」的手法。
- 整體 90% 以上維持白／淺米白紙色；唯一點綴色是藍色紙飛機。不要卡通、不要描邊、不要文字或 logo。
- 細節以「程式之後做得出來的」為優先：重複性的幾何、規則的紋理、光影，優於一次性的手繪。
