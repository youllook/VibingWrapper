# 紙飛機穿城（paper-plane）· 0 分析做法與預期效果

目標圖：`target.png`（無限系列第二輪 n03a，2026-11-28 用戶定調）。
用戶要的感覺：**整座城是白模，看起來像白紙做的**；彩色繪本小鎮版退件。

## 畫面讀法（n03a）
- 鏡頭在街谷上方、約大樓中段高度，順著一條筆直大街往前（−Z）看；消失點在畫面中偏右（約 x 0.68、y 0.47）。
- 主角：淡藍紙飛機，畫面左中（約 x 0.40、y 0.62），機頭朝右前方，略向右傾。是全畫面唯一顏色。
- 左側：近景大樓很高、貼近鏡頭、被動態模糊拉長（最快）。右側：近景大樓較矮，屋頂在畫面下緣。
- 街上：一條高架單軌從右側中景彎進街谷、往消失點延伸；一座空橋橫跨街道（中景）；遠處還有幾座。
- 遠景：一排排細高樓溶進白霧；右上角天空乾淨（HUD 區）。
- 光：午後側光從右上來，街面有長長的建物投影，白色之間全靠明暗、AO 分層。

## 無限怎麼成立
- 鏡頭和紙飛機固定在原點附近，**城市往 +Z 流過來**。城市切成每段 60 m 的街廓，從鏡頭後方離開的那段搬到最前面、用它的「全域段號」重新抽籤生成。這樣不會有座標精度問題，而且每段長相只取決於段號（`?t=` 能重現同一畫面）。
- 高架單軌的路線、空橋位置都是「全域距離」的函數，跨段自然連續。
- 遠景天際線另一套更大的段（240 m），流速一樣，但霧很濃，只看剪影。

## 分層
| 層 | 內容 | 速度感 |
|---|---|---|
| 主角 | 紙飛機（固定位置，輕微上下浮、側傾） | 不動 |
| 近景 | 街道兩側第一排大樓、空橋 | 最快、加動態模糊 |
| 中景 | 第二、三排大樓、高架單軌、街道 | 中速 |
| 遠景 | 天際線剪影（細高樓群） | 慢（靠霧） |
| 天空 | 淺灰白、右上乾淨 | 不動 |

## 素材策略
- **全部程式生成，不用 Tripo、不用 ロケハン**：白模本來就是量體。
  - 大樓＝幾個堆疊盒子（退縮、頂部機房），立面的垂直溝槽／水平窗帶用 shader 依世界座標刻，不加面數。
  - InstancedMesh：每段大樓的每個盒子是一個實例，整城只有幾個 draw call。
  - 紙飛機：手寫的幾個三角面（摺紙本來就是平面），兩面材質、有摺痕。
  - 高架單軌、空橋：程式擠出。
- 「像紙」的質感在步驟 4：紙纖維噪聲、邊緣稍微不完美、切口露出紙芯厚度感、柔和 AO。

## 預期效果與風險
- 預期：一眼就是在白紙模型城市裡飛行，左側高樓唰唰掠過，遠方一路溶進霧裡，藍紙飛機是唯一的顏色。
- 風險 1：程式亂排會像一堆箱子 → 街廓規則：主街兩側建築線對齊、高度分區（近街高、偶爾一棟地標）、退縮與頂部機房。
- 風險 2：白色畫面分層全靠光 → 陰影貼圖＋AO（SSAO 太貴，先用頂點／盒子底部的假 AO＋接地暗化），霧做大氣透視。
- 風險 3：內顯效能 → 30 fps、半解析度、陰影只在鏡頭附近一小段。

## 狀態對應（之後步驟 5 細做）
- 不在：夜晚模式，城市只剩月光和少數窗燈，紙飛機停在某棟屋頂。
- 待命：慢速巡航，飛機輕輕浮。
- 思考：起霧（n03b 那種晨霧金光），遠景溶掉、速度放慢。
- 執行：加速，近景動態模糊拉長，飛機壓低穿過空橋。
- 收尾：霧散、拉高一點，陽光變暖。
- 等你：飛機在路口繞小圈盤旋，等你。
