# 健力健身房 — 04 貼圖、材質、環境光

前後對照：[04-前後.jpg](04-前後.jpg)（上 03 灰模／下 04）；局部對 gym1：[04-局部對照.jpg](04-局部對照.jpg)（上 gym1／下 04）。

## 做法

- **一個檔管全部材質**：[`themes/powerlifting-gym/lib/surface.js`](../../themes/powerlifting-gym/lib/surface.js)。`kit.material(slot)` 改呼叫 `surfaceMaterial(slot)`，所以 02 做的道具一行都不用改。
- **PBR**：每個 palette 槽一組粗糙度／金屬度（`SPEC` 表）。
- **三向投影做舊**（世界座標，不靠 UV；程式產生的模型 UV 不一致）：
  - 紋理：`textures/micro_grime.png`（素材庫 `ambientcg_micro`，CC0）。R 髒污、G 鏽、B 刮痕。
  - 每槽可調：`dirt` 髒污壓暗、`rust` 鏽色變化、`scr` 刮痕（改粗糙度）、`chip` 掉漆鏽點（約 15% 面積，深鏽褐到亮鏽橘）。
  - **重複數 `k` 要低（約每公尺 1 次）**：紋理顆粒很細，`k` 太高會被 mipmap 平均成一片均勻色，看起來像沒做。
- **木紋**：素材庫沒有木頭，用 canvas 畫（板子、年輪、節疤、板縫），一樣三向投影。舉重台、木箱用。
- **環境光**：背景看板模糊成全景當 `scene.environment`（強度 0.9），金屬反射到的是健身房的暖色。半球光降到 0.8；正式打光在 05。

## 效能（2026-10-30，1080p，`PERF=1`）

約 16 ms／格（獨顯、內顯都差不多）。量測時另有其他 session 在跑 Blender／錄影，數字可能偏高；06 交付前再量一次，必要時把做舊從三次取樣減成一次。
