本資料夾的 `src.png`（1672×941）是一張健身房桌布的背景圖。畫面上方中間偏右有一台老式吊扇（馬達中心約在 (1120, 74)，五片淺色木扇葉，往上有一根吊桿）。
`fan-mask.png` 是吊扇所在範圍（白色＝要修補的區域）；`fan-mask-preview.jpg` 用紅色標出範圍給你參考。

請輸出 `no-fan.png`：
- **1672×941、RGB、不透明**，除了遮罩範圍以外的像素必須和 `src.png` **完全相同**（最後請用 Python 把修補結果只貼回遮罩範圍內，再羽化 6–8 px 邊緣，確保其他地方一個像素都沒變）。
- 遮罩範圍內：把吊扇（扇葉、馬達、吊桿）完全拿掉，補成**後方原本的天花板**：斜向的鐵皮浪板、深色鋼樑，延續周圍的透視方向與光線（左邊高窗照進來的暖色光、右邊霓虹的紅光）。不要新增任何東西，不要留下扇葉的殘影或模糊塊。
- 可以用你內建的圖像生成／編輯工具做修補，再用 Python 合成。

完成後建立空檔 `.done`。
