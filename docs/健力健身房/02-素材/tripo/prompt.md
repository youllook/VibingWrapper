# 任務：產生 Tripo3D 建模用的人物多視圖（同一個人、A-pose）

參考圖：本資料夾的 `ref-gym1-lifter.png`（從目標圖裁下的健力選手）。請照這個人的長相、體型、服裝畫，用你內建的圖像生成工具。

## 人物（要寫實、逼真，像真人照片或高品質 3D 掃描，不要卡通、不要誇張漫畫肌肉）
- 重量級健力選手，男，約 35 歲，身高約 180 cm、體重約 120 kg：粗脖子、厚斜方肌、寬背、厚實的胸和肚子（力量型，不是健美選手那種低體脂）、非常粗壯的大腿和臀部、粗前臂。
- 深色短捲髮、濃密短鬍子，皮膚曬成小麥色，有一點汗光。
- 服裝：黑色舉重連身衣（singlet，肩帶式）外面套一件黑色無袖背心；寬版深棕色舊皮革舉重腰帶（有金屬扣）；黑色護膝（膝蓋套，上下緣有紅色條紋）；黑色護腕（紅色條紋）；黑色長襪到小腿；黑色平底舉重鞋。
- **雙手空著、手指張開自然放鬆**（不要握拳、不要拿東西）。不要槓鈴、不要任何道具。

## 姿勢與構圖（建模用，嚴格遵守）
- **A-pose**：站直、雙腳與肩同寬、腳尖朝前，雙臂向兩側斜下張開約 45°，手臂與身體分開不要碰到，雙腿也分開看得到中間縫隙。表情平靜，嘴閉著。
- **全身入鏡**，頭頂到腳底完整，上下留一點邊；人物置中。
- 背景：純淺灰（#d9d9d9）無漸層、無地面陰影、無其他物體。
- 光線：均勻柔和的攝影棚光，正面打光，不要強烈陰影或戲劇光（之後貼圖會烘焙進模型，要乾淨）。
- 直式 3:4（例如 1024×1365）。
- 不要文字、浮水印、logo。

## 輸出（存在本資料夾）
1. `view-front.png`：正面。
2. `view-left.png`：人物的左側面（人物面朝畫面右邊），**同一個人、同一個姿勢、同一套服裝**。
3. `view-back.png`：背面。
4. `view-right.png`：人物的右側面（面朝畫面左邊）。
5. `view-34.png`：前 3/4 角度（單圖生成用的備案，最清楚的一張）。

先做 view-front，之後的每張都以 view-front 為參考圖編輯產生，確保臉、髮型、鬍子、體型、服裝、護具顏色完全一致；四個正交視圖的人物高度、腳底位置要對齊（同一個比例）。
全部完成後建立空檔 `.done`。
