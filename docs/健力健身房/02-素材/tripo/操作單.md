## 拿到之後我（賈維斯）做的事

1. Blender 匯入：從蒙皮綁定矩陣重建骨架靜止姿勢（Tripo 匯出的坑，以前遇過）；材質改成不透明；高度縮放到 1.80 m；原點設在兩腳中間的地板，面朝 +Z。
2. 檢查權重：深蹲時膝蓋、髖、肩的彎曲要能撐住，壞掉的地方要修。
3. Key 動作（blender-animation）：坐凳休息、抹粉拍手、走路、上槓退步、高槓深蹲循環、最低點卡住發抖、扛槓站立鎖住、掛槓，共 8 段，每段一個 action，一起匯出成 GLB。
4. 換掉 assets/lifter.js 的假人，`getBarAnchor` 改成跟著骨架走。
