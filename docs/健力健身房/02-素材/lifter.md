# 假人 lifter（子代理 C，2026-10-30）

檔案：`themes/powerlifting-gym/assets/lifter.js`。比例假人，給階段 3 擺場景、量 J 鉤／槓位、構圖、試動作節奏；正式選手之後走 Tripo＋綁骨。

## 做了什麼

- 重量級健力選手：身高約 1.82 m（含頭髮）、肩關節高 1.49 m、髖關節高 0.95 m（站姿），粗脖、厚背、粗腿。
- 膠囊／橢球／圓柱拼成，平光固有色。看得出：黑背心＋短褲（`tank`）、舊皮腰帶＋扣（`belt`）、護膝＋紅邊、護腕＋紅邊（`sleeve`／`sleeveRed`）、黑長襪（`sleeve`）、鞋（`shoe`）、短髮＋鬍子（`hair`）。
- 原點＝兩腳中間的地板，面朝 +Z，選手左邊＝+X。站距：兩踝 ±0.26 m（比肩寬），腳尖外八 30°，踝在 z=-0.05（腳掌中段落在 z≈0）。
- 姿勢用解算：腿是兩骨 IK（髖→踝，膝蓋朝腳尖方向彎＝往前並外推），腳板世界朝向固定（腳跟永遠貼地）；手是兩骨 IK 去握 `getBarAnchor` 兩側。
- 平衡：每一格先擺軀幹前傾，再反推髖的前後位置，讓槓中心 z 一直落在 -0.01（腳掌中段）。
- 三角形：每隻 **約 6.0k**（≤ 8k），build 5–25 ms。

## 關節表（`lifter.userData.joints`）

| 關節 | 掛在 | 說明 |
|---|---|---|
| `hips` | root | 樞紐＝兩髖關節中點；position 由 setPose 決定 |
| `spine` → `chest` | hips | 腰椎、胸；前傾分配在 hips／spine／chest |
| `neck` → `head` | chest | 下蹲時反向抬，視線往前 |
| `barAnchor` | chest | 低槓位（胸座標 0, 0.15, -0.19），getBarAnchor 讀它 |
| `shoulder_L/R` → `upperArm_L/R` → `foreArm_L/R` → `hand_L/R` | chest | 肩胛→肩→肘→腕 |
| `thigh_L/R` → `shin_L/R` → `foot_L/R` | hips | 髖→膝→踝 |

尺寸在 `userData.dims`：小腿 0.44、大腿 0.45、上臂 0.31、前臂 0.28、踝高 0.085、肩關節半寬 0.225。

## API

```js
import { makeLifter, setPose, getBarAnchor } from './assets/lifter.js';
const L = makeLifter({ seed: 1 });          // 回傳 Group，已擺好 squat:0
setPose(L, { squat: t });                   // 0..1 連續內插，每格可呼叫
const p = getBarAnchor(L);                  // 世界座標 Vector3：槓鈴中心放這
```

`setPose(lifter, pose)` 參數：

| 參數 | 意義 |
|---|---|
| `squat: 0..1` | 0＝扛槓站直（軀幹前傾 18°）、1＝最低點（前傾 50°，髖關節 0.415 m 低於膝 0.45 m，膝蓋過腳尖一點並外推）。前傾用 sin 曲線（低槓前段就前傾），髖高線性下降 |
| `grip`（預設 0.55） | 握槓半距（槓中心到每隻手） |
| `bar: false` | squat 姿勢但不握槓（手自然下垂） |
| `sit: true` | 坐 0.43 m 凳休息：髖關節在 (0, 0.525, -0.40)，凳面中心 z≈-0.42；前傾 50°，手肘撐膝、雙手在兩膝間 |
| `chalk: 0..1` | 站姿抹粉，一個循環拍兩下（0／0.5＝拍到，0.25／0.75＝手張開 16 cm），手在胸前約 1.2 m 高 |

優先序：`sit` ＞ `chalk` ＞ `squat`。lifter 擺到場景任何位置／轉向都可以（解算用世界座標）。

## 量出來的數字（給深蹲架與鏡頭）

| 姿勢 | 槓中心高 | 槓中心 z | 髖關節 | 膝 |
|---|---|---|---|---|
| 站直 squat 0 | **1.48 m** | -0.01 | 0.95 / z 0.06 | 0.51 |
| 半蹲 squat 0.5 | 1.22 m | -0.01 | 0.68 | 0.46 |
| 最低點 squat 1 | 0.93 m | -0.01 | 0.415 / z -0.19 | 0.45（x ±0.37、z 0.17） |

## 和目標圖差什麼

- **槓位不同**：gym1 的選手其實是高槓＋手肘往下、握距較寬，軀幹較直；這裡照規格做低槓（槓在後三角肌下、手肘往後上、前傾 50°）。如果之後要像 gym1 的剪影，把 `barAnchor` 往上 3–4 cm、往前 3 cm，最低點前傾改 35–40° 即可。
- 形體是膠囊，肌肉量只到「大隻」不到 gym1 那種誇張的斜方肌、股四頭；背心是整塊橢球，沒有背心肩帶的開口。
- 手只是一片橢球，沒有手指握槓；`grip` 0.55 時手臂接近伸直，看起來偏寬。
- 護膝上緣在膝蓋大彎時會露出圓筒的切口（半透的環）；假人用途可接受。
- 臉朝正前方，沒有咬牙表情；頭只做前後點頭。
