## 共同規格（所有子代理都要守）

- **單位**：公尺。y 向上，選手面朝 +Z，槓鈴沿 X 軸。
- **原點**：器材、道具＝底面中心（地板 y=0）；槓鈴＝槓的中心點；假人＝兩腳中間的地板；吊扇＝吊桿頂端。
- **真實尺寸**（照實物，別目測）：
  - 奧林匹克槓總長 2.20 m、握把段直徑 28 mm、套筒直徑 50 mm、套筒長 0.415 m、內側擋環在距中心 ±0.655 m。
  - 槓片直徑 0.45 m；舊式鐵片 20 kg 厚約 0.05 m、25 kg 厚約 0.06 m，中孔 50 mm，有凸起的外圈與內轂。
  - 深蹲架：方管 75 mm、高 2.3 m、內寬 1.20 m、前後深 1.2 m；孔徑 25 mm、間距 50 mm；J 鉤高度要能調（參數）。
  - 平板凳：高 0.43 m、墊長 1.2 m、寬 0.30 m。
  - 舉重台：2.4×2.4 m、厚 0.04 m，中間木心 1.2 m 寬，兩側是黑橡膠。
- **顏色只用 `lib/palette.js`**：這階段是**固有色＋平光**，不做貼圖、霧、發光、陰影，那些是階段 4、5 的事。可以在同色系內微調明暗做斑駁。
- **材質槽**：每個 mesh 用 `kit.mesh(geo, slot)` 建，標上 palette 裡的槽名稱，階段 4 會依槽換材質。會發光的部分（裁判燈燈面）要**獨立成一個 mesh**。
- **會動的部件**掛在有名字的 Group 樞紐上（例：`barbell` 的 `plates_L`／`plates_R`、假人的關節），並在回報裡寫清楚。
- **亂數用 `kit.rng(seed)`**，同參數同結果。
- **匯出形式**：`export const items = { 名稱: { build: () => Object3D, note: '一句話' } }`；另外匯出產生器函式供階段 3 組場景用，例如 `export function makeBarbell(opts)`，每個參數寫一行 JSDoc。
- **預算**（三角形，用 `kit.countTris`）：槓鈴含 8 片 ≤ 12k；深蹲架 ≤ 10k；長凳 ≤ 3k；其他小道具各 ≤ 2k；假人 ≤ 8k；吊扇 ≤ 2k。每項 build ≤ 200 ms。
- **只改自己的檔**。不要動 `lib/`、`assets.html`、別人的 assets 檔；需要共用改動就寫在回報裡。

## 驗收方法（子代理自己做）

在主 repo 根目錄 `E:/DesktopPet` 有 node_modules，用它的 electron 拍 worktree 的頁面：

```bash
cd E:/DesktopPet/.claude/worktrees/american-gym-wallpaper-design-273587
E:/DesktopPet/node_modules/.bin/electron "docs/健力健身房/tools/shot.js" "powerlifting-gym/assets.html?m=<模組>&grid=1" E:/tmp/gym/<模組>.png 1280 720
```

- 加 `&i=<項目>` 看單一項，`&yaw=…&pitch=…` 換角度（單位是度），`&dist=` 調遠近倍率。左上角會印尺寸、三角形數、build 毫秒。
- 用 Read 看截圖，對照 gym1.png 的形狀、比例、輪廓，至少拍兩個角度。
- 交付：截圖存 `docs/健力健身房/02-素材/<模組>-*.png`，再在 `docs/健力健身房/02-素材/<模組>.md` 寫做了什麼、產生器參數、三角形數、和目標圖還差什麼。

### 進階段 3 前要決定的事

1. **最多加幾片**：套筒長 0.415 m，放不下每邊 8 片 25 kg。改成上限每邊 6 片，或 25 kg 和 20 kg 混搭。
2. **高槓或低槓**：gym1 的選手其實是**高槓**（上身較直），假人照規格做成低槓（前傾 50°）。要貼近目標圖，就改成高槓、前傾約 30°。
3. **底圖上的舊吊扇**：底圖裡原本的吊扇還在，要先修掉，或讓 3D 扇完全蓋住。
4. palette 加一個 `rackHole` 槽（架孔目前暫用 rubber 的顏色）。
