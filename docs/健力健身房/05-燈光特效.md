## 背景看板

- **遮罩**：`mask-glow.png`＝R 霓虹、G 燈泡、B 窗（**已去掉 alpha**：原本 A＝裁判燈、幾乎全 0，瀏覽器解碼預乘會把 RGB 吃掉）。裁判燈改用圓心座標畫。
- **日夜**：夜＝光束拿掉、整體壓到約四成並偏暖（鎢絲燈）、窗換深藍；霓虹與燈泡保留原亮度。
- **舊吊扇**：cv2.inpaint 會把浪板紋抹糊 → 派 Codex 用圖像編輯修掉（遮罩外像素 0 差異），3D 吊扇疊上去轉。
- **白板**：`drawWhiteboard` 的墨水層，透視轉換貼在白板四角上，乘上底色（字會吃到霓虹紅光）。`MEET D-??` 等朋友給比賽日（`PARAMS.meetDate`）。

## 3D 燈光

| 燈 | 白天 | 晚上 |
|---|---|---|
| 窗光（平行光，從後上方高窗斜射，投影） | 3.2 | 0 |
| 霓虹紅（點光，放低只打選手與器材右側） | 2.5 × 霓虹強度 | 3.25 × 霓虹強度 |
| 吊扇下燈泡（點光） | 1.2 | 4.2 |
| 頂燈（聚光，架子上方） | 0 | 14 |
| 半球光、補光 | 跟室內燈 | 跟室內燈 |

吊扇扇葉用不受光材質：霓虹點光源為了打到選手放得近，會從下面把扇葉染紅。

## 狀態

| 狀態 | 燈光／特效 |
|---|---|
| 不在 | 室內燈關到 38%；霓虹偶爾閃；吊扇慢轉 |
| 待命 | 正常；抹粉拍手兩下噴白粉 |
| 思考 | 光束裡粉塵變多 |
| 執行 | 霓虹 40 秒內亮到 1.7 倍；每 60 秒加一對片（4 → 6）；扛槓微彎、卡黏滯點彎更多並發抖 |
| 等你 | 裁判燈暗著、約每 4 秒微微亮一下；久等（20 秒）霓虹開始閃 |
| 收尾 | 三盞白燈亮 3.5 秒；白板多一筆正字（存瀏覽器，隔天歸零）；掛槓時粉塵從槓上震下來；片數歸零 |

## 已知

- **效能**：1080p 約 20 ms／格（04 是 16 ms；多了陰影與燈）。獨顯、內顯數字一樣，像是卡在 CPU 或量法，06 交付前細查。
- 加片要執行超過 60 秒才看得到，分鏡（執行 16 秒）裡看不到。
- 掛槓的粉塵量偏少，畫面上不明顯。
- 夜間仍看得到很淡的光束痕跡（遮罩外圍的霧）。
