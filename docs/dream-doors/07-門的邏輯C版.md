# 夢境之門 · 7 門的邏輯（C 版，2026-11-28）

## 為什麼改
用戶回饋：「一道一道的門……然後？」，而且門板會漂走。舊版的問題：
- 門什麼都沒擋：兩邊沒有牆，穿過去也沒有意義。
- 門後的世界永遠到不了：她走近，世界就淡掉。
- 她沒有目的，看不出接下來會怎樣。
- 狀態和門沒有關係，只是燈光效果。
- 門快過鏡頭時，門板往兩側滑 1.8 m，看起來像漂走。

## C 版規則
- **門平常是關著的。Claude 做一步，就開一扇門**：
  - 讀 `events.json`，每次工具呼叫（`kind: tool`，PostToolUse 不算）開一扇。
  - 執行時如果超過 3.5 秒沒有事件（或沒有 bridge），改成每 2.4 秒開一扇。
  - 前方最多 3 扇開著等她。
- **開著的門通往下一個世界**。世界一共六個：
  - 0 雲海
  - 1 燈塔海岸
  - 2 燈籠街
  - 3 月夜湖
  - 4 雪地
  - 5 麥田
- **穿過門，四周就換成那個世界**：
  - 天空 shader 會算每條視線依序穿過哪幾扇開著的門洞，畫出最後一扇門後的世界。門一扇套一扇，世界也一層套一層。
  - 門過了鏡頭，鏡頭所在的世界（`ENV.cur`）就換成那一個。因為是同一套投影，畫面不會有接縫。
  - 燈光（太陽、天光、霧）隨前方那扇門走近，逐漸過渡到那個世界的配色（`PAL`）。
- **門板永遠掛在門柱上**：全開約 115°，翻過門框外，不再往旁邊滑。
- **關著的門會擋住她**：她走到門前 1.4 m 會減速停下、收腳站好；門開了才慢慢加速。

## 狀態
| 狀態 | 門 | 世界 |
|---|---|---|
| 待命 | 在門前站 2.5 秒，門自己開 | 換成隨機另一個世界（2026-11-28 改：門內外一定不同） |
| 思考 | 前方的門關回去；她停在門前，門縫光一明一暗 | 不換 |
| 執行 | 每一步開一扇，她小跑穿過 | 每扇門都換新世界（不重複上一個） |
| 收尾 | 門提早自己開 | 走進金色麥田（已經在麥田就回雲海） |
| 等你 | 停在關著的門前，門縫亮光，她回頭看 | 不換 |
| 不在 | 停在關著的門前，微弱門縫光 | 套夜色。燈籠街、月夜湖本身就是夜景，不再壓暗 |

夜裡執行時，只抽雲海、燈籠街、月夜湖。

## 構圖調整（2026-11-28 用戶）
- 拿掉最前景左右兩片滑門、左上的櫻花枝：畫面只剩她、下一扇門，以及門後的世界。
- 門距從 5.2 m 拉到 10.4 m（`?sp=` 可調）。
- 沒有近景滑門遮兩邊了，所以門不再在 1.2 m 處消失，而是門框從頭頂、兩側自然掠過。門過了鏡頭（z＝0）那一刻換世界。

## 驗收
- 執行一路穿過雲海 → 燈籠街 → 麥田，世界都正確套滿畫面。
- 等你、思考、不在都會停在門前。對照圖 `E:/tmp/dream-doors/c_sheet.jpg`。
- 效能：1080p 約 8.7 ms／格（同時在錄分鏡，實際應該更低）。
- 測試介面：`theme.tool()` 模擬一次工具呼叫，`theme.ENV` 看目前世界。
