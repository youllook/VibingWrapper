# 任務：「夢境之門」的門框（Tripo 輸入圖）＋門板（正面平貼圖）

先看 target.png 抓風格：日系動畫背景的柔和寫實、做舊木頭、暖金與粉藍光。夢裡的走廊，一扇接一扇獨立的門框橫跨石板步道，每扇門材質不同。

## A. 門框 ×2（給 Tripo 圖生 3D 用）
- 只畫門框本身：兩根門柱＋上方橫樑（含出挑的樑頭、斗拱般的小托架），**開口是空的、沒有門板**，底部直接收在柱腳（無地面）。
- 物件完整、不被裁切、置中，佔畫面約 70%；3/4 角度（約 15° 俯角、35° 側向），看得出門柱與橫樑的厚度。
- 背景純淺灰（#d8d8d8）平光，無地面、無陰影投射、無其他物件、無文字。光線均勻柔和。1:1 正方形，1024×1024 以上。
1. frame_wood.png — 做舊淡褐木頭門框（就是 target.png 最近那座），開口約寬 2.4 m、高 3 m 的比例。
2. frame_iron.png — 藍灰色鐵件門框，鉚釘、略帶鏽斑，同樣比例。

## B. 門板 ×6（正面平貼圖，程式拿來貼在方塊上）
- **正視、完全正面、無透視**，一片門板填滿整張畫布（邊緣就是門板邊緣），直式 1:2.4（例如 800×1920，或盡量接近；做不到就生成後自己裁切／縮放到這個比例）。
- 光線平均、沒有投影、沒有環境；不要門框、不要地面。保留材質細節與做舊。
