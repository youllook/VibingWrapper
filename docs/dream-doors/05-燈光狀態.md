# 夢境之門 · 5 燈光與狀態

- `05-燈光對照.jpg`：上面是我們（freeze、1080p），下面是目標圖。
- `05-狀態.jpg`：六種狀態各一格（960×540，用 `theme.tick()` 推進時間後截圖）。
- 擺景一致率維持 90.0%（mean IoU 0.804）。

## 燈光
| 元素 | 做法 |
|---|---|
| 太陽 | 方向光從走道盡頭偏右後方照過來（`SUN_DIR` = 0.12, 0.42, −1）。門框、門板、女孩的影子往鏡頭這邊拉長；陰影貼圖 2048、PCF soft。**太偏側邊或太低的話，開著的門板會把整條走道遮暗**，這個角度是試出來的平衡點。遠處（9 m 外）半開的門板不投影。 |
| 天光 | 半球光：天空偏淡紫、地面偏暖，所以影子是淡紫色。 |
| 步道光斑 | `walkTop.onBeforeCompile`：用世界座標雜訊（斜向拉長、跟步道一起捲）乘在太陽光上，亮暗範圍 0.38–1.3。只影響直射光，不動天光。 |
| 雲海 | 金邊加強（rim 0.6、迎光面 1.0）；遠處的霧淡一點（0.0015），金色才留得住。 |
| 天空的太陽 | 貼著地平線、在走道盡頭偏右（`SUN` = 0.14, 0.06, −1），有一圈光暈和亮核。 |
| 消失點白光 | 走道盡頭（z −104）一片加法光，被門框擋到的部分自然看不到。 |

## 狀態對應（`STATES`；每秒讀 `state.json`，`?state=` 可固定一種）
| 狀態 | 速度 m/s | 畫面 |
|---|---|---|
| 待命 idle | 1.3 | 慢步、空中約 40 片花瓣。 |
| 思考 thinking | 1.0 | 遠處的門由近到遠一扇扇亮起：門洞前一片加法暖光，一道光波往遠處跑，約 3.3 秒一輪。 |
| 執行 working | 2.6 | 快步；門在 26 m 外就整排彈開（平常是 14 m）；空中花瓣 140 片；陽光稍強。 |
| 收尾 finishing | 0.8 | 放慢；天色、太陽、霧轉金；消失點白光最亮。 |
| 等你 waiting | 停 | 挑前方一扇門，算好距離減速，讓那扇門剛好停在她面前 1.4 m。門關上，中間門縫透光。她把腳收攏站好（walk 動作裡兩腳併攏的四個時間點），頭和脖子轉向鏡頭回頭看。 |
| 不在 absent | 0.9 | 夜：天空深藍、月亮、星星；雲海映月光；步道兩側每 2.6 m 一盞小燈，地上有光暈；門後世界只抽燈籠街和月夜湖。入夜時 12 m 外的門重新抽世界，近的門等回收再換，不會當著鏡頭跳換。 |

- 時鐘：19–6 點一律是夜（18–19、6–7 點漸變）。`?day=1`、`?night=1` 固定白天／夜晚；freeze 固定白天。
- 各參數用 2.5 秒時間常數平滑過渡；速度另用 1.5 秒。
- 其他動態：
  - 每穿過一扇門，近景滑門從靠內 0.12 m 處滑回原位（1.8 秒）。
  - 櫻花枝輕微擺動；夜裡壓暗偏藍。
- 測試介面 `window.theme`：`applyState`、`setSessions`、`setState`、`requestState`、`STATES`、`CONFIG`、`AT`，還有 `tick(秒)`。分頁在背景時 rAF 不跑，用 `tick` 手動推進時間。
- 支援 `window.wpPause(on)`；`document.hidden` 時停止渲染。

## 效能
- 1080p、pixel ratio 0.6：每格約 6.6 ms，含 CPU 和同步讀像素，在 12 ms 規格內。
- 陰影是主要的新增開銷（步驟 4 約 2 ms）。
- 不要陰影時可以加 `?noshadow=1`。
