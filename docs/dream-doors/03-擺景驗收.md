# 夢境之門 · 3 擺景驗收

## 做法
- 開發伺服器：`.claude/launch.json` 的 `dream-doors`（`docs/dream-doors/devserver.py 5192`）。
- `themes/dream-doors/index.html?freeze=1&ids=1` 出五色分層遮罩（近景紅／女孩黃／門綠／步道藍／天空黑），`check.js` 跟 Codex 拆的五層逐層比：

```
await (await import('./check.js')).score()      // 逐層 IoU＋像素一致率
(await import('./check.js')).compare()            // 上：我們／中：目標／下：差異
(await import('./check.js')).optimize({...})      // 鏡頭、門距、開門角、近景滑門、櫻花位置座標下降
```

## 模型
| 檔案 | 來源 | 三角形 | 大小 | 備註 |
|---|---|---|---|---|
| `models/frame_wood.glb` | Tripo H3.5 → 重拓撲 | 7,332 | 0.63 MB | 載入時量兩柱內緣，x 縮放到開口＝`ow`、高度＝`ph+beam` |
| `models/frame_iron.glb` | 同上 | 6,105 | 0.74 MB | 同上 |
| `models/girl.glb` | Tripo H3.5 → 重拓撲 2 萬 → Mixamo 骨架自動綁定 → Tripo 內建 walk（原地，2.33 秒） | 20,023 | 1.42 MB | 65 根骨；裙子權重已抹平（見下） |

- 原檔在 `E:\tmp\dream-doors-tripo\raw\`。
- **長裙權重**：Tripo 自動綁定把裙子左右各綁一條大腿，跨步時從兩腿中間撕開。`E:\tmp\dream-doors\skirt_fix.mjs` 把腰（0.58）到裙擺（0.2）之間、非手臂的頂點改成「髖＋左右大腿」平滑混合：左右依 x 漸變、越往裙擺越跟腿（12% → 62%）；膝以下只改離小腿中心線 5 cm 以外的（裙子），小腿不動。改了 5,716／25,132 個頂點，正面與側面跨步都不再撕裂。
- 門板：方塊＋Codex 正面貼圖（6 款），每扇門每輪隨機抽框與左右門板；freeze 時第 0 扇＝木框＋格子窗／櫻花木門、第 1 扇＝鐵框＋保險庫門（照目標圖）。

## 結果
- 灰模（方塊門框、膠囊女孩）：一致率 86.9%。
- 換上 Tripo 模型、門板改成往遠處開：擬合前 88.0%（女孩 IoU 0.64 → 0.71、門 0.70 → 0.74）。
- 擬合後：**一致率 90.2%、五層平均 IoU 0.81**（近景 0.78、女孩 0.72、門 0.79、步道 0.91、天空 0.83）。參數已寫成 main.js 預設；對照圖 `03-擺景對照.jpg`（上＝我們、下＝目標）。
- 已知差異：木門框的柱子比目標圖粗（Tripo 框被 x 拉寬）；近景滑門、步道、天空仍是灰模，步驟 4–5 再上材質。
