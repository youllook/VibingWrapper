# 夢境之門 · 9 藝術化（2026-11-28）

用戶：「我希望看起來像是高品質藝術品」。

對照圖：
- `09-藝術化對照.jpg`：改前、改後、目標圖。
- `09-藝術化四景.jpg`：雲海待命、執行、月夜湖等你、夜。

## 判斷
跟目標圖最大的差距不在貼圖，而在**光的處理與最後一道畫面處理**：
- 沒有光暈，也沒有空氣感。
- 天空泛白，顏色不統一。
- 沒有逆光的金邊和光束。
- 地板的光斑是單色的。

## 做了什麼
| 項目 | 做法 |
|---|---|
| 最後一道畫面處理 `post.js` | 場景畫進 HDR 浮點畫布（4× MSAA 抗鋸齒），接著做五件事：① 亮部擷取（門檻 1.4，只抓太陽、燈）；② 6 層光暈；③ 從太陽往外的徑向光束；④ ACES 柔和壓高光，曝光 0.82；⑤ 調色：飽和 1.12、對比 1.06、暗部偏藍紫、亮部偏金，再加暗角、底片顆粒。`?post=0` 可關掉。 |
| 雲海世界改用 Codex 畫的全景 | `tex/world_clouds.webp`：飽和藍天、金邊積雲、蓬鬆雲海，太陽在水平 56%、略高於地平線。和其他五個世界同一種畫風。原本程式畫的天空與雲海留著，`?sky=proc` 可切回。 |
| 天空 shader 輸出線性值 | 畫進浮點畫布時才不會轉兩次 sRGB。只有太陽核心附近會推過 1，交給後製發光，雲頂不會閃成雜點。 |
| 環境貼圖 | 每個世界的全景用 PMREM 轉成環境貼圖。石板、門框、門板、女孩的反光與環境光都跟著世界走，強度 0.55，夜裡降低。`?envmap=0` 可關掉。 |
| 輪廓光 | 女孩（1.4）、門框（0.6）、門板（0.5）加上菲涅耳金邊，顏色跟太陽走。 |
| 地板 | 光斑亮處偏金，偶爾帶粉；石板顏色偏暖，石縫淡一點。陽光整體降約 13%，免得地板過曝。門前地面光降到原本的 30%，花瓣自發光降低（之前在光暈下變成白色短線）。 |
| 壞像素（NaN） | 來源已找到並修好：門前地面光的 `pow(vUv.y, 2.2)` 在平面邊緣遇到極小的負值就變 NaN，經光暈擴散成整片黑。另外把輪廓光的 `pow` 也夾到 0–1。後製擷取時仍保留 `isnan`／`isinf` 歸零當保險。 |

## 效能
- 1080p、pixel ratio 0.6（1152×648）：約 4.1 ms／格，比之前的 5.9 ms 快。
- 原因：雲海世界不再做雲海步進，省下的時間比後製多花的還多。

## 還可以做
- 雲海全景是靜態的。程式版的雲海會跟著走路捲動，這個版本沒有；之後可以讓全景左右緩慢漂移，或疊一層薄雲往後捲。
- 女孩模型的細節與畫風：目前是 3D 模型，目標圖是手繪。可以考慮加卡通描邊或色階化。
