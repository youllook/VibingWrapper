# 夢境之門（dream-doors）· 0 分析做法與預期效果

目標圖：`target.png`（＝`../infinite-series/s11.png`，無限系列「先做」那排；2026-11-28 用戶點名「來做門」）。

## 畫面讀出來的東西
- 一條**懸在雲海上的石板步道**，沒有牆、沒有屋頂；一扇接一扇**獨立的門框**橫跨步道，往消失點排到無限。
- 每扇門兩片門板往外開，材質各不同：和風格子窗木門、鐵灰保險庫門（圓轉盤）、木板門、彩繪玻璃門…
- 半開的門後**是另一個世界**：燈塔海岸（白天）、雪地、月夜湖面。門後的光灑到步道上，帶著那個世界的顏色。
- 近景：剛穿過的那扇門的門板，貼在畫面左右兩側、糊掉（動態模糊）。左上有一枝櫻花垂進畫面。
- 主角：短髮女孩、背影、斜背包，走在左下三分之一。花瓣從門縫飄出、散在地上。
- 右上是乾淨的天空＋雲海（HUD 空間）。

## 無限怎麼成立
- 鏡頭跟主角**固定**，主角原地走（跑步機式），**步道與門框往鏡頭移動**；過了鏡頭的門回收到最遠處重生（物件池約 14 扇，間距 6 m → 看得到 ~80 m，再遠交給霧＋縮小的剪影門）。
- 每扇門重生時**隨機抽**：門型（5–6 款）× 門後世界（4–5 個）× 開門程度（關／半開／全開）。這就是「前景重複、背景微變」。
- 步道石板用貼圖沿 Z 捲動，接縫天然無限。雲海用程式體積雲在下方慢速飄，天空幾乎不動。

## 門後世界（最關鍵的技術點）
- 不真的渲染五個場景。每扇門的開口裡放一片「入口面」，shader 用**視線方向去讀那個世界的全景圖**（cubemap／等距圓柱）——走近時視角在變，門後景物會跟著產生正確的視差，看起來像門後真的有空間。
- 全景圖由 Codex 生（同畫風，海岸燈塔／雪原／月夜湖／夏日麥田／海底…），一張 2K 即可。
- 地上的「世界光」：每扇半開的門在門口地面放一片加法混色的光斑（顏色＝該世界主色），跟著開門角度變大變小。
- 穿過門的瞬間不會跳畫：鏡頭永遠不進入門後世界，人是**從門框中間走過**，門後世界只在門板開口裡看得到。

## 分層
| 層 | 內容 | 速度感 |
|---|---|---|
| 近景 | 剛穿過的門板（滑出畫面兩側＋動態模糊）、櫻花枝、飄落花瓣 | 最快 |
| 中景 | 一扇扇門框、門板開合、門後世界、地上光斑 | 中速 |
| 遠景 | 縮小的門框剪影一路到消失點、亮白的盡頭光 | 慢 |
| 天空 | 粉藍＋暖金漸層、雲海、微塵 | 幾乎不動 |

## 素材策略
- **門框與門板 → Tripo 生成**（Codex 先出正面去背圖，每款一張），做舊木頭、鐵門轉盤這類質感交給生成；門板要能開合，所以生成後在 Blender 把門板拆成獨立件、樞紐設在邊上。
- **步道、門口光斑、入口面、雲、花瓣 → 程式**（雲霧光一律程式，規則）。
- **櫻花枝 → Tripo 或 Codex 去背圖做成貼片**（近景、略糊，貼片就夠）。
- **門後世界全景 → Codex 生圖**。
- **女孩 → Tripo 生成＋綁骨**（同滑板下坡的流程），走路動作見下方待決事項。

## 預期效果與風險
- 預期：一眼看出「在一條夢裡的走廊上一直走下去」，每扇門開出不同的世界，花瓣從門縫飄出來。
- 風險 1：**人物**——生物細節是已知瓶頸；但這支是小背影，跟滑板下坡同級，可控。
- 風險 2：**門後全景的接縫與畫風**——Codex 生全景圖不一定能無縫，可能要先生寬圖再自己補成圓柱貼圖（只需要看得到門後前方約 ±60°）。
- 風險 3：內顯效能——門框 14 扇×Tripo 面數，要重拓撲到每款 5 千面內；入口面 shader 很便宜。

## 狀態對應（步驟 5 細做）
待命＝慢步；思考＝遠處的門一扇扇亮起、門縫透光；執行＝快步（小跑），門提早整排彈開，花瓣變多；收尾＝放慢、天色轉金；等你＝她停在一扇關著的門前、回頭看；不在＝夜裡，步道兩側亮起小燈、雲海映月光，門後世界都換成夜景。
