# 任務：為「星圖」桌布主題發想三個新構圖

## 背景
星圖（DesktopPet）是 Windows 桌面桌布引擎，每個主題是一張固定鏡頭的氛圍場景，
畫面會隨 AI 工作狀態（待命／思考／執行／收尾／等你）產生細微變化。
現有主題：沖繩珊瑚礁水母、霧林剪影、十六位像素山丘、FFT 湧浪海面、鷗航灣空拍、
深淵之眼（巨眼＋安康魚）、大海怪（漁夫肩後看暴風海、巨魷眼破水而出）、沙蟲（石拱框景＋破土沙蟲）。

## 風格原則
- 氛圍優先於物理光學，光可以違反物理。
- 固定鏡頭、電影感、有「巨大事物緩緩現身」的戲劇張力；前景／中景／遠景分層清楚。
- 雲、霧、煙、水霧由程式做，所以圖中這些要是柔和的密度感。
- 不要與上面現有主題重複（不要再是巨魷、沙蟲、水母、巨眼）。
- 畫面右上角要留一塊較乾淨的區域（放 HUD），整體 16:9。

## 要你做的事
1. 想出三個彼此差異大的新主題構圖（不同環境：例如沙漠／雪原／太空／城市／森林／水下等，自行選）。
2. 對每個主題用圖像生成工具各產生「一張」16:9 橫幅概念圖（越接近 1920x1080 越好），不要寫程式畫圖。
3. 圖檔依序命名 concept1.png、concept2.png、concept3.png，放在目前資料夾。
4. 另寫 concepts.md：每個主題一段——名稱、一句話鏡頭描述、構圖分層（前／中／遠）、
   會動的元素、對應 AI 五種狀態的變化、你實際用的圖像 prompt。
