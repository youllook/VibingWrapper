# 任務：為「星圖」桌布發想三個「麥塊（Minecraft）世界＋苦力怕（Creeper）」新主題構圖

## 背景
星圖（DesktopPet）是 Windows 桌面桌布引擎，每個主題是一張固定鏡頭的氛圍場景，
畫面會隨 AI 工作狀態（待命／思考／執行／收尾／等你）產生細微變化。
已有主題：沖繩珊瑚礁水母、霧林剪影、十六位像素山丘、湧浪海面、鷗航灣空拍、深淵之眼、大海怪、沙蟲。
上一輪已發想：雪原鐘塔巨像、軌道帆城、雨城天鯨（本輪不要重複）。

## 本輪主題：麥塊世界，苦力怕必須是畫面主角之一
- 世界是方塊體素風格（立方體地形、方塊樹、方塊雲、方塊水），但打光與氛圍要有電影感，
  可用景深、體積光、暮色、霧，不是平淡的遊戲截圖。
- 苦力怕（綠色、方塊身體、四隻短腳、哭喪般的臉）要在畫面中清楚可辨；
  可以是一隻、一群，或巨大化，由你決定戲劇性（例如：悄悄靠近、從洞穴探出、遠方成排剪影、站在窗外）。
- 氛圍優先於物理光學，光可以違反物理；要有「即將發生什麼」的張力。
- 固定鏡頭，前景／中景／遠景分層清楚；霧、煙、雲層由程式做，圖中要是柔和密度感。
- 畫面右上角要留較乾淨區域（放 HUD），整體 16:9。
- 三個構圖環境與鏡位要差異大（例如：夜晚室內窗邊／洞穴礦坑／高空俯瞰地表／下界／末地…自行選）。
- 不要出現文字、UI、血條、物品欄，不要真實人物。

## 要你做的事
1. 想三個彼此差異大的構圖。
2. 對每個用圖像生成工具各產生「一張」16:9 橫幅概念圖，不要寫程式畫圖，一張一張依序生成。
3. 圖檔命名 mc1.png、mc2.png、mc3.png，放在目前資料夾。
4. 另寫 concepts.md：每個主題一段——名稱、一句話鏡頭描述、構圖分層（前／中／遠）、
   會動的元素、對應 AI 五種狀態的變化（苦力怕怎麼對應狀態，例如「等你」＝快爆炸前閃白）、你實際用的圖像 prompt。
