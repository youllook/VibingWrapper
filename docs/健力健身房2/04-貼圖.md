# 健力健身房 2 — 04 材質與環境光

這版的底圖本身就是成品質感，04 只處理 3D 的部分：**鏡中倒影**和**吊扇**。目標是讓倒影像目標圖那樣是「背光的暗剪影＋暖色輪廓」。

對照：[04-倒影.jpg](04-倒影.jpg)（目標圖／03／04，都是模糊 2）、[04-日夜.jpg](04-日夜.jpg)。

| 項目 | 03 | 04 |
|---|---|---|
| 倒影的光 | 窗光 9、半球光 0.9、燈泡 10 → 選手整個被照亮、偏橘 | 窗光 14 從選手身後左上方打（只亮輪廓）、半球光 0.25、燈泡 2.5、鏡頭側補光 0.1 |
| 架子 | 受光、反射白天全景 → 發灰，比目標圖明顯 | 不受光的近黑，融進鏡中的柱子 |
| 槓片 | 灰 | 近黑金屬、低反射（像素約 RGB 30,20,10，目標圖約 25,20,15） |
| 鏡中暖霧 | 無 | 倒影蒙一層底圖鏡面的平均色（10%），人跟房間深處融在一起 |
| 吊扇 | 偏灰 | 暖褐；晚上壓到一成多亮 |

- 鏡中倒影的參數集中在 `LAYOUT.mirror`（`sun`、`hemi`、`bulb`、`fill`、`exp`、`haze`），網址 `?tune={"mirror":{...}}` 可以直接試。
- 倒影模糊用模糊 2（用戶 2026-10-31 選）。
