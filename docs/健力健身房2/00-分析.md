# 健力健身房 2 — 00 分析做法與預期效果

目標圖：[../gym-brainstorm/gym4.png](../gym-brainstorm/gym4.png)（1672×941，低角度看整間倉庫健身房，選手只出現在鏡子裡）。
與第一版的差別：第一版的主角是選手；這一版的主角是**光**。重點有三個：
1. **光影**：高窗斜射進來的光束，地上一格一格的窗格光斑。
2. **灰塵反光**：光束裡飄著的粉塵，飄進光裡就亮起來。
3. **鏡中選手**：選手不在畫面裡，只在大鏡子裡，是模糊的倒影。

**這版要解決的問題（2026-10-31 用戶）**：第一版選手動作與近景都不夠細緻，表達不了細節。
所以這版的取捨是：近景細節交給高解析的平面圖；選手退到鏡子裡、糊掉，只需要看得出動作的節奏，不用經得起細看。
用戶已定：做法照下面推薦；紅黃白燈當裁判燈，收尾時三顆一起變白。

## 一句話

傍晚的倉庫健身房。陽光從高窗斜切進來，粉塵在光裡慢慢翻。鏡子深處有個模糊的人影在深蹲：Claude 在做事，他就在練。

## 為什麼這張比第一版好做

- **鏡頭固定，幾乎所有東西都不動**：牆、器材、長凳、海報都是靜物，用 Codex 的平面圖就夠了，不必建 3D。
- **選手是模糊的**：第一版最難的是人（手臂姿勢、表情、走位穿模）。這一版他在鏡子裡、又糊掉，這些缺點全部看不到。
- **會動的只剩光、灰、鏡中人**，這三樣都適合用程式做，而且就是這張圖的重點。

## 做法（推薦）：平面背景 ＋ 程式光影 ＋ 鏡中 3D 人

| 層 | 做法 |
|---|---|
| 背景圖 | Codex 修出「乾淨版」：去掉光束、去掉鏡中人、去掉吊扇扇葉，放大到 1920×1080 以上。另外做一張夜晚版（窗外暗、燈泡亮）。 |
| 光束 | 螢幕空間的體積光：從三組高窗往右下斜射，窗格會在光裡切出暗條紋。強度跟時間和狀態走（思考時有雲飄過，光忽明忽暗）。 |
| 地上光斑 | 窗格形狀的光斑投在地上，隨太陽角度慢慢挪。 |
| 粉塵 | 2–3 千顆粒子。不在光裡幾乎看不見，飄進光束就亮成一顆小亮點；前景再加幾顆大的、失焦的光斑。收尾時「哐」一聲揚起一團。 |
| 鏡中選手 | 把第一版的選手、槓、架另外畫進一張小畫面，模糊後貼進鏡子的範圍，再疊上鏡面的髒污和窗光反射。 |
| 吊扇 | 扇葉單獨一層，用程式轉，加動態模糊。 |
| 裁判燈、白板 | 左牆的三顆燈會亮（收尾時全白）；白板照第一版用程式寫真資料：深蹲 120／臥推 100／硬拉 110／總和 330，加上今天完成次數的正字。 |

**Tripo 不用再建模。** 第一版的選手 GLB（含 8 段動作）直接拿來用。槓、架是程式生成的，也沿用。
其他東西（長凳、槓片架、水桶）都是靜物，平面圖就夠。如果之後想讓前景長凳有一點視差，再考慮建模。

## 狀態對照（動作沿用第一版的 8 段）

| 狀態 | 鏡子裡 | 光與灰 |
|---|---|---|
| 不在 | 空架，沒有人 | 光束靜止，灰塵很少，最安靜 |
| 待命 | 選手坐在鏡中的長凳上休息、抹鎂粉 | 正常 |
| 思考 | 走到槓前，深呼吸 | 有雲飄過，光束忽明忽暗 |
| 執行 | 一下接一下地蹲 | 光束最強，粉塵最多（蹲起時揚起一點） |
| 等你 | 扛著槓站住不動 | 裁判燈慢慢呼吸 |
| 收尾 | 掛槓 | 三燈全白，粉塵爆開，白板加一筆 |

日夜：白天是夕陽斜光（＝目標圖）；晚上窗外深藍，光束換成燈泡的暖色光暈，粉塵只在燈泡附近亮。

## 預期效果與風險

- **最像目標圖的是光和灰**，這兩樣純程式做，可以一直調到對。
- **鏡中人糊的程度要拿捏**：太清楚，3D 感會穿幫；太糊，就看不出在深蹲。先做三個模糊程度給您挑。
- **夜晚版**要 Codex 另外生成，跟白天版的構圖要完全對齊（同一張改光，不能重畫）。
- 效能：背景只是圖，鏡中人用小畫面渲染，預估內顯 8 ms 以內，比第一版輕。

## 要先確認的事

1. **這個做法可以嗎？**（背景全用平面圖，3D 只用在鏡中人）
2. **左牆那組紅黃白燈**：真的比賽沒有黃燈。要當成裁判燈（收尾時三顆一起變白），還是只當裝飾？

確認後進入 01：請 Codex 修出乾淨版背景（無光束、無鏡中人、無扇葉）＋夜晚版，並把要動的範圍（窗、鏡子、光斑、吊扇、燈、白板）標成遮罩。
