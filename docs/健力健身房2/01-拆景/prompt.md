# 任務：把 gym4.png 整理成可做動態桌布的底圖與遮罩

本資料夾的 `gym4.png`（1672×941）是一張健身房桌布的目標圖。之後會用程式重新做出三樣會動的東西：
**窗光光束與粉塵**、**鏡子裡模糊的選手倒影**、**吊扇扇葉**。所以需要把這些從圖裡拿掉，得到乾淨的底圖。

可以用內建的圖像生成／編輯工具，也可以寫 Python（PIL、numpy、opencv）做遮罩與合成。
**每張輸出都要是 1672×941，物件位置必須與原圖完全對齊。** 建議做法（第一版驗證過）：生圖只負責補被拿掉的區域，
最後用遮罩把補好的區域接回原圖，其餘像素保持原圖不動。全部完成後建立空檔 `.done`。

## 底圖（RGB）

1. `plate-day.png`：同一個鏡頭、同一個傍晚光線，但
   - 拿掉**空氣中所有的體積光束**（從高窗斜射下來的光柱、霧狀的光），也拿掉**空中飄浮的粉塵亮點**。牆、柱、器材上原本被陽光照亮的地方可以保留。
   - **地上的窗格光斑保留**（地板上一塊塊亮的格子）。
   - **鏡子裡的選手、槓鈴、槓片、深蹲架全部拿掉**，鏡中補成模糊的健身房內部倒影（柱子、高窗、燈泡、遠處器材），保持原本的失焦與暖色。鏡框、鏡子下緣的鐵框保留。
   - **吊扇的扇葉拿掉**，只留中間的馬達與吊桿，扇葉後面補成鐵皮屋頂與桁架。
   - 白板上的字與正字全部擦掉，變成有點髒、留有擦痕的空白白板（框、筆槽、筆保留）。
   - 海報、紅黃白三顆燈、壁燈、器材、長凳都不動。
2. `plate-shade.png`：與 1 相同，但**太陽被雲遮住**：地上的窗格光斑消失（地板變成一致的陰影暗色），
   牆柱上的直射陽光也消失；高窗本身仍然是亮的（陰天的天光），壁燈照常亮。
3. `plate-night.png`：與 1 相同的構圖，改成**夜晚**：高窗外是深藍夜色（看得到窗框），沒有任何陽光與光斑；
   所有鎢絲壁燈與天花板吊燈亮著，暖黃光暈打在附近的磚牆上；鏡中倒影是暗的，只映出幾顆燈泡的光點；
   紅黃白三顆燈**全部關著**（暗的燈罩）；整體偏暗但磚牆、地板紋理看得出來。物件位置一律不動。

## 遮罩（L 灰階，255＝範圍內，邊緣可以有 2–3 px 的柔邊）

4. `mask-windows.png`：所有高窗的玻璃範圍（左上兩組、中上一組、鏡中倒影裡的窗不算）。
5. `mask-mirror.png`：鏡面玻璃的內部範圍（不含鐵框）。
6. `mask-floor-sun.png`：plate-day 地上窗格光斑的範圍（可以用 plate-day 與 plate-shade 的亮度差做出來）。
7. `mask-fan.png`：原圖扇葉掃過的整個圓盤範圍（以馬達為圓心），另外在 `fan.json` 記下馬達中心座標與扇葉半徑（像素）。
8. `mask-lamps.png`：紅、黃、白三顆燈的燈罩（三個圓）；在 `lamps.json` 記下三顆燈的圓心與半徑，順序紅、黃、白。
9. `mask-board.png`：白板可寫字的內部範圍；在 `board.json` 記下四個角的座標（左上、右上、右下、左下）。
10. `mask-bulbs.png`：畫面中所有壁燈與吊燈燈泡的發光點（每顆一個小圓）；在 `bulbs.json` 記下每顆的圓心與半徑。

## 驗收
