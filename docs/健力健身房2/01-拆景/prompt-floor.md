# 補一張遮罩：整個地板

本資料夾 `gym4.png`（1672×941）。另做一張 `mask-floor.png`（L 灰階，1672×941，255＝地板，邊緣 2–3 px 柔邊）：
- 範圍是**畫面中所有看得到的地板表面**（橡膠地墊／水泥地，含亮的窗格光斑與暗處），一直延伸到牆腳、器材底部、鏡子下緣鐵框的底線。
- **不含**：右下角的長凳（含椅腳、橫桿與它旁邊地上的小槓片）、左側站在地上的器材（槓片、架子、桶子、木箱、鐵架）本身、牆、鏡子與鏡框。地板只算露出來的部分。
- 另外產 `check-地板.png`：把遮罩用半透明青色疊在 gym4.png 上。
- 用 Python（PIL／numpy／opencv）或你內建的工具都可以；位置必須與原圖完全對齊。完成後建立空檔 `.done-floor`。不要改動其他檔案。
