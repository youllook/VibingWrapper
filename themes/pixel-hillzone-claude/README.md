# 十六位像素熱帶丘陵・Claude（pixel-hillzone-claude）

風格競稿 `16bit-pixel`（Sonic Mania 風）的 Claude 版。需求單：`studio/briefs/16bit-pixel/brief.md`；
目標圖：`studio/runs/16bit-pixel/target.png`（本機，不進 git）。

## 做法
真的低解析度：整張畫在 480×270 的**調色盤索引**緩衝區，最近鄰放大到螢幕。

| 層 | 內容 |
|---|---|
| 天空 | 擬合色盤裡的 11 階天藍，交界用 Bayer 抖動；太陽是階梯色環；夜晚有星星 |
| 雲 | 生成素材，緩慢飄移、循環；overcast 多出的雲先用抖動溶入再變實心 |
| 遠景 | 遠山、拱岩、小島、懸崖瀑布（生成素材）；遠的用「混霧後找最近色盤色」做空氣透視 |
| 潟湖 | 程式畫的 7 階水色＋短橫反光，反光是**調色盤循環**（每段有自己的相位）；島與懸崖有隔行倒影（混水色後找最近色盤色），岩腳和山丘邊有閃爍浪花 |
| 瀑布 | 懸崖素材裡的淺藍／白像素改成循環索引：亮帶往下流，底部水花閃爍 |
| 山丘 | 程式畫的棋盤土（亮格上緣受光、右緣陰影、第 5 排以下整排變暗）＋鋸齒草頂、草裡的小花 |
| 棕櫚、灌木 | 生成素材，分在向日葵前後兩層；每格重畫，一行一行整像素錯開＝隨風擺（越上面擺越大，風力隨狀態） |
| 小生物 | 海鷗成群飛過、潟湖裡魚躍出水（水花＋漣漪）、瀑布底水霧上飄、水面閃光、向日葵旁的蝴蝶；夜晚換成螢火蟲（不受夜色盤影響的固定亮色）；下雨時都躲起來 |
| 向日葵 | 程式畫（5 個 session 位置），每格重畫 |
| 打光（2026-10-23） | 素材的法線貼圖在 `normals/`，用 [Sprite Normals](https://github.com/Hugo-Dz/spritefusion-sprite-normals)（MIT）產生（`spritefusion-sprite-normals sprites/*.png --output-dir normals`，預設參數；雲不打光）。每個基本色多出 5 組調色盤副本：受光、背光、深背光、燈照強、燈照弱。像素依法線朝向太陽的程度換成對應副本，所以仍然是調色盤畫。太陽（夜裡是月亮）依時鐘走一道弧，早上從左邊照、下午從右邊照；陰天減弱。晚上每朵開著的向日葵是一盞暖燈，照亮朝向它的峭壁、樹幹、草地。烘好的背景層只在太陽或燈的狀態變了才重算 |

狀態全部是**換色盤**（每格對 48 色＋循環色做一次轉換），不是疊半透明：overcast 降飽和、storm 壓暗＋雨＋整片色盤一格一格的閃電、waiting 傍晚暖色、夜晚靛藍；clearing 天邊出現階梯彩虹。

向日葵：clear 隨風晃、overcast 低頭、storm 花盤旋轉、clearing 冒星光、waiting 轉正面上下彈跳；沒有對話的位置是花苞。

## 素材
`sprites/`：Codex 生成的洋紅底像素素材（prompt 在 `studio/briefs/16bit-pixel/claude/sprite_prompts/`，
`BG=magenta studio/mac/gen_sprite.sh`），再用 `studio/blender/pixel_key.py` 去背、切成邏輯像素格（每格取眾數色）、鎖到 `palette.json`。
`palette.json`：`studio/analyze/palette.py` 從目標圖在 480×270 擬合的 48 色。

## 效能
CPU 繪製，480×270：storm＋5 朵旋轉向日葵＋擺動 **5.8 ms／格**（含上傳畫布；只加靜態細節時 1.65 ms）。
加打光後（2026-10-23，內建瀏覽器量）：白天約 3.5 ms／格，夜晚 5 盞燈約 6.6 ms／格。測試網址參數 `?hour=7.5`。
