# 海月（jellyfish）

寫實的海底：水深約 9 m 的沙地，鏡頭貼著海底（離沙 1.1 m）微微往上看。水面在頭頂起伏，光柱斜斜照下來，沙地和海草上有焦散在流動。左右兩片海草床被水流梳向同一邊，中間留一片開闊的沙地。每個 Claude session 是一隻海月水母，遠處還有幾隻小的在霧裡漂。

- 入口：`index.html`（WebGL2，全程序式，沒有外部函式庫或圖檔；2026-10-15 由 Claude 設計）
- 測試介面：`window.theme`（也掛 `window.jellyfish`）；`theme.simulate(秒)` 只推進場景、不畫（慢機器上跳到穩定狀態用）
- 預覽：`http://127.0.0.1:47321/themes/demo.html?style=jellyfish`
- 素材盤點與缺口：[素材.md](素材.md)。水母目前是程序式暫代，正式模型請 Gemini 4 Argon 做（需求單在雲端硬碟 `Gemini4Argon/MoonJelly_Gemini/`）

## 狀態 → 參數

定義在 `index.html` 的 `PARAMS`（範圍）和 `STATES`（目標），切換規則跟其他主題一樣（平滑、可中斷、最長 4 s）。

| 狀態 | 意思 | 海底的樣子 |
|---|---|---|
| `clear` | 閒置 | 水清，光柱柔和，焦散清楚，海草慢慢擺 |
| `overcast` | Claude 在想 | 水變混、海雪變多，光柱和焦散變淡 |
| `storm` | Claude 在跑工具 | 暗流：海草被推斜、整片一波一波倒，水面翻動讓焦散跳得快，氣泡大量冒 |
| `clearing` | 剛做完 | 水最清，光柱和焦散最亮 |
| `waiting` | 等你 | 水流停住，畫面稍暗，同一顆 等你 星（x≈58%、y≈80%，約 2.9 s 一次脈動） |

參數：`turbidity`（混濁）、`current`（水流）、`shafts`（光柱）、`caustics`（焦散）、`chop`（水面擾動）、`bubbles`、`brightness`、`beacon`。

## 水母（session）

`JELLY_SPOTS` 五個位置各對應一個家（16:9 畫面上的位置＋距離），避開左邊三分之一。每隻生殖腺顏色不同：淡紫、粉、桃、淡藍、紫。沒有 session 時，位置 0 那隻跟著整體狀態。進場時從更深、更遠的霧裡游過來，淡入淡出 2.5 s。

| session 狀態 | 水母 |
|---|---|
| `clear` | 每秒約 0.55 次脈動，慢慢漂 |
| `overcast` | 0.75 次，游得比較用力 |
| `storm` | 1.15 次，逆著暗流用力游 |
| `clearing` | 0.42 次，滑行 |
| `waiting` | 0.3 次，幾乎懸停，傘和生殖腺跟 等你 星一起微微發光（夜裡比較明顯） |

動作：一次脈動＝快速收縮（24%）、慢慢舒張（54%）、停一下；收縮從傘頂傳到傘緣。收縮產生推力（沿傘的軸），有阻力、稍微比水重（停下時會慢慢沉）、轉向追著家附近一個慢慢漂的目標點。口腕和傘緣觸手讀「傘過去 1.8 秒的位置」（水的座標系，所以跟著水漂不會拖，自己游才會拖），游的時候往後拖、轉彎時甩開。

## 日夜

台北的太陽高度（跟其他主題同一套）。太陽光進水會折射（Snell），太陽低也照得很陡；早上光往右走、傍晚往左。夜裡是月光，曝光拉高，海雪和生物發光的小點比較看得到。`?day=1`／`?night=1` 固定 10:30／22:00。

## 做法

- **線性光＋4× MSAA 浮點目標**，最後一個 pass 才 tone map（ACES）＋暈影＋抖動。所有 shader 輸出線性值，透明物件用預乘 alpha，光柱是加法。
- **水**：沿視線分頻道消光（紅最快被吃掉），散射色往上看比較亮、看向光源方向比較亮；任何一點收到的光＝水面光 × 依深度的分頻道衰減。
- **海底只算一次**：鏡頭不動，所以海底（沙丘 fbm、遠處上升的坡、岩石＝帶 noise 的圓丘）在啟動／改視窗大小時 ray-march 一次，把距離、法線、岩石遮罩、反照率、AO 存進 G-buffer（2 張 RGBA16F）；每格只算焦散和光。另外 bake 一張 512² 的高度圖給海草貼地。海草床底下的沙比較暗（碎屑）。
- **焦散**：兩層 Worley 邊緣、特徵點會動、domain warp。
- **水面**：從下往上看，起伏的法線；法線剛好轉進 Snell 窗（臨界角 48.6°）的地方透出天光，其他地方全反射暗的水。
- **海草**（照 Posidonia／Zostera 照片重做）：一株 6 片葉子從同一點扇開（外圈長、斜，內圈短、直）；寬約 1 cm 的扁帶、沿長度扭轉；沿圓弧彎、被水流梳向 +x；整片草床一起跟著長波（monami）起伏，每片再加一點顫動。逐像素：每片色相不同（鮮綠到橄欖）、外圈老葉尖端枯褐、附生物白斑（遠了會淡出）、葉脈、背光時透出黃綠色。按螢幕面積分配株數（近的密、遠的省），遠處葉子至少 1.4 px 寬避免閃爍；varying 用 `centroid`（MSAA 取樣點在三角形外會外插，`pow(負數)` 變 NaN，出現黑白雜點）。
- **光柱**：半解析度、16 步沿視線積分，每個取樣點往光源方向找到水面上的光柱圖樣（會飄），Henyey–Greenstein 前向散射；最後一個 pass 用 4 個 bilinear 取樣柔化後加回去。
- **粒子**：海雪（近的失焦變大變淡）、三道氣泡（越往上越大）、生物發光小點。

## 效能

1600×900、4× MSAA：Intel UHD 630 約 45 ms（2026-10-15，headless Chrome 選到內顯）；海底 bake 後，主要成本是海草（約 20 ms）、海底焦散（約 13 ms）、光柱（約 7 ms）。獨顯應該在預算內，待實機量。
