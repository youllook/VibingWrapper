# 稻田（paddy）

2026-10-02 從「寫實草原」（themes/meadow-real）複製改成屏東老家的稻田。跟寫實草原不同的地方：

- **稻子**：草葉沿用寫實草原的做法，色調是一般的綠；約 325 株直立、青黃半熟的稻穗（程式畫的穗軸＋往上斜的穀粒），跟著莖在風裡傾斜，遠處淡入田裡。
- **地形**：拉平；眼高 1.65 m。
- **遠景**：三層同一藍色調的山（越近越深），山面有山脊／山谷的明暗，稜線有樹冠般的鋸齒；山腳一排樹叢。
- **天空**：深藍；大太陽（光強 ×1.2、收緊的光暈）；雲影偶爾飄過。
- **雲**：用草原那棵樹的做法——一團團面向鏡頭的柔邊小團塊，法線依雲團往外散開、照真實太陽方向受光，雲底切平；會藏在山後面。左上角一朵大積雲跟著忙碌程度約一分鐘長大／縮回（`busy` 參數），其餘 10 朵隨風飄。
- **狀態**：天空永遠晴朗；忙不忙看風（最強約寫實草原的 70%）、左上大雲、小木屋的炊煙。剛做完不再把太陽拉低。

試過又拿掉的（素材留在 scratchpad，沒進 repo）：Codex 的照片稻穗、農舍、照片雲；電線桿（`polesRow` 已從程式移除）。

以下是原本寫實草原的說明，大部分仍適用。

# 寫實草原（meadow-real）

寫實風格的草原：幾十萬片「真的」草葉（每片都是幾何體，在 GPU 上彎腰）、起伏的草地、遠處的丘陵與樹林帶、有太陽／雲／霧的天空；風是會轉向的風場加上一道一道掃過草地的陣風前緣。強陣風會捲起枯葉、斷枝和碎草。每個 Claude session 是遠處稜線上的一間小木屋。

- 入口：`index.html`（WebGL2，三個 pass：近景草葉（instanced，7 段）→ 遠景草葉（instanced，1 段，頂點打光）→ 地面網格 → 天空（全螢幕，畫在遠平面、深度測試，只算草葉沒蓋到的像素）；無任何外部函式庫，離線可用；由 Claude（Fable）設計）
- 技術來源：**SimonDev 的 Quick_Grass**（MIT，github.com/simondevyoutube/Quick_Grass；影片「How do Major Video Games Render Grass?」），它本身整理自 Sucker Punch **Ghost of Tsushima 的 GDC 2021 演講**。移植的部分：
  - 每片草葉是低頂點數的 triangle strip（近 7 段 16 頂點、遠 1 段 4 頂點），用 instancing 畫；每片的位置抖動、朝向、高度、寬度、彎度、顏色都是頂點著色器裡「對草根位置做 hash」算出來的，不存每片資料
  - 草葉是一條依高度 ease 的曲線，再被風往風向彎；風 = 慢慢轉向的方向場 × 經過 ease 的強度場（陣風會「啪」地壓下去），再加上 JS 排程的陣風前緣
  - 「圓葉片」法線：兩條繞葉軸 ±0.3π 的法線，沿寬度混合；葉中線的折痕變暗；根部 AO；根→尖的顏色漸層；wrap diffuse ＋ 假的背光透光（backscatter）＋ Blinn-Phong 光澤；法線隨距離往 UP 混，遠處讀起來是一片地毯
  - 側面看到的葉片在 view space 加厚（不會消失成一條線）；葉尖保留最小寬度，半解析度下不會碎成點
  - 兩級 LOD：近（< 11 m）每像素打光，遠（11–70 m）每頂點打光、顏色收斂到地毯色，70 m 外草葉縮到 0、交給地面網格的「地毯」著色
- 其他都是這個主題自己的：程序式地形（三個 octave 的 value noise，鏡頭附近與遠處拉平）、分析式天空（Mie 前向光暈、太陽盤、1.3 km 高的雲層、地平線霾、夜晚星月）、三層稜線＋針葉樹林帶、風車、等你星、狀態機、輪詢、日夜、`wpPause`、`bench`。
- 測試介面：`window.theme`（也掛 `window.meadowReal`）
- 預覽：`http://127.0.0.1:47321/themes/demo.html` → 樣式選「寫實草原」

## 狀態 → 參數

每個狀態是一組目標數值，切換時從目前的實際數值平滑轉過去（可中斷，時間依變化量縮放，最長 4 s）。定義在 `index.html` 的 `PARAMS`（範圍）和 `STATES`（目標）。

| 狀態 | 意思 | 草原的樣子 |
|---|---|---|
| `clear` | 晴：閒置 | 微風，藍天幾朵雲，草尖透光 |
| `overcast` | 陰：Claude 在想 | 風大一點，雲多、天色灰，霧氣重一點 |
| `storm` | 工作：Claude 在跑工具 | 一道一道強陣風掃過草地：前緣把草壓倒、尖端閃光，後面的草彈回來（看得到一道波）；雲層厚而暗 |
| `clearing` | 轉晴：剛做完 | 風停下來，太陽拉低、光變成金黃色（也會把太陽的高度拉到 ≤ 9°） |
| `waiting` | 等你：Claude 在等你回答或批准 | 幾乎不動，天空暗下來，同一顆四芒 等你 星（x≈58%、y≈80%，約 2.9 s 一次脈動，跟其他主題同位置同節奏） |

參數：`sway` 基本風力、`gustRate` 每秒陣風數、`gustStrength` 前緣彎度、`cloudCover`、`skyBrightness`（1 藍天 … 0 暴風暗天）、`warmth`（金光）、`haze`（空氣透視濃度）、`beacon`（等你星）。

## 日夜

台北的太陽高度（跟其他主題同一套 `sunAltitude`）。鏡頭面向南南東，太陽早上在畫面左前、下午移到右前（`sky().az`），高度是真實高度（最低 6°，不然會沒有主光）。夜晚月光當主光（藍白、約白天 4%，曝光拉 2.4 倍）、天空深藍有星、月亮在右上；草讀得出來，不會黑。`?day=1`（齒輪「白天模式」）把時鐘固定在 10:30。

## 小木屋（session）

2026-10-02 由風車改成小木屋（木牆、深色人字屋頂、煙囪、一扇窗一扇門）。`state.json` 的 `sessions` 五個位置各對應稜線上一個固定位置（`MILL_HOMES`：螢幕 x 0.38／0.84／0.23／0.50／0.93，避開 等你 星那一欄和左邊桌面圖示那一側），大小不同。沒有任何 session 時，位置 0 留一間跟著天空狀態的小屋。進出 2.5 s 淡入淡出。程式裡沿用 mill 的命名（`mills`、`MILL_STATES`），`speed` 現在是炊煙量。

| session 狀態 | 小木屋 |
|---|---|
| `clear` | 一縷細煙 |
| `overcast` | 炊煙穩定 |
| `storm` | 濃煙往下風處斜飄，窗子亮燈 |
| `clearing` | 煙散了 |
| `waiting` | 窗燈跟著 等你 星一起脈動 |

夜晚、黃昏、暗天每間都亮窗。

## 雜枝殘葉

強陣風（`strength ≥ 0.35`）的前緣掃過近景時會捲起枯葉（橢圓、有葉脈）、斷枝（帶分叉的細枝）和碎草，跟著陣風飛、翻轉、落地後淡出；多雲有風時偶爾也飄過一片葉子。CPU 模擬、上限 260 顆、`gl.POINTS` 畫，成本可以忽略。`theme.CONFIG.skip = 'debris'` 可關掉。

## 畫面配置

- 鏡頭：固定，離地 1.30 m（`CAM_H`），往下俯 0.10 rad（`PITCH`），垂直視角 49°（`VFOV`）；地平線在畫面高度約 61% 處
- 左邊約 15% 留給桌面圖示：那一帶的風力與陣風減 55%（`calm`），草葉密度也少 45%
- 近景草葉 0.6–12 m（`Z_NEAR_BLADES`、`LOD_DIST`），遠景到 70 m（`GRASS_MAX`），地面網格到 160 m，再遠是分析式地平面，丘陵從地面網格的輪廓線以下開始畫（沒有霧白的縫）

## 成本（2026-10-02 量測）

1920×1080（渲染 960×540，4× MSAA），**RTX 2060 SUPER**（主程式 `main.js` 用 `force_high_performance_gpu` 把 Electron 推到獨顯；量測用同一個開關。注意：螢幕接在 Intel UHD 630 上，沒加這個開關的 Electron 會落在內顯，同一張畫面要 14–17 ms）。量測時主程式同時在跑另一張桌布，數字偏高也偏抖：

| 狀態 | 中位數 | p90 |
|---|---|---|
| clear | 1.8 ms（最抖，前一輪 6.2） | 5.8 ms |
| overcast | 1.5 ms | 1.8 ms |
| storm（3 道陣風） | 2.9 ms | 3.3 ms |
| clearing | 1.6 ms | 1.8 ms |
| waiting | 1.5 ms | 1.9 ms |
| night | 2.3 ms | 2.6 ms |
| storm＋night | 2.2 ms | 2.5 ms |

單獨：天空 0.6 ms、地面 1.0 ms、近景草 2.3–4.2 ms、遠景草 0.7 ms；空跑（只 clear＋同步）0.5–1.1 ms（26 萬片：近 7.4 萬＋遠 18.7 萬）。在 Intel UHD 630 上同一張畫面是 14–17 ms，不符預算。草量在 `CONFIG.bladesHigh / bladesLow`（分布指數 `expoHigh / expoLow`，越大越偏遠處）；`theme.setBlades(high, low)` 可以即時改；`theme.CONFIG.skip = 'sky'`／`'terrain'`／`'high'`／`'low'` 可以關掉某個 pass 量成本；`theme.bench(60)` 回傳中位數／p90。

## 調整筆記

- 顏色全部是線性空間，最後過 ACES ＋ gamma（`finish()`）。ACES 會把中間調拉亮，所以暗天要給很低的線性值（暴風天頂 0.055）才會真的暗。
- 草色：`lighting()` 的 `colA–colD`（黃綠／綠／藍綠／枯黃）是根部色、`tipA/B` 是尖端色；公尺級的 `fieldMap()` 決定哪裡偏黃、哪裡枯。
- 強制來一陣風：`theme.gust(strength, frontX)`（frontX 公尺，從左往右掃）；測試多 session：`theme.setSessions([...])`（`[]` = 沒有 session；`null` = 回到 state.json）。按 `g` 也會來一陣風，`d` 開 HUD。
- 陣風形狀在 `gustAt()`：前面一個高斯峰（壓倒＋閃光）、後面一個負的淺谷（彈回、變暗），這樣在畫面上才讀得出「一道波」而不是整片一起倒。
- 已知弱點見 scratchpad 的交付報告：雲是 2D 層沒有體積、丘陵是稜線函數沒有真的地形、風車很小、近景草色偏黃、LOD 交界在陰天還看得出一點明暗差。
