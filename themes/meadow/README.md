# 草原

手繪風格的草原（1990 年代日本動畫背景的味道）：層層景深——雲朵、遠山、中景山、近處綠丘、草坡、前景失焦的草葉；一棵孤樹是視覺焦點；光從右上方低低地打過來，草葉逆光透出暖黃綠色，雲影隨風掃過草地。風一陣一陣來，陣風前緣是一道光影與彎腰的波，吹散蒲公英、搖落樹葉。每個 Claude session 是近丘稜線上的一座風車。

- 入口：`index.html`（WebGL1，四個 draw call：背景畫（天空／山／丘／遠草地／孤樹／風車／等你星）、草葉（一條 triangle strip）、花頭（point sprite）、粒子（種子／落葉／螢火蟲）；由 Claude（Fable）設計）
- 草的打光（v3）：用地面法線＋葉片橫向微傾的「圓葉片」法線打光（BotW／Ghost of Tsushima 的做法），顏色來自公尺級的「草地色圖」（黃綠／綠／藍綠／橄欖色塊），遠處退回叢共用色避免閃爍；根部 AO、尖端高光、逆光透光；夜晚月光當主光（約白天 45%），陰影抬到藍紫、不會黑。
- 孤樹（v3）：約 320 張面向鏡頭的葉叢卡片（Codex 的 `assets/leaf-clusters.png` 六格），分 7 個子叢，法線各自球面化，三段色調＋右上緣光；風分三層（樹幹彎／枝幹搖／葉片顫）。前景（v3）：約 90 張草叢卡片（`assets/grass-clumps.png` 四格），根固定、頂端隨風彎，是筆觸感的來源。
- 草（v6）：五條草帶的地線跟著起伏的地形走（共用低頻地形＋各帶自己的擺動、高度沿 x 變化），相鄰草帶互相疊蓋；最近的一條（2 m）重用 strip-1 翻轉，墊在草叢後面。草叢 150 張、草帶、樹葉卡片全部 alpha 測試＋fwidth 銳化、由近到遠畫（early-z）；天空／背景那一格改成最後畫、深度測試，被草蓋住的像素不用算。蒲公英只露頭和一小截莖。
- 草（v5）：沒有幾何草葉了。前景 1.25–3 m 是約 90 張手繪草叢卡片（Codex 的 grass-clumps.png + grass-clumps-2.png 共 8 款，隨機翻轉／旋轉／縮放／色相抖動、成叢分布，三段色調＋緣光，預乘 alpha＋fwidth 銳化邊緣）；3／5／8／14 m 是四條手繪視差草帶（grass-strip-1..4.png + 遮罩），頂端剪影隨風搖、草身不動，風以「光澤波」表現。所有草＋地面共用同一張公尺級草地色圖；遠處往山丘色靠。
- 樹幹（v5）：幾乎不動（只剩葉叢顫動與枝條微搖），錐形、根部外擴、微彎、三根主枝，樹皮分明暗帶，根部有接觸陰影。
- 雲影（v5）：三朵大積雲各自在地上投一片大而柔邊的影子（偏向雲的左下），掃過草帶、草叢、坡地與樹；陰天多、暴風幾乎全陰、轉晴散去。
- 雲（v4）：Codex 的 assets/clouds.png（六格：三朵大積雲、兩朵平底中雲、一條層雲）當貼圖，10 朵雲隨風漂移、繞回；依時段／狀態染色（陰天多而灰、底下墊一層灰幕；夜晚月光灰藍；黃昏粉橘底）。缺檔時退回程序式雲。
- 山與丘的三張圖層由 Codex 繪製，放在 `assets/`（`mountains-far.png`、`mountains-mid.png`、`hills-near.png`，同一張 3840×1080 畫布，稜線以上透明；見 `assets/README-assets.md`）。圖層缺檔時自動退回程序式山丘。
- 測試介面：`window.theme`（也掛 `window.meadow`）
- 預覽：`http://127.0.0.1:47321/themes/demo.html` → 樣式選「草原」

## 狀態 → 參數

每個狀態是一組「目標數值」，切換時從目前的實際數值平滑轉過去（可中斷，時間依變化量縮放，最長 4 s）。
數值定義在 `index.html` 的 `PARAMS`（範圍）和 `STATES`（目標）。

| 狀態 | 意思 | 草原的樣子 |
|---|---|---|
| `clear` | 晴：閒置 | 微風輕搖，大朵積雲，偶爾一顆種子飄過 |
| `overcast` | 陰：Claude 在想 | 風大一點，雲多一點，雲影多 |
| `storm` | 工作：Claude 在跑工具 | 一陣一陣的強風掃過草地：前緣是一道陽光帶＋前方一道暗影（看得到波），有些陣風吹散一大片蒲公英，樹上落葉翻滾 |
| `clearing` | 轉晴：剛做完 | 風停下來，最後的種子慢慢落下，金色的光 |
| `waiting` | 等你：Claude 在等你回答或批准 | 幾乎不動，天空暗下來，同一顆四芒 等你 星（x≈58%、y≈80%，約 2.9 s 一次脈動） |

## 風車（session）

`state.json` 的 `sessions` 五個位置各對應稜線上一個固定位置（`MILL_HOMES`，實際高度從 `hills-near.png` 的 alpha 稜線讀出），遠近大小不同，避開 等你 星那一欄、孤樹和左邊桌面圖示那一側。
沒有任何 session 時，位置 0 留一座「跟著天空狀態」的風車。

| session 狀態 | 風車 |
|---|---|
| `clear` | 葉片幾乎不動 |
| `overcast` | 穩穩地轉 |
| `storm` | 轉得快，窗子亮燈 |
| `clearing` | 慢慢停下來 |
| `waiting` | 窗燈跟著 等你 星一起脈動（白天也看得到） |

進出都是 2.5 s 淡入淡出；葉片角度是積分出來的，變速不會跳。夜晚所有風車都亮窗。

## 調整筆記

- 風場 `windAt()`、光影場 `lightAt()` 在 JS 與 shader 各一份（`COMMON`），要一起改。雲影漂移速度跟著風（`shadowDrift`）。
- 強制來一陣風：`theme.gust(strength, burst, frontX)`；測試多 session：`theme.setSessions([...])`（`[]` = 沒有 session；`null` = 回到 state.json）。
- 畫面配置：地平線 `HORIZON = 0.45`；圖層畫布貼齊螢幕寬，近丘稜線落在約 0.63（`layerBox()`）；孤樹在 `TREE`（x 70%、21 m）。
- 調色在 `palette()`：暖高光、藍紫陰影（`shadowTint`）、各層往天色靠（空氣透視）。
- 成本：1920×1080（半解析度）GPU 每格約 9–11 ms（量測時主程式同時在跑同一張桌布，數字偏高；天空那一格最貴，草帶約 2 ms，卡片約 1 ms）。除錯：theme.CONFIG.skip 可含 strips；粒子上限 1200。除錯：`theme.CONFIG.skip = 'cards,blades'` 可關掉某些 pass 量成本。v1／v2 備份在 Claude 的 scratchpad。
