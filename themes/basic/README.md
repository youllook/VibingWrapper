# 基礎版（basic）

最輕的主題，也是精簡版唯一內建的主題（2026-10-21）：一打開就看得懂「AI 現在在做什麼」，順便當除錯畫面。

- **背景**：五層山稜沒入薄霧，幾乎沒有飽和度，各層慢慢左右漂；日夜跟著時鐘（`?day=1`／`?night=1`）。
- **正中間**：
  - 5 段弧＝5 個 session 位置。顏色是狀態；動態各不同：待命呼吸、思考中有光點慢慢繞、執行中變粗抖動且光點快跑、收尾從頭畫滿、等你閃爍並往外發出圓圈。空位是虛線。
  - 環內是 60 秒活動鐘：一秒一根，事件越多越長。
  - 工具名稱從用到它的那段弧飛出去（`mcp__xxx__` 前綴省略）。
  - 下方是最近 2 分鐘的事件曲線。
- **除錯面板**（右下，`?debug=0` 關掉）：版本、bridge 延遲、`events.json` 是否可用、目前天空與 5 個位置、各類事件數、每個 session 的來源／狀態／閒置時間／事件數／最後工具、最近 5 個事件、fps 與每格耗時、頁面錯誤。

資料來源：`state.json`（所有主題共用）＋`events.json`（bridge 提供）；讀不到 `events.json` 時仍會跟著 `state.json` 的變化反應。
