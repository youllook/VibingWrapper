# 鷗航灣・Claude（beach-aerial-claude）

空拍正上方看熱帶海灘：左 1/3 是林地、花崗岩和白沙，右 2/3 是海，浪一道道推上岸，再往外是深藍外海和來往的船。
構圖參考用戶給的塞席爾風格空拍照（2026-10-24）。

## 三層
1. **陸地** `land.webp`：Codex 生成（Mac `gen.sh`）。prompt 刻意要求「把海抽乾」，所以海那半邊也是沙，順便當海床用。
2. **海**（程式）：
   - 岸線是幾條正弦疊成的曲線，每個像素算出「離岸距離」，當水深。
   - 浪的相位＝距離 × 波數＋時間，再用雜訊扭曲，讓浪頭平行岸線往岸推。外海是圓滑湧浪，近岸變成陡峭的碎浪。
   - 沖刷：每道浪上岸後的爬升與回退有解析解，退後留下深色濕沙。
   - 水色依深度做吸收與散射；海床有折射、沙紋、焦散，水面有日光閃點。
3. **泡沫**（程式）：一張 1024×576 的半精度 ping-pong 緩衝。
   - 生成：碎浪區（每道浪分段碎、碎點沿岸飄移）、沖刷前緣、外海白頭浪會注入泡沫。
   - 泡沫跟著浪頭速度走，落後的部分留下尾巴，再逐漸衰減。
   - 顯示：Worley 細胞邊緣隨密度「閉合」。泡沫新鮮時一片白、有小破洞，變舊後只剩蕾絲線。
     細胞在垂直岸線方向拉長（x 縮 0.45），舊泡沫就讀成回流的條紋；另外在碎浪點直接疊一條細亮的浪頭線（分段、沿岸飄）。
   - 注入量有一個沿岸慢變的「閘門」：有些岸段白浪多、有些幾乎清澈，避免整條岸一樣厚。

## 審稿後的調整（2026-10-24 第 1～5 輪）
- 雨滴漣漪改成三層錯位、稀疏、隨機存活的細胞，不再出現規則點陣。
- 外海湧浪線：浪面微暗、浪背微亮，用 fbm 閘門只在局部出現，遠處淡出（第一版太規則像瓦楞板，已壓低）。
- 水色吸收係數調低（od = depth×5.2），中深度還看得到海床暗斑；遠處偏深藍綠。
- 焦散調細調淡（scale 44、0.17），極淺水不出現，免得沖刷帶出現黃色網格。
- 沖刷帶泡沫透明度降低、近岸衰減加快；夜晚夜光藻壓到 0.26；白天等待中的海龜光暈加強到 0.3。

## 互動：船與海鳥（2026-10-24 改版，移除天氣）
天氣效果全部拿掉，畫面只跟著日夜變化。陸地往左收到畫面 1/3（`LAND_SHIFT` 讓 plate 左移），右邊 2/3 是海，越往右越深、轉成深藍外海。

**每個 session 是一艘船**（`boat1.png` 漁船、`boat2.png` 帆船，Codex `gen_sprite.sh` 洋紅幕）：
- **航行**：對話活著時，船從畫面下方駛進、上方駛出；隔幾秒換一條航道再來一趟。
  - 船隨湧浪輕晃：慢慢偏航、左右漂一點、大小微微起伏。
  - 船尾的攪動水注入泡沫緩衝，留在原地成為尾流，慢慢散開、消失。船頭兩側有浪花。
  - 船後方有 Kelvin 尾波（約 19.5° 的 V 形波臂加橫向波紋）：寫進水面高度，所以看起來是反光，不是泡沫。
- **依對話狀態**：
  - 執行中（storm）：船開快一點，有一隻海鳥跟著飛。
  - 等你回應（waiting）：船停下來怠速，四隻海鳥（`gull.png`）從畫面外盤旋進來繞著它飛，海面上有牠們的影子，偶爾拍一下翅膀。
  - 空位：船把這趟開完就不再出現。
- **夜晚**：船有白色桅燈、紅綠舷燈、艉燈和艙內暖光；泡沫是淡藍色的夜光藻。

**氣氛**：淺水有三隻海龜慢慢繞圈游，跟狀態無關。

## 泡沫注入改版（2026-10-24，審稿後）
- **白浪牆**：注入不再只在浪頭一條線。浪頭本身是實心的一道，後方（往外海）再拖一段厚的亂流帶，後緣用 fbm 撕碎；密度上限 1.4→1.7。
- **外海尾巴**：
  - 加了幾條窄的**離岸流**：沿岸慢慢飄的雜訊決定位置。碎浪區的水沿岸往離岸流匯集，再往外海流（0.03／秒），把舊泡沫拉成長尾。
  - 離岸流附近的白浪最多；離岸流裡的泡沫衰減最慢（0.012／秒）。
  - 兩道浪之間，碎浪區的水會往外回流。
- 顯示：密度很低的泡沫也會留一條細蕾絲線，尾巴才看得到。
- 修正：沖刷爬升高度原本每個浪週期用 floor() 跳一次，會把濕沙帶沿岸撕出斷層，改成連續變化。

## 船與尾流審稿（2026-10-24 第二次，4 輪）
- **船尾尾流改走泡沫緩衝的 G 通道**，自己一條命：螺旋槳後面窄窄一道攪動（約船寬 0.4），橫向擴散、0.3／秒衰減，
  約十秒內散掉，所以尾流是一條漸細的舌頭，不再是拖到畫面底的白粉筆線。船頭浪花也放在 G。顯示用更細的 Worley 細胞（90／210）。
- **Kelvin 尾波兩側都看得到**：高度場的波臂只靠太陽閃光，所以原本只亮一邊。另外在水色上疊一條淡淡的「浪脊接天光」亮線，
  不吃光向、有週期性的小浪頭鏈，長度壓到約 0.34（高度場 env 也從 exp(-4.5s) 收到 exp(-7s)）。
- **船坐進水裡**：船體 alpha 放大 1.07 倍當接觸陰影（waterline 一圈暗水，0.24），加上原本的偏移軟影。
- **夜晚可讀**：船殼不再先乘 0.16 再乘月光 0.15（兩次變暗剩 2%）；現在只吃月光，艙燈 1.4 倍暖光。海鳥同理（1.15）。
  夜光藻的光會被船體與海鳥的 alpha 遮住，蕾絲不再爬過甲板；船尾尾流的夜光壓到 40%。
- **效能**（Intel UHD 630、1920×1080、`?perf=1` 用 readPixels 同步量；gl.finish 在 ANGLE 下不會擋）：
  主畫面 97 ms → 56 ms，泡沫模擬 ~10 ms。做法：Worley／fbm 只在緩衝有東西的地方算（深海大部分像素跳過），
  焦散、沙紋、海床斑、風紋、湧浪線各自限定深度範圍，海鳥／船／海龜先用距離剔除再採樣貼圖，heightW 的 fbm 降為 3 層（每像素算 3 次）。
  獨顯應該落在 10–15 ms 左右；30 fps 上限不變。
- 除錯：`?perf=1` 左上角顯示 120 幀平均／最大幀時與暖機時間（`window.__warmMs`）。
