# 天氣

只有天空的桌布：體積感的雲、逐滴的雨、閃電、陽光光束，日夜跟著台北的真實日出日落。

- 入口：`index.html`（單一 WebGL fragment shader）
- 測試介面：`window.weather`
- 預覽：`http://127.0.0.1:47321/themes/demo.html` → 樣式選「天氣」

## 狀態 → 參數

每個狀態是一組「目標數值」，切換時從目前的實際數值平滑轉過去（可中斷，時間依變化量縮放）。
數值定義在 `index.html` 的 `PARAMS`（範圍）和 `STATES`（目標）；用 demo 頁調好後可以匯出貼回去。

| 狀態 | 意思 |
|---|---|
| `clear` | 晴：閒置 |
| `overcast` | 陰：Claude 在想 |
| `storm` | 雷雨：Claude 在跑工具 |
| `clearing` | 轉晴：剛做完 |
| `waiting` | 等你：Claude 在等你回答或批准 |

## 雨窗（2026-10-23）

下雨時，整片天空像隔著一扇窗在看：玻璃起霧、雨滴滑落、水珠裡看出去是清楚的、雨痕把霧擦開。

- 天空先畫進一張貼圖，再過一道「玻璃」pass（用 mipmap 層級當霧玻璃模糊）。玻璃乾的時候直接畫天空，不多花任何東西。
- 雨量 = 天空本身的 `rainAmount`（這場雨隨機擲的強度也一起帶過來）；日夜 = 桌布的太陽仰角（`?day=1`／`?night=1`／齒輪模式都適用），夜裡燈光與閃電會在霧玻璃上暈開。
- 下雨約 8 秒玻璃慢慢起霧；雨停（轉晴）時做一次 4.5 秒的對焦轉移：霧散、焦點拉回天空、鏡頭微微拉遠回原位，**玻璃上的水同時收乾，放晴後不留任何雨滴**。
- 參數在 `GLASS`（起霧秒數、對焦秒數、鏡頭縮放量、開始／停止的雨量門檻），`window.weather.glass` 看現在的狀態，按 `d` 的 HUD 也有。`?glass=0` 關掉這層。需要 WebGL2（沒有就自動不畫）。
- 程式碼自己寫的（跟本 repo 一樣 MIT），只照物理原理：水珠＝球冠凸透鏡（看到縮小倒立的天空、邊緣一圈暗環）、霧玻璃＝散射（mip 模糊＋略為泛白）、滑落的雨滴沿路擦掉霧、雨痕慢慢又起霧；水珠各自慢慢長大再蒸發，大雨滴「黏住→突然滑」沿只隨高度變化的蛇行路徑落下。雜湊用 lowbias32（Chris Wellons，公有領域）。
- 構想來自研究 BigWings〈Heartfelt〉（Shadertoy ltffzl）時的拆解，但沒有沿用它的程式碼。

## 調整筆記

- 雲的畫法參考 power418/skygl（MIT），壓成單一 2D pass。
- 每場雨開始時隨機擲強度與風向（`rainMood`），雲跟著同一陣風飄。
- 這份程式碼和 `../sea/` 一開始是同一份複製出來的；海的程式還在裡面但預設關閉（`?sea=1` 可以打開比較）。
