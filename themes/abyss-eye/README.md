# 深淵之眼（abyss-eye）

兩千公尺深的黑暗裡，大王酸漿魷的巨眼從右邊浮現；一條小安康魚提著燈在眼前游。
**動作是固定的演出，Claude 只改變光**：越忙燈越亮，燈照到哪裡，巨獸的皮膚、吸盤、鉤爪就浮現到哪裡。

2026-10-25 第一版。設計稿與規格在 `docs/素材庫/colossal-squid/DESIGN.md`、`SPECS.md`（素材庫不進 git，在作者本機）。

## 狀態對照（只改餌燈亮度與海雪）

| 狀態 | 餌燈（燭光） | 畫面 |
|---|---|---|
| 沒有對話（`sessions` 全空） | 0.05 | 幾乎全黑：剪影、眼球一點反光、眼下發光器 |
| `clear` / `clearing` | 0.55 | 看得到輪廓與濕潤高光 |
| `overcast` | 1.30 | 皮膚斑紋、腕上吸盤 |
| `storm` | 1.60 | 同上，再亮一點 |
| `waiting`（等你回覆） | 3.20 | 最亮：整個頭部、漏斗、眼周細節 |

鍵盤（除錯用）：`0`–`5` 切狀態，`d` 開資訊列。

## 固定演出（90 秒一輪，`CONFIG.cycle`）

| 秒 | 內容 |
|---|---|
| 0–18 | 黑暗，牠在遠處（`CONFIG.away`）幾乎看不到 |
| 14–30 | 眼下發光器亮起 |
| 18–40 | 從右後方游近到定位（`CONFIG.stage` = 左眼的位置） |
| 40–70 | 停住：腕慢慢捲動、頭微轉、巨眼映著餌燈 |
| 70–88 | 沉回黑暗 |

安康魚全程在眼前畫一個慢慢的八字（46 秒一圈，`CONFIG.fishOrbit`），擺尾、划胸鰭、釣竿晃、嘴一張一合。

## 技術

- three.js r170，放在 `vendor/`（MIT，`vendor/LICENSE-three.txt`）：魷魚是蒙皮網格，手寫 WebGL2 太費工。
- 模型：`assets/colossal_squid.glb`（5.45 m、84 根骨頭，眼球與 14 顆發光器掛在頭骨）、`assets/anglerfish.glb`（0.185 m、下顎骨、各鰭與釣竿／餌球是獨立節點）。來源與節點說明見素材庫 README；兩者都是 Tripo 專業版產出（私有、可商用）再經 Blender 腳本處理。
- 光：餌球上掛一盞 `PointLight`（場景唯一的真光源）＋極弱的藍色半球光；ACES 色調、指數霧。
- 海雪：2,600 顆點，緩慢下沉，離餌燈越近越亮。
- 腕：每條骨架鏈沿鏈傳一道慢波（`CONFIG.armAmp` 調幅度，0 = 靜止姿勢）。
- 30 fps 上限、像素預算 1920×1080 的一半；實測每格約 5.5 ms（含同步，內建瀏覽器）。
- 測試網址參數：`?t=55` 固定在演出第 55 秒、`?state=waiting` 固定狀態（不讀 state.json）。
  `window.theme`：`requestState`、`applyState`、`setTime(秒|null)`、`setSessions([...])`、`frame()`、`CONFIG`、`squid`、`fish`。

## 已知問題 / 下一步

- 左下一根腕尖（觸腕穗）近看有塊狀破面，是 Tripo 網格本身；腕擺動太大時會折得硬。
- 眼球是純黑鏡面球，轉動看不出來；「看向小魚」目前靠頭骨微轉。
- 還沒做：光量低時用發光海雪粒子勾出巨獸輪廓（粒子凝聚）、牠游近時外套膜收縮噴水。
- 還沒在 VibingWrapper 本體裡跑過（只在瀏覽器驗過）。
