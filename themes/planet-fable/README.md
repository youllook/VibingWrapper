# 行星・Fable（planet-fable）

一格科幻電影劇照（2026-11-10）：從一顆衛星的低軌道往外看，帶環的氣態巨行星佔住右上，衛星的隕石坑地平線橫過下緣，
左下一列小船。恆星在畫面外或剛好探出行星邊緣，光從左上方來。整張圖只有一個 WebGL fragment shader：
解析幾何的行星／環／衛星、緯向雲帶（緯度一維剖面三種寬度＋帶邊剪切渦流；大紅斑是雲帶繞行的橢圓）、大氣邊緣光與前向散射、環與行星互相投影、
星空＋銀河、閃電、極光、流星、變形鏡頭光暈；第二道 post pass 做半解析度放大、色散、泛光、ACES、
分離調色（陰影偏青、高光偏暖）、暗角、膠卷顆粒。沒有圖檔、沒有外部函式庫。

## 狀態如何講故事

核心手法：**恆星繞著行星走**（`sunAngle` = 相機看出去，恆星離行星中心幾度；0 = 恆星正好躲在行星背後）。
相位、環的受光、衛星的明暗、鏡頭光暈全部跟著它一起變，所以每個狀態是一種「光」而不是一個圖示。

| 狀態 | 畫面 |
|---|---|
| `clear` 待命 | 恆星在左上畫面外（98°），凸月相、側光，雲帶緩慢，環從左側受光，暖色調。 |
| `overcast` 思考中 | 恆星往行星靠（80°）變半相；雲帶翻湧（domain warp 變強）、大紅斑漩渦加深、地平線塵霾變厚，調色偏冷。 |
| `storm` 執行工具 | 細彎月（62°），大片夜面：雲頂閃電連閃、兩極極光全開、流星頻繁、小船引擎噴焰。 |
| `clearing` 收尾 | 日出破限（25°）：恆星從行星邊緣探出，環被背光照成金色，變形鏡頭的藍色橫向光暈最強，整張最暖。 |
| `waiting` 等你 | **日蝕**（6°）：行星變成黑盤，只剩一圈大氣光慢慢呼吸（1.7 rad/s），環前向散射發亮，衛星幾乎只剩輪廓。一眼看得出「停下來了」。 |

狀態切換是連續的（`fullTransition` 6 秒 × 參數變化量），所以 storm → clearing 會看到恆星沿著天空升起。

## Session（五個位置）＝地平線上一列小船

左下、衛星地平線上方一排 5 艘小船（固定位置，慢慢往右漂），每艘是一個暗色船身＋一盞導航燈（帶小小的橫向光芒）。
燈光跟著那個 session 的狀態：

- `clear` 暖白恆亮　· `overcast` 琥珀色慢慢明滅　· `storm` 青藍色引擎噴焰拖尾（`events.json` 有事件時更亮）
- `clearing` 橘光、噴焰漸弱　· `waiting` 紅色雙閃（像航空警示燈）　· `null` 沒有船

## 日夜（`?day=1` / `?night=1`，預設跟真實時間）

夜晚＝恆星角度乘 0.75（彎月更細、更戲劇）、整體曝光降 22%、星空更亮。日間維持原角度。

## 參數（demo.html 可調，`window.theme`）

`sunAngle` 恆星角度 · `turbulence` 雲帶翻湧 · `vortex` 大紅斑 · `lightning` 閃電 · `aurora` 極光 · `haze` 地平線塵霾 ·
`flare` 鏡頭光暈 · `warmth` 調色冷暖 · `shake`（已停用，鏡頭固定） · `meteors` 流星 · `beacon` 日蝕光環呼吸 · `exposure` 曝光。
測試鉤子：`requestState / applyState / STATES / PARAMS / CONFIG / setOverride / setSessions / jump(name) / snapshot()`。
快捷鍵 1–5 切狀態。`?debug=1` 右下顯示除錯面板（預設沒有任何文字）。

## 效能

場景在 0.40 倍解析度算，post pass 全解析度；30 fps 上限。Intel UHD 630、1920×1080 實測一格約 12–13 ms（含同步讀回，2026-11-10 v2），
獨顯遠低於此。`CONFIG.scale` 可再降。

## 構圖筆記

相機在 (0, 0.6, 4.7)，行星半徑 1、環 1.3–2.36，環面法線 (0.36, 1, 0.2)；衛星半徑 1.5 貼在相機前下方。
衛星永遠畫在環前面（我們在環外很遠的軌道，不會被環切到）。氛圍優先於物理：日蝕時衛星仍有一點環光補光。

## v2 修正（2026-11-10）

雲帶改緯向細帶；環變薄且半透明、在行星上的投影改用平滑剖面；衛星隕石坑減量（少數大坑＋細小坑＋風化、月海明暗、邊緣反鋸齒）；
星數大減且隨恆星角度（畫面曝光）變暗；小船改剪影（艦橋／引擎／桅杆）＋邊緣受光、縮小；鏡頭 ghost 只在收尾出現。
