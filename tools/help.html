VibingWrapper 說明

右上角

AI 圖示
Claude Code／Codex 現在在做什麼：待命、思考中、執行中、收尾、等你。桌布的天氣跟著它變。
齒輪
所有設定都在這裡。上下鍵移動、Enter 選、← 或 Esc 回上一層。

齒輪選單

桌布
換桌布。最近用過的排最上面；主題很多時可以直接打字搜尋。
主題庫
在「桌布」最下面。看所有主題的預覽圖，下載新的、套用、移除下載過的。
模式
預設跟著真實時間日夜變化；也可以固定成日間或夜間。
還原桌面
一鍵把桌布和圖示全收起來，看起來就是普通桌面；再按一次同一組快捷鍵就回來。
桌面圖示
一鍵收起／放回桌面上所有圖示，右邊會顯示現在是開還是關。
設定
Claude／Codex 連動、改快捷鍵、語言、更新、這份說明、重新啟動、解除安裝。

快捷鍵

Ctrl+Alt+B
還原桌面（可在 設定 → 快捷鍵 改）
Ctrl+Alt+D
隱藏／顯示桌面上所有圖示

連動與更新

Claude 連動
只對 Claude Code 有效：終端機的 CLI，或 Claude Desktop 的 Code 分頁。Claude Desktop 的一般對話沒有 hook，天氣不會變。裝好後要重開 Claude Code。
Codex 連動
有裝 Codex 才會出現，用法同上。
語言
自動（跟著 Windows 顯示語言）、中文或 English，點一下切換。
更新
有新版時齒輪會出現紅點。「自動」會在 Claude 閒著時自己更新並重開；「手動」只提醒，到 設定 → 更新 點一下。
桌布被最大化或全螢幕的視窗蓋住時會自動暫停，不吃效能。設定、紀錄和下載的主題都在 %APPDATA%\vibing-wrapper，更新不會動到。

VibingWrapper Help

Top-right corner

AI icon
What Claude Code / Codex is doing right now: Idle, Thinking, Working, Wrapping up, Waiting for you. The wallpaper's weather follows it.
Gear
Every setting lives here. Arrow keys move, Enter picks, ← or Esc goes back.

Gear menu

Wallpaper
Change the wallpaper. Recent picks are on top; with many themes, just start typing to search.
Theme library
At the bottom of Wallpaper. Previews of every theme: download new ones, apply, remove downloaded ones.
Mode
Auto follows the real time of day; or hold it at Day or Night.
Plain desktop
Hides the wallpaper and icons in one go, so it looks like an ordinary desktop; press the same shortcut again to bring it back.
Desktop icons
Hide or show every icon on the desktop; the right side shows whether they are on or off.
Settings
Connect Claude / Codex, shortcuts, language, updates, this help, restart, uninstall.

Shortcuts

Ctrl+Alt+B
Plain desktop (change it under Settings → Shortcuts)
Ctrl+Alt+D
Hide / show all desktop icons

Connections and updates

Connect Claude
Works with Claude Code only: the CLI in a terminal, or the Code tab in Claude Desktop. Plain Claude Desktop chats have no hooks, so the weather won't change. Restart Claude Code after installing.
Connect Codex
Shows up only when Codex is installed; same idea.
Language
Auto (follows the Windows display language), 中文 or English; click to switch.
Update
A red dot on the gear means a new version. Auto updates and restarts by itself while Claude is idle; Manual only reminds you: click Settings → Update.
The wallpaper pauses while a maximized or full-screen window covers it, so it costs nothing then. Settings, logs and downloaded themes live in %APPDATA%\vibing-wrapper; updates leave them alone.
