# 木材貼圖（大海怪3 的船，boat.gdshader）

Poly Haven，CC0（免標作者），4K 下載後縮成 2K：

| 檔名前綴 | 來源 | 用在 |
|---|---|---|
| `planks_*` | [worn_planks](https://polyhaven.com/a/worn_planks) | 船側板（木板沿船身） |
| `timber_*` | [rough_wood](https://polyhaven.com/a/rough_wood) | 船舷頂蓋、甲板、木樁 |

`_diff` 顏色、`_nor_gl` 法線（OpenGL）、`_rough` 粗糙度。4K 原檔在 `E:\tmp\sea-monster-3\wood\`。
